# 전 과정 UX 여정 (2026-11)

교재 넣기 → AI로 만들기 → 다듬기 → 참여 기능 → 공개·QR → 연수 당일 → 연수 후를 한 줄로 이어 보고, 화면·결정·누름·앱 밖 일·글자를 재서 줄였어요.
운영자 요구: "작업대(lecpage)" 구조 때문에 왔다 갔다·복잡해지면 안 됨. 그냥 AI 에이전트보다 쉬워야 함.
정해진 것(바꾸지 않음): AI로 만드는 것이 기본, AI는 두 길(쓰던 챗봇 창·API 키), 에이전트 스킬은 .lecpage로 넘어옴, 교재 지킴이.

## 1. 재는 법

- 스크립트: `scratchpad/ux-journey/before.js`·`after.js`(Playwright), 도우미 `meter.js`. 앱은 빌드해 `vite preview`로 띄우고, 바깥(챗봇·Vercel·구글 시트·Cloudflare)은 흉내 서버로 이어요. 실제 AI·계정·배포는 쓰지 않았어요.
- 교재: 실습형 `practice-ai-lesson.pptx`(21쪽). 챗봇 답은 프롬프트 속 초안으로 만든 흉내 답.
- 단계마다 셈: **화면**(새 화면·창·대화상자), **결정**(고를 것이 둘 이상인 곳), **누름**(앱 안), **입력**, **앱 밖**(새 창·다른 앱으로 나감) 횟수와 그곳에서 할 **밖 동작** 수(가입·로그인·칸 채우기·복사, 앱 안내 글 기준), **보이는 글자**(화면에 들어온 글자, 공백 뺌)·**전체 글자**(스크롤 포함), 기다림, 되돌아감, 막힘(인지적 워크스루로 판단).
- 페르소나
  - **P1** AI를 거의 안 써 본 초등 교사 · 학교 PC 1366×768 · 챗봇 계정 없음
  - **P2** ChatGPT만 써 본 중등 교사 · 노트북 1440×900
  - **P3** 휴대폰으로만 하는 강사 · 390×844 터치
- 참여 기능은 질문 받기·투표, 올릴 곳은 앱의 첫 추천(바로 공개 꺼짐 = Vercel), 참여 기능 연결은 앱의 첫 추천(전: 구글 시트).

### 2.3 막히는 곳·왔다 갔다(전)

1. **만들기 전에 고르기 화면**: [AI 연결하고 만들기] → "쓰던 챗봇 창 / API 키" 두 카드. P1은 'API 키'·'프롬프트'를 몰라 고를 근거가 없음. 고른 뒤에도 챗봇 셋·[프롬프트만 복사] 중 또 고름(결정 2).
2. **챗봇 길이 대화상자 안**: 챗봇 창에 다녀오는 동안 대화상자에 걸려 있음. 휴대폰은 다른 앱에 다녀오면 브라우저가 탭을 새로 고쳐 대화상자가 닫히고, [AI로 사이트 만들기]부터 다시(받은 답을 넣을 자리가 사라짐).
3. **1366×768에서 만들기 버튼이 첫 화면 밖**: 파일 목록 → 찾은 것 → PPT 안내 → 연수 정보 → 요청 사항 → 더 정하기 → 버튼 순서.
4. **공개 화면에 계정 일이 둘, 서로 떨어져 있음**: 위에서 Vercel 가입·토큰 → [공개하기] → "참여 기능이 아직" 확인 창 → 맨 아래 참여 기능 연결(구글 시트 6단계: 시트 만들기·Apps Script·권한 허용 '안전하지 않음' 경고·관리자 키 짓기·연수 코드·웹 앱 배포) → 다시 위로 올라가 [공개하기]. 밖 동작 35, 결정 4(공개 범위 3·올릴 곳 5·연결 방법 3).
5. **구글 시트는 연수마다 처음부터**(시트 하나 = 연수 하나). 다음 연수에도 6단계를 다시 함. 휴대폰에서는 Apps Script 편집기를 쓸 수 없어 사실상 못 함.
6. **관리자 키를 강사가 지어 기억해야 함**: 시트 메뉴·Cloudflare ADMIN_KEY 칸에 직접 짓고, 연수 당일 강사 화면에서 다시 넣어야 하는데 앱에는 남지 않음.
7. **공개 뒤 고치면 다시 3단계로**: 이전 → 탭 → 고치기 → 공개하기 → → 아래로 → [바뀐 내용 다시 올리기]. 참여 기능을 공개 뒤에 켜면 두 번 올림.
8. **"느낌이 다른 세 안" 비교가 안 됨**: 추천 4개가 모두 한 계열(이 교재는 테크·미래적).
9. **고치기 화면 누를 것 99개**(첫 화면 안 50): 섹션마다 위·아래·숨기기.
10. **연수 당일 진입**: 처음 화면 → 내 연수 → 공개하기 단계 → 발표 화면·강사 화면. 강사 화면 관리자 키는 앱에 없음.
11. **바로 공개 서버가 켜진 앱**: 첫 추천이 Vercel(직접 바로 공개를 골라야 함), 새 연수가 질문·보드를 켠 채 시작해야 하는데 교재를 넣으면 꺼진 채가 됨(교재 읽기가 끝나며 예전 연수 정보로 덮어씀).

## 4. 설계

### 4.1 원칙

1. **결과가 먼저, 계정은 꼭 필요할 때 한 번.** 교재를 넣으면 바로 만들기로. 올릴 곳·참여 기능 계정은 공개 직전 체크리스트에서 한 번에, 다음부터는 저절로.
2. **한 화면 한 일, 주 버튼 하나.** 고를 것은 기본값으로 정해 두고 한 줄 [바꾸기]로 접음.
3. **밖에 나갔다 오면 하던 자리, 다음 할 일 하나만.** 나간 사실을 저장하고, 돌아오면 그 버튼에 초점. 허락받은 클립보드는 저절로 읽음.
4. **바깥에 넣을 값은 앱이 만들어 복사.** 관리자 키를 강사가 짓지 않음. 앱이 기억해 연수 당일 보여 줌.
5. **되돌릴 수 있게, 막다른 길 없이.** 모든 디자인 선택은 되돌리기, 참여 기능은 건너뛰고 올린 뒤 나중에 켤 수 있음.
6. **lecpage의 강점이 흐름 속에서 보이게.** 기다리는 동안 "교재에서 찾은 것"(교재 그대로), 세 안 비교(주제 맞춤 디자인), 체크리스트의 참여 기능(연수 당일 기능), 체크리스트 한 장(쉬운 공개).

### 4.2 여정 지도(전 → 후)

```
전: 첫 화면 ─ 교재 넣기(긴 양식) ─ [AI 연결하고 만들기] ─ ⟨길 고르기⟩ ─ ⟨챗봇에 보내기⟩ ⇢ ChatGPT ⇢ ⟨답 넣기⟩
    ─ 고치기(탭 5·누를 것 99) ─ [공개하기 →] ─ 공개하기(범위·올릴 곳 5·Vercel 3단계) ─ [공개하기] ─ ⟨참여 기능이 아직⟩
    ─ 맨 아래 구글 시트 6단계 ⇢⇢⇢⇢ ─ 위로 ─ [공개하기] ─ 주소·QR
    (고치면: 이전 ─ 고치기 ─ 공개하기 → ─ 아래로 ─ [다시 올리기])

후: 첫 화면(.lecpage도 받음) ─ 교재 넣기: 찾은 것 + 연수 정보 한 줄 + "AI로 만들기" 카드(ChatGPT로 만들기 ↗ 바로)
    ⇢ ChatGPT ⇢ 돌아오면 [답 넣기] 하나(허락했으면 저절로, 탭이 새로 고쳐져도 그 자리)
    ─ 고치기(디자인: 느낌이 다른 세 안 크게, 순서 바꾸기는 접음) ─ [공개하기 →]
    ─ 공개 준비 체크리스트: ① 참여 기능(내 서버는 한 번 연결하면 다음부터 자동·관리자 키는 앱이 만듦) ② 올릴 곳(추천 하나, 연결되면 한 줄) ③ 공개 범위 한 줄 ④ 확인할 곳
    ─ [공개하기] 한 번 ─ 주소·QR + 연수 당일 묶음(발표 화면·강사 화면·관리자 키·안내문)
    (고치면: 고치기 화면 머리 [바뀐 내용 다시 올리기] 한 번 · 연수 당일: 처음 화면 내 연수 카드에서 바로)
```

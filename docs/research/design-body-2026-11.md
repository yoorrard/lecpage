# 강의 페이지 본문 디자인 다양화 (2026-11)

사용자가 세 번 짚은 문제: ① 모든 시안의 본문이 비슷함(제목 자리만 다르고 "01/02/03 + 한 줄" 목록) ② 글 왼쪽 정렬·글 위주, 그림이 주인공인 본문이 없음 ③ 움직임·반응이 첫 화면에 몰림.
목표: 시안마다 본문 **구성 자체**가 다르고, 그림·도식·움직임이 본문 전 구간에 고르게 쓰이며, 읽기 쉽고 겹침·꼬임 0건.

## 1. 진단(숫자) — 바꾸기 전

`skills/lecpage/scripts/body-diversity.mjs`: 프리셋 27개 × 설계도 3개(예시 2종 + 모든 본문 칸을 담은 시험 설계도 `engine/test/fixtures/body-all.blueprint.json`)를 폭 1440px 브라우저로 열고, 섹션마다 **구성 지문**을 뽑음.

- 구조 지문 = DOM 뼈대(내용 상자들의 태그·첫 클래스, 4단계 깊이) + 격자 열 수 + 주인공(글 · 숫자 · 그림 · 도식 · 조작). 정렬·머리 자리는 넣지 않음("정렬만 바꾼 것은 다르다고 세지 않음"). 그림 넓이가 내용 넓이의 20% 넘으면 그림(그중 절반 넘게 교재 값으로 그린 도식이면 도식), 40px 넘는 실제 값 숫자(순번은 뺌)가 5% 넘으면 숫자, 따라 하는 칸·입력칸이 주인이면 조작
- 사람이 읽듯 끝까지 내렸다가 처음으로 돌아온 뒤 잼(들어올 때 한 번 움직이는 그림이 제자리에 온 모습)
- 프리셋 쌍(351쌍)마다 같은 자리 섹션의 구조 지문이 같은 수를 셈. '읽는 칸만'은 따라 하는 칸(교재·질문·보드·투표·설문·실습 등)을 뺀 값
- 움직임·반응 섹션 = 따라 하는 칸을 뺀 섹션 중 스크롤 연동(scroll-driven CSS·붙박이·숫자 세기·선 그리기) 또는 가리킴·누름 반응(카드 hover 규칙·넘김·아코디언·도식 잇기)이 있는 섹션
- 표 원본: `docs/research/data/body-diversity-before.md`(main, 같은 측정) · `body-diversity-after.md`

- **고르는 순서**: 섹션의 `layout`("변형", "변형@c·@r·@l") → 교재 구성 흐름(`structure.flow`)의 주인공 칸(프리셋이 기본 배치를 골랐을 때만: procedure → 절차·핵심 단계 흐름도, discussion → 큰 물음표·인용 카드, course → 진행 지도, event → 가로 트랙·그림 숫자, talk → 무대·발표 순서) → 프리셋 계획 → 기본.
- **내용이 맞지 않으면 기본으로**(지어내지 않음): 시간 도식은 하루 안·모든 길이를 알 때만, 낱말 그물은 3~8개, 고리는 3~8개, 비교 열은 견줄 것 2~4개 등(`FITS`).
- **같은 종류 칸이 둘이면 두 번째는 다른 배치**(설명회 교재의 한눈에 보기 둘, 자료와 연수 후 안내).
- **도식은 교재 값으로만**: 일정 → 길이에 비례한 트랙·시계판·블록, 목표 → 여정의 정류장, 핵심 단계 → 고리·흐름도, 절차 → 흐름도, 수치 → 도넛·시계 고리·점 묶음, 차시 → 진행 지도(지난·지금 표시), 용어 → 연수 제목을 가운데 둔 낱말 그물, 자료 → 책등에 자료 제목.
- **모티프 되풀이**: `concept.motif` 글에 그림 가족 낱말이 있으면 그 가족(물결 → waves 등), 없으면 프리셋 가족. 바탕이 같은 두 섹션 사이 구분 장식 · 옅은 바탕 칸 구석 그림(앞 두 칸만, 크기 절약) · 무대 · 좌우 번갈아 · 큰 얼굴 · 마무리 그림.
- **AI 티 규칙**: 가짜 로고(이름 첫 글자 딱지)는 쓰지 않음 → 도구 타일은 '떼는 쪽에 주소'인 표 모양으로 바꿈. 한쪽 색 띠·알약·그라데이션 글자 없음(테스트). 카드 3D 기울기 없음(종이 쪽지·더미만 1도 안팎).

### 3-2. 프리셋마다 조합(`PRESET_BODY`, `scripts/plan-body.mjs`)
분위기 낱말(moods → calm·formal·playful·editorial·tech·bold·warm)과 변형의 어울림 점수를 높이고 한 변형이 너무 많은 프리셋에 몰리지 않게(한도 = 프리셋 수 ÷ 변형 수 + 2) 하면서, 시험 설계도 셋에서 **어느 두 프리셋도 본문 배치가 절반 넘게 같지 않음 · 프리셋마다 그래픽 주인공 2개 이상 · 글만 있는 섹션 절반 이하 · 왼쪽 정렬이 아닌 섹션 2개 이상**을 지키도록 담금질(씨앗 고정, 위반 0). 예시 두 벌의 프리셋은 연수 성격에 맞춰 일부 고정(마음 연수 = 선언문·무대·고리·시계판·질문 색인·파일 더미·큰 얼굴·그래픽 마무리, 데이터 연수 = 번호 줄·가로 시간 축·낱말 그물·문항 카드·줄 목록·서명 카드). 배치가 다른 디자인 여섯은 나란히 견주어 보는 일이 많아 목표 구조를 서로 다르게 고정(선언문·번호 줄·벤토·세로 단·여정·번호 줄@r).

- 원칙: 가독성 먼저, 한 화면에 큰 움직임 하나, 본문 글자는 등장 뒤 정지, 반복은 장식만, transform·opacity만, 화면 밖 정지(스크롤 연동이라 화면 밖에서는 계산하지 않음), CLS 0(넘김·필름 띠는 판이 한 줄에 같은 높이로 서 있음, 단추 자리는 `html.js`로 처음부터 잡음).
- 단계: 0 정적 · 1 섹션이 들어올 때 한 번(배치마다 다른 방식: 선언문 번짐·여정 위에서 펼침·벤토 커짐·흐름도 옆에서·쪽지 내려앉음·명함 넘어옴…, 도식은 길·축·고리가 제자리로) + 가리킴 반응 · 2 스크롤 연동(여정의 길이 그려지고 정류장이 켜짐, 트랙이 왼쪽부터 참, 시계판·고리·낱말 그물이 돌아 들어옴, 선언문 문장이 화면에 들어오며 또렷해짐, 필름 띠 가운데 장면, 무대·마무리 그림이 천천히 미끄러짐, 큰 물음표가 기울어짐) · 3 = 2 + 첫 화면·띠의 장면 연출.

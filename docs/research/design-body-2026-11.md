# 강의 페이지 본문 디자인 다양화 (2026-11)

사용자가 세 번 짚은 문제: ① 모든 시안의 본문이 비슷함(제목 자리만 다르고 "01/02/03 + 한 줄" 목록) ② 글 왼쪽 정렬·글 위주, 그림이 주인공인 본문이 없음 ③ 움직임·반응이 첫 화면에 몰림.
목표: 시안마다 본문 **구성 자체**가 다르고, 그림·도식·움직임이 본문 전 구간에 고르게 쓰이며, 읽기 쉽고 겹침·꼬임 0건.

## 1. 진단(숫자) — 바꾸기 전

`skills/lecpage/scripts/body-diversity.mjs`: 프리셋 27개 × 설계도 3개(예시 2종 + 모든 본문 칸을 담은 시험 설계도 `engine/test/fixtures/body-all.blueprint.json`)를 폭 1440px 브라우저로 열고, 섹션마다 **구성 지문**을 뽑음.

- 구조 지문 = DOM 뼈대(내용 상자들의 태그·첫 클래스, 4단계 깊이) + 주인공(글 text · 큰 숫자 number · 그림 figure · 도식 diagram — 그림 넓이가 내용 넓이의 20% 넘으면 그림, 그중 절반 넘게 교재 값으로 그린 도식이면 diagram, 40px 넘는 숫자가 5% 넘으면 number)
- 전체 지문 = 구조 지문 + 격자 열 수 + 머리 자리(위·왼쪽·오른쪽) + 정렬(제목·첫 글)
- "정렬만 바꾼 것은 다르다고 세지 않음" → 비슷함은 **구조 지문**으로 판정. 프리셋 쌍마다 같은 자리 섹션의 지문이 같은 수를 셈
- 움직임·반응 섹션 = 따라 하는 칸(실습·질문·교재·보드·투표)을 뺀 섹션 중 스크롤 연동(scroll-driven CSS·붙박이·숫자 세기·선 그리기) 또는 가리킴·누름 반응(카드 hover 규칙·탭·아코디언·넘김)이 있는 섹션

| 설계도 | 구조 지문이 절반 넘게 같은 쌍 | 가장 비슷한 쌍 | 평균 같은 비율 | 글만 있는 섹션(평균/최대) | 그래픽 주인공(평균/최소) | 왼쪽 정렬 아님(평균/최소) | 움직임·반응 섹션(평균) |
|---|--:|--:|--:|--:|--:|--:|--:|
| sel-story(15칸) | **351 / 351** | 100% | 91% | 82% / 93% | 0.1 / 0 | 3.8 / 1 | 6.9 |
| data-lab(14칸) | **351 / 351** | 100% | 96% | 94% / 100% | 0 / 0 | 2.9 / 0 | 2 |
| body-all(20칸) | **351 / 351** | 100% | 95% | 86% / 90% | 0 / 0 | 4 / 0 | 6 |

섹션 종류별 서로 다른 구조 지문 수(27개 프리셋 가운데): 대부분 **1**(목표 2 · 메시지 2 · 마무리 2~4). 정렬·머리 자리를 넣은 전체 지문도 쌍의 절반 이상(186~200쌍)이 절반 넘게 같음.
→ 사용자의 말 그대로: 27개 시안이 본문에서는 사실상 한 벌. 왼쪽 정렬이 아닌 섹션은 가운데·오른쪽 정렬 프리셋 5개에 몰려 있고 나머지 22개는 0~1개.

## 2. 레퍼런스(본 것 → 가져온 원리)

- Øredev 2025(Awwwards 선정, https://www.awwwards.com/sites/oredev-2025) → 섹션마다 화면 문법이 바뀌어도 한 가지 그림 언어(우주 모티프)가 되풀이되면 한 사이트로 읽힘 → 컨셉 모티프를 구분 장식·숫자 장식·마무리 그림으로 되풀이
- Spring I/O 2025 세션 화면(Awwwards 요소, https://www.awwwards.com/inspiration/sessions-spring-i-o-2025-conference) → 일정은 표가 아니라 시간 축 위의 덩어리로 보일 때 "지금"이 한눈에 → 가로 트랙·시계판·블록(길이만큼 높이)
- Fourwaves 행사 일정 사례(https://fourwaves.com/blog/conference-website-designs) → 시간 레일을 왼쪽에 고정하면 긴 일정도 읽힘 → 기본 일정(세로 레일)은 그대로 두고, 짧은 연수에만 도식형을 고름
- scroll-driven-animations.style 가로 붙박이 예제(https://scroll-driven-animations.style/demos/horizontal-section/css) → 붙박이 틀 안에서 띠가 옆으로 흐름 → 필름 띠는 가로 스크롤 스냅 + 단추 + 방향키(붙박이는 쓰지 않음: 한 화면에 큰 움직임 하나)
- Codrops 스크롤 연동 입문(https://tympanus.net/codrops/2024/01/17/a-practical-introduction-to-scroll-driven-animations-with-css-scroll-and-view) → `animation-timeline: view()`는 @supports 안에서만, 꺼지면 완성된 정지 모습 → 선언문·여정 길·트랙 채움 모두 CSS 스크롤 연동, 지원하지 않으면 다 보임
- Chrome 스크롤 연동 사례(https://developer.chrome.com/blog/css-ui-ecommerce-sda) → 카드 등장은 transform·opacity만, 스크롤 끝나면 정지 → 본문 글자는 등장 뒤 정지, 반복은 장식만
- 편집 디자인(신문 단·책 차례·사전 두 단) → 차례·용어·FAQ는 "책의 부품"을 빌려 글이 많아도 구조가 다르게 보이게(책 차례 점선·사전 두 단·질문 색인)

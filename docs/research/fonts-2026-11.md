# 한국어 웹 글꼴 조사(2026-11)

- 조사일: 2026-11-10. 대상: 생성 사이트 글꼴 목록(`engine/src/design/fonts.js`), 글꼴 짝 25종(`seeds.js` `FONT_PAIRS`), 프리셋 12종(`presets.js`), 교재 글꼴 대체표(`fonts.js` `SAME`·`LIKE`), 편집 앱 UI 글꼴.
- 문제: 프리셋 12종의 본문이 모두 Pretendard이고 제목도 4종이 Pretendard다. 어떤 연수를 넣어도 같은 얼굴이 나온다.
- 확인 방법
  - 라이선스: 공식 사이트·저장소의 라이선스 파일을 먼저 봤고, 없으면 눈누(noonnu.cc)에 실린 라이선스 원문을 봤다. 눈누의 '라이선스 요약표'는 공식 문구와 다른 경우가 있어(아래 KoPub) 판단에 쓰지 않았다.
  - URL: 모두 설정된 프록시로 `curl -sS -o /dev/null -w '%{http_code} %{size_download}'`(TLS 검증 유지). CSS는 안에 적힌 글꼴 파일 하나까지 받아 200을 확인했다. 숫자는 받은 바이트(CSS는 압축 전 크기).
  - 글꼴 파일: fontTools로 한글 음절 수와 가운뎃점(·, U+00B7) 유무를 셌고, Pillow로 견본을 그려 교재 글꼴과 나란히 비교했다.

## 요약

1. **새로 넣을 글꼴 13종**: 페이퍼로지, 프리젠테이션, 에이투지체, 아스타 산스, LINE Seed Sans KR, 리디바탕, 나눔휴먼, Pretendard GOV, 케리스 케듀체, 학교안심 둥근미소, 학교안심 알림장, 엘리스 디지털배움체, Bagel Fat One. 모두 OFL 1.1 또는 같은 조건의 나눔글꼴 라이선스.
2. **지금 목록에서 고칠 곳 4곳**: 나눔스퀘어 네오가 3.0MB짜리 가변 woff를 받고 있다. 마루 부리·나눔스퀘어라운드는 같은 경로의 woff2로 바꾸면 절반이 된다. SUIT 가변은 624KB 한 파일인데 한글이 2,668자뿐이다.
3. **넣지 않을 글꼴**: KoPub World(웹 서버 탑재는 별도 승인), 에스코어드림·조선일보명조·넥슨(파일 수정 금지라 woff 변환본을 쓸 수 없음), 원스토어 모바일·머니그라피(재배포 금지). 교재에 나오면 비슷한 무료 글꼴로 바꾼다(§5).
4. **새 호스트는 필요 없다.** 추천 URL은 모두 지금 CSP가 허용하는 cdn.jsdelivr.net, fonts.googleapis.com/fonts.gstatic.com, hangeul.pstatic.net 안에 있다.
5. **프리셋 본문 Pretendard는 2곳만**: 종이 워크북(프롬프트·영문·복사 버튼이 많은 실습)과 공식 브리핑(정부 디자인 시스템 KRDS 지정 서체 Pretendard GOV).
6. **엔진에 필요한 작은 변경**
   - 글꼴 짝이 `FONTS` 키를 가리킬 수 있게. 지금 짝은 `css` 링크만 읽어서 `face` 방식 글꼴(에이투지체·나눔휴먼·케듀체 등)을 짝에 못 쓴다.
   - 교재 글꼴 이름을 모를 때 Pretendard로 덮지 않기. 지금은 `guessCategory`가 'sans'면 `CAT_DEFAULT.sans = 'pretendard'`가 되고 `system`이 아니라서 프리셋 본문을 Pretendard로 바꾼다(예: 'ONE Mobile'). 본문 자리에 제목 전용 글꼴이 오면 `BODY_SAFE`가 또 Pretendard로 바꾼다. 둘 다 "프리셋 글꼴 유지"가 낫다.
   - 프리셋에 `fontAlts`(이미 `chooseFonts`가 읽지만 어느 프리셋에도 없음)를 채워 주제·분위기에 따라 글꼴이 갈리게(§3-2).
   - `FONTS` 항목에 `variable: true`를 두고 `kinetic-weight` 효과를 가변 글꼴일 때만 고르게. 새 제목 글꼴 대부분은 정적 굵기다.

## 1. 호스트와 CSP

`render/pages.js`의 `cspMeta`:

| 지시어 | 허용 호스트 |
|---|---|
| `style-src` | `'self'` `'unsafe-inline'` fonts.googleapis.com, cdn.jsdelivr.net, hangeul.pstatic.net |
| `font-src` | `'self'` `data:` fonts.gstatic.com, cdn.jsdelivr.net, hangeul.pstatic.net |

- 이 문서의 추천은 모두 위 호스트 안에 있다. 호스트 표기: **jsd** = cdn.jsdelivr.net, **gf** = fonts.googleapis.com + fonts.gstatic.com, **nv** = hangeul.pstatic.net.
- 피할 것: 네이버의 나눔휴먼 CSS(`hangeul_static/css/NanumHuman.css`)는 안에서 **campaign-cdn.pstatic.net**의 파일을 부른다. CSP에 없는 호스트다. 같은 파일이 `hangeul_static/webfont/NanumHuman/`에도 있으니 `face`로 직접 쓴다.
- 공식 프리젠테이션·페이퍼로지 CSS(`gh/Freesentation/...`)는 커밋으로 고정해도 안에서 `@main` 주소를 부른다. 버전이 고정되지 않으니 상대 경로를 쓰는 ayaan-fonts 사본을 쓴다.
- jsDelivr 한도(직접 겪은 것)
  - gh 저장소가 50MB를 넘으면 `data.jsdelivr.com` 목록은 실패하지만 파일은 나온다(`ayaan-fonts/Paperlogy@1.001`). 목록이 되는 태그(`1.001-ko`)를 쓰는 편이 안전하다.
  - npm 패키지가 150MB를 넘으면 파일도 403이다(`npm/pretendard-gov@1.3.9`). Pretendard GOV는 gh 경로로 쓴다.
  - 파일 하나가 20MB를 넘으면 403(구글 폰트 저장소의 Noto Serif KR 가변 TTF). 실행 중에는 상관없다.
- 네이버 URL에는 버전이 없다. `architecture.md` §1은 "jsDelivr 버전 고정 URL만"이라고 하는데 CSP는 이미 구글 폰트와 네이버를 허용한다. 문서와 정책을 맞춰 둘 것. 구글 폰트 글꼴은 Fontsource 사본(jsDelivr, 버전 고정)이 다 있다.

## 6. 편집 앱 UI 글꼴

지금 `app/src/styles/app.css`는 제목 Jua, 라틴 Quicksand, 본문 Pretendard다. 둥근 두 글꼴이 장난감 같은 인상을 만든다. 둘 다 빼고 아래 중 하나로 제목·본문을 통일한다. Pretendard는 이미 설치돼 있으니 대체 글꼴로만 둔다.

| | 1안 Wanted Sans | 2안 IBM Plex Sans KR (+ Plex Mono) |
|---|---|---|
| npm | `wanted-sans@1.0.3` (`npm view` 1.0.3, OFL-1.1) | `@fontsource/ibm-plex-sans-kr@5.3.0`, `@fontsource/ibm-plex-mono@5.3.0` (`npm view` 둘 다 5.3.0, OFL-1.1) |
| Vite import | `@import 'wanted-sans/fonts/webfonts/variable/split/WantedSansVariable.css';` (family `Wanted Sans Variable`) | `@import '@fontsource/ibm-plex-sans-kr/400.css';` 500·600·700도 같은 꼴, `@import '@fontsource/ibm-plex-mono/400.css';` |
| 결 | 제품 화면용으로 만든 단단하고 또렷한 고딕. 400~1000 가변, unicode-range 분할 | 공학적인 네모꼴. JSON·코드·표가 많은 편집기에 맞고 Plex Mono와 한 가족 |
| 쓰는 법 | 제목 700~800, 본문 400~500 | 제목 600~700, 본문 400, 입력칸·코드 Plex Mono |
| 주의 | 생성 사이트 `glass-lab` 본문과 같다(앱과 결과물이 겹쳐 보일 수 있음) | 정적 7단계라 굵기마다 CSS를 따로 import |

추천은 1안. 편집 도구는 작은 글자(12~14px)가 많은데 원티드 산스가 그 크기에서 가장 덜 흐려진다. 표와 코드가 늘어나면 2안.

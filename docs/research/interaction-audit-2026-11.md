## 3. 실패·살핌 자세히

1. **두 번 눌러도 한 번만 — 실패.** 첫 화면 [교재 없이 시작하기]·[이 예시로 시작]을 빠르게 두 번 누르면 연수가 2개 생긴다(4번 모두). `newProject()`가 끝나 화면이 바뀌기 전까지 다시 누를 수 있다.
2. **보이지 않는 곳에 초점 — 실패(data-lab).** 디자인 효과 `guided-progress`가 진행 단계 목록(`nav.fx-gp-steps`, 링크 15개)을 `.lp-scrollbar` 안에 붙이는데, 이 막대는 `transform: scaleX(스크롤 비율)`이라 고정 위치 목록이 막대를 기준으로 그려지고 너비가 0으로 눌린다. 화면에는 안 보이고 Tab만 15번 거쳐 간다(맨 위에서 너비 0, 스크롤하면 찌그러져 보임).
3. **초점이 가려짐 — 실패(sel-story, data-lab은 스크롤 위치에 따라).** 아래 떠 있는 참여 단추 줄(`.lp-dock`, 높이 약 56px)이 Tab으로 간 [전체 보기]·[전체 화면]·체크 칸을 덮는다(캡처로 확인). 위쪽은 `scroll-padding-top: 84px`이 있는데 아래쪽 여백이 없다.
4. **화면 이동 CLS — 실패.** 도움말·설정처럼 늦게 불러오는 화면으로 갈 때 잠깐 "불러오는 중…" 한 줄만 남아 바닥글이 위로 258px 올라왔다가 다시 내려간다(0.08씩 두 번). 갤러리는 여기에 더해 디자인 카드가 예시 설계도를 읽은 뒤에야 그려져 아래 '효과 58가지' 칸이 화면 밖으로 밀린다(0.38).
5. **초점 표시 없음 — 실패(두 사이트).** 교재 보기 칸(`div.lp-deck-stage`, `tabindex`)이 `outline:none`이라 Tab으로 가도 보이지 않는다.
6. **대화상자 첫 초점 — 살핌.** 첫 화면 '연수 지우기' 창과 1단계 '다시 만들기' 창이 열리면 첫 단추(지우기·다시 만들기)에 초점이 간다. 목록에서 [지우기]를 Enter로 연 사람이 Enter를 한 번 더 누르면 바로 지워진다.
7. **누름 반응 — 흔들림.** 갤러리에서 첫 화면으로 돌아갈 때 CPU 4배 느리게 하면 4번 중 3번 100ms를 넘음(121·141·174ms, 한 번 86ms). 갤러리의 사이트 미리보기 iframe들이 50~150ms짜리 긴 작업을 잇달아 만든다(PerformanceObserver longtask로 확인). 다른 누름은 5~51ms.
8. **터치 44px — 살핌.** 앱: 머리 메뉴 링크 40px(터치용 규칙이 `height:40px`), 로고 34px, 바닥 링크 22px, 단계 표시 링크 너비 30px, 2단계 탭 42px, 미리보기 페이지 고르기 32px, 칸 순서 단추 32×40. 참가자 화면: 바닥 차례 링크·로고 26px, "교재 3쪽 보기" 28px, 문장 속 쪽 번호 링크 7×21, [전체 보기]·[전체 화면] 36px, 쪽 넘김 40px, 일정 링크 42px, 이해도 단추 너비 42px, 감정 체크 이름표 43px.
9. **휴대폰 입력 글자 — 살핌(data-lab).** 프롬프트 칸(`textarea.lp-prompt-text`) 15px. 읽기 전용이면 문제가 작지만 누르면 iOS가 확대한다.

검사 도구 오탐 점검: 처음 돌렸을 때 나온 것 중 4가지는 도구 탓이라 고쳤다 — 같은 이름 단추가 둘이면 한 바퀴 돈 줄 안 것, 바깥 칸에 그리는 초점 표시(`:has(a:focus-visible)`)를 못 본 것, 숨긴 라디오(이름표가 보이는 칸)를 '보이지 않는 초점'으로 본 것, 체크 칸을 이름표가 아닌 13px 네모로 잰 것. 지금 남은 실패 9개는 하나씩 화면·캡처·계산값으로 확인했고 오탐은 없다.

## 5. 검사를 어떻게 돌리나(CI 제안)

- 지금은 사람이 돌린다(1분 남짓). `vite preview`와 예시 사이트가 있어야 하고 헤드리스 Chromium이 필요하다.
- 4번 중 흔들린 두 항목(누름 반응 100ms, 독 가림)은 CPU·스크롤 위치에 따라 달라 CI의 실패 조건으로는 이르다. 위 1~6을 고친 뒤 흔들리지 않는 항목(초점 표시·보이지 않는 초점·대화상자·두 번 누르기·움직임 줄이기·24px·키보드 진행)만 `--only` 같은 묶음으로 CI에 넣는 것을 제안한다.

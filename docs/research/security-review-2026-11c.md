## 1. 위협 모델

| 지킬 것 | 누가·어떻게 노리나 | 들어오는 곳 |
|---|---|---|
| 관리자 키(강사 화면 권한, 명단·출석 CSV) | 같은 연수 참가자, 공용 PC 다음 사용자, 주소를 아는 바깥 사람(차례로 넣어 보기), 강사 화면을 틀에 넣는 다른 사이트 | 강사 화면 입력칸, 저장소(sessionStorage·localStorage), 서버 요청 머리글, 화면 공유·주소창 |
| 발표 화면(프로젝터, 모두가 봄) | 장난치는 참가자: 화면 덮기(긴 낱말·쌓인 결합 부호·방향 바꿈), 강사를 흉내 낸 별명, 피싱 주소를 '공식 안내'처럼 | 질문·보드 글·별명·투표 보기·낱말 투표 |

| 참가자 개인정보 | 바깥 사람·검색 엔진·CDN | 서버 저장, 검색 색인, 외부 요청 |

## 3. 고친 것(요약)

- **글 거르기 한 목록**: 제어 문자·C1·U+00AD·U+034F·U+061C·U+115F·U+1160·U+17B4·U+17B5·U+180B~180F·U+200B·U+200C·U+200E·U+200F·U+202A~202E·U+2060~2064·U+2066~206F·U+2800·U+3164·U+FE00~FE0E·U+FEFF·U+FFA0·U+FFF9~FFFB·U+E0000~E01EF. 결합 부호(U+0300~036F 등)는 둘까지. `core.js`·`protocol.js`(둘)·`Code.gs`·`schema.sql`이 같음(소스에 보이지 않는 글자를 그대로 두지 않고 `\u` 꼴로).
- **받을 때도 거름**: `_maskDoc`이 컬렉션 필드 길이·문자·투표 보기·파일 이름을 다시 정리 → 강사·발표·참가자 화면이 같은 값을 씀.
- **잠그기**: `X.locked(state, 'qa'|'board')`·`X.lockPatch()`. 참가자 화면은 칸을 막고 까닭을 보임.
- **속도 제한**: `CLIENT_RATE = { questions: [6, 1분, 3초], posts: [10, 1분, 2.5초], help: [4, 1분, 5초], chat: [20, 1분, 0.8초], answers: [40, 1분, 0.3초] }`(서버 `RATE`보다 조금 낮게). 넘으면 `rate_limited`와 "n초 뒤에".
- **관리자 키**: `useAdminKey()`(한 번만 물음), 틀리면 화면에서도 3번째부터 5·10·20…초(최대 60초) 기다림, 서버 429면 `Retry-After`만큼. 키는 이 탭(sessionStorage)에만, 기억하기면 localStorage. 발표 화면은 두 곳을 읽어 타이머를 강사 화면과 맞춤. 참가자 화면은 키를 읽지 않음.
- **CSP·헤더**: `render/shell.js` `cspPolicy(ctx, page)`·`liveOrigins(bp)`, `build.js` `_headers`.
- **암호**: `protect.js` `passwordAdvice`·`friendlyPassword`, 잠금 화면 CSP.

## 4. 확인했지만 문제없던 것

- **XSS**: 강사·발표·안내문·접속 확인 화면은 참가자 글을 모두 `textContent`로(정적 SVG 아이콘만 `innerHTML`). 브라우저 시험에서 `<img src=x onerror=…>` 질문이 세 화면 어디서도 실행·요소가 되지 않음. `jsonScript`가 `<`를 바꿈.
- **키가 남는 곳**: 주소(해시·검색 문자열)·DOM·로그에 없음(시험). Node 서버 요청 기록은 방법·경로·상태·시간만(머리글·검색 문자열 없음), Cloudflare는 500 오류 메시지만.
- **링크**: 강사가 덧붙인 자료 링크만 누를 수 있음(https만, `noopener noreferrer`). 참가자 글은 링크로 바뀌지 않음.
- **지난 검토(2차)에서 남은 것**: L4·L5·L6·I1·I2 모두 코드에 들어가 있음(markdown 자리 표시, `applyInfo` 주소 빼기, 짧은 주소 안내, 보이지 않는 글자 거절, 컨셉 출처) — 확인함.
- **AES-GCM 잠금**: PBKDF2-SHA256 60만 회, 쪽·파일마다 새 IV, 열쇠는 추출해 sessionStorage(기억하기면 localStorage)에만, 암호 원문은 저장하지 않음, `#k=`는 열자마자 주소에서 지움. 잠긴 쪽: index·console·screen·poster(접속 확인·개인정보는 그대로).

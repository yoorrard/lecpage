## 3. 빈틈과 결정

### 필수인데 없던 것 → 넣음
| 빈틈 | 결정 |
|---|---|
| 연수 목표·대상 | 새 칸 `goals`(목표 2~4개 + `who` 한 줄). 첫 화면 바로 아래, 메뉴에는 넣지 않음 |
| 온라인 입장 | `meta.joinUrl`이 있었지만 **어디에도 안 보였음** → 첫 화면 첫 버튼("Zoom 입장"·"Google Meet 입장"), 장소에 "온라인 (Zoom)". 새 필드 없음 |
| 이수 기준 | `meta.admin`(official·hours·completionRate)이 있었지만 참가자에게 안 보였음 → "3시간 · 출석 80% 이상 · 설문 제출"을 목표 칸(없으면 첫 화면)에, 출석·설문 칸에 "이수가 확인돼요" |
| 연수 후 | 새 칸 `followup`(다시 보기·소통방·다음 연수·더 읽을거리·이수 처리 일정, 종류는 주소로 자동) + **연수 후 보기**: 날짜가 지나면 '끝난 연수' 줄, followup을 첫 화면 아래로, 입장 버튼·참여 도크 숨김(`?phase=after`로 미리 보기) |
| 문의처 | `meta.contact` 한 줄 → 바닥글·연수 후 안내·개인정보 안내. 이메일·전화는 눌러서 연결 |

### 상황에 따라 → 기존 칸으로 해결
| 후보 | 결정 |
|---|---|
| 자주 막히는 곳 | 새 칸 없이 실습별 `note`. 초안이 교재의 "※", "주의:", "안 되면" 줄을 자동으로 넣음. 전체 문제는 faq·접속 진단 |
| 차시별 페이지 | 페이지를 나누지 않음. `sessions`에 날짜를 넣으면 마침·오늘·다음 자동 표시, 차시마다 앵커. 교재에 날짜가 여럿이면 초안이 차시를 채움 |
| 사전 지식 | `goals.who`에 함께("함수는 몰라도 돼요") |
| Q&A 아카이브 | 콘솔 질문 CSV → faq로 다시 빌드(운영 안내에 적음) |

### 넣지 않음
글자 크기 버튼(브라우저 확대로 충분, 확대를 막지 않음) · 인쇄 버튼(인쇄 CSS가 실습을 모두 펼침) · '오늘' 보기로 지난 일정 접기(흐리게 하는 것으로 충분) · 시간대(국내 연수) · '오늘 만들 것' 칸(목표·outcome·보드로 충분) · Wi-Fi·지도 칸(QR 안내문의 Wi-Fi 줄, hero.meta의 `url`) · 사이트 저작권 칸(자료·교재 `notice`, 보드 이용 조건).

### 구조
- **순서**: 첫 화면 → 목표 → 준비 → 본문 → 자료·연수 후 → 강사 → **설문 → 마무리**(설문을 마무리 뒤에 두면 놓침). 이야기형은 핵심 메시지 다음에 목표.
- **첫 화면**: 연수명이 제목(구호는 부제). 일시·장소(온라인 포함)·강사, 직무연수면 이수.
- **시기**: 같은 주소가 전·중·후를 맡음. 중에는 '지금' 줄(실시간), 후에는 '끝난 연수' 줄과 연수 후 안내가 위로.
- **꼬리표**: 실습 꼬리표는 짧은 우리말(시트·함수·차트 또는 준비·만들기). 번호와 겹치는 STEP 1을 쓰지 않음.

## 4. 문구 규칙(요약, 전체는 `skills/lecpage/references/copywriting.md`)
1. 해요체로 짧게(한 문장 70자 안). 버튼은 동작, 제목은 명사, 메뉴 2~4자.
2. 흔한 용어는 그대로(QR, URL, CSV, PDF, Wi-Fi, 로그인, 프롬프트). 괄호로 풀어 쓰지 않음.
3. 쓰지 않는 말: ~를 통해, ~할 수 있습니다, 함께 ~해 보아요, 알아볼까요, ~하는 시간을 가져요, 여정, 탐험, 핵심 포인트, 꿀팁, 과장 형용사, 느낌표 여럿, 이모지, 영어 대문자 라벨.
4. 제작 과정("원고의 ~")을 드러내지 않고, 알림·빈 화면은 다음 할 일까지.
- 목록은 `engine/src/prompt/copy-rules.js` 하나. AI 프롬프트(`bridge.js`)에 들어가고, `scripts/copy-lint.mjs`가 설계도·만든 사이트를 점검(고침=error, 살핌=warn).

## 5. 일반 AI 프롬프트보다 나은 까닭(skill이 주는 것)
- **빠뜨리지 않는 구조**: 유형별 칸 순서, 연수 전·중·후 보기, 온라인 입장·이수 기준·문의처가 설계도 값에서 자동으로 나옴. 사람이 매번 챙길 필요가 없음.
- **지어내지 않는 자동 채우기**: 목표·대상·문의처·막히는 곳·차시 날짜·참고 링크를 교재에서만 가져오고, 없으면 할 일 목록에 남김.
- **한국 연수 행정 기본값**: 이수 기준 문구, 출석 2회, 만족도 기본 5문항(사이트 안 수집 → CSV), 개인정보 최소 수집·파기 안내.
- **문구 품질의 기계 점검**: 같은 규칙이 생성 프롬프트와 lint에 함께 걸려, 일반 프롬프트에서 흔한 AI 말투를 빌드 전에 잡음.

# 그냥 AI 에이전트와 lecpage 견주기 — 2026-11

> 결론: 같은 교재·같은 요청으로 만들기부터 연수 뒤 CSV까지 했을 때, lecpage 앱은 AI를 내용 짤 때 한 번만 불러 **AI 비용이 약 1/127**이었고, 같은 기기 두 번째 연수부터 **공개·질문·투표 준비로 강사가 할 일이 0가지**였습니다(그냥 에이전트 12가지). 첫 화면 '재어 본 값'(`app/src/data/benchmark.json`)이 이 문서의 수치를 씁니다.

## 2. AI 토큰 <a id="tokens"></a>

| | 그냥 에이전트(전 과정) | lecpage 앱 |
|---|---:|---:|
| 입력 처리(캐시 아님 + 캐시 쓰기 + 캐시 읽기) | 약 2,630만 | 6,643 |
| 출력 | 219,941 | 약 6,000 |
| AI를 부른 횟수 | 단계마다(도구 호출 117번) | 만들 때 1번 |

- 그냥 에이전트: 작업 기록(JSONL)의 사용량을 단계별로 더함.
- lecpage 앱: AI에 보내는 요청(교재 요약 + 초안 + 규칙) 13,847자를 o200k_base 토크나이저로 셈 = 6,643토큰. 쓰던 챗봇 창으로 만들 때도 강사가 붙여 넣는 글이 같음. 답(설계도 JSON)은 흉내 답이라 직접 재지 못해, 다듬은 설계도에서 엔진이 채우는 칸을 뺀 13,573자를 같은 토크나이저로 센 약 6,000을 씀. 모델의 생각 토큰은 모델마다 달라 뺌.
- 디자인 바꾸기·공개·참여 기능·안내물·CSV(2~6단계)는 엔진이 해서 AI 0토큰.

# 운영비와 "멈추지 않기" 점검 (2026-11)

목표는 둘입니다. **사이트가 멈추지 않는 것**이 먼저이고, 그 안에서 운영비를 0에 가깝게 둡니다. 무료에 묶이지 않습니다.
확인한 날: 2026-11-12. 호스팅 수치는 [`hosting-2026-11.md`](hosting-2026-11.md). AI 모델·가격은 각 회사 공식 문서([OpenAI 가격](https://developers.openai.com/api/docs/pricing)·[모델](https://developers.openai.com/api/docs/models), [Google 가격](https://ai.google.dev/gemini-api/docs/pricing)·[한도](https://ai.google.dev/gemini-api/docs/rate-limits)·[키](https://ai.google.dev/gemini-api/docs/api-key), [Anthropic 모델](https://platform.claude.com/docs/en/about-claude/models/overview))를 읽고, OpenRouter 공개 목록과 codeitso(models.dev 2026-11-10)로 맞춰 봤습니다.

## 1. 누가 무엇을 내나

| 부분 | 어디서 도나 | 운영자 비용 | 사용자(강사) 비용 | 사용자가 늘면 |
|---|---|---|---|---|
| lecpage 앱 | 정적 파일(Cloudflare Workers 정적 자산 + GitHub Pages 미러). 교재 읽기·사이트 만들기·ZIP은 모두 브라우저 | 0 | 0 | 정적 요청은 무료·무제한이라 그대로 0 |
| AI | 강사의 키로 브라우저가 AI 회사를 직접 부름 | 0 | Gemini 무료 키 0원, 유료 키는 한 번에 10~1,100원(모델에 따라) | 운영자 몫 없음 |
| 만든 사이트(정적) | 강사 계정의 Vercel·GitHub Pages·Cloudflare | 0 | 0 | 계정마다 한도가 따로라 서로 영향 없음 |
| 참여 기능 | 강사 계정의 구글 시트·Supabase·Cloudflare | 0 | 0(큰 행사는 Cloudflare 월 $5) | 계정마다 따로 |
| 올린 자료 파일 | 사이트 안의 정적 파일 | 0 | 0 | 위와 같음 |
| 바로 공개(선택) | 운영자의 Cloudflare Worker + Durable Objects | **0 또는 월 $5** | 0 | 여기만 운영자 한도를 함께 씀 → §3 |
| skill | 사용자의 AI 도구 안 | 0 | 그 도구의 구독 | 운영자 몫 없음 |

운영자에게 비용이 생길 수 있는 곳은 **바로 공개 서버 하나**입니다. 켜지 않으면 전체가 0원이고, 모든 기능이 그대로 됩니다.

## 2. 멈출 수 있는 곳과 막는 방법

| 어디 | 무료 한도를 넘으면 | 이렇게 막았습니다 |
|---|---|---|
| Vercel(강사 계정) | 월 100GB 전송. 넘으면 멈춤 | 보통 연수는 1~3GB. 사이트 크기 × 인원으로 어림해 한도의 절반을 넘으면 Cloudflare·GitHub Pages를 먼저 권함(`decideHost`). 공개 화면에 한 줄로 알림 |
| GitHub Pages | 월 100GB는 권고 | 넘어도 바로 멈추지 않음 |
| Cloudflare(정적) | 한도 없음 | — |
| Netlify | 월 300크레딧. 다 쓰면 그달 멈춤 | 맨 뒤 순서, 한 줄 안내 |
| 구글 시트 | 동시 실행 30 | 멈추지 않고 늦어짐. 50명까지만 권함 |
| Supabase | 7일 안 쓰면 일시정지 | 항상 경고하고, 연수 전날 접속 확인(check.html)으로 깨우게 안내. skill은 강사가 할 일이 가장 적은 Cloudflare 중계를 먼저 권함(가입·로그인 2번, 멈춤 없음, `decideInfra` L08b·`TEACHER_STEPS`) |
| Cloudflare(참여 기능, 강사 계정) | 하루 10만 요청. 넘으면 그날 멈춤 | 웹소켓이 막힌 망 + 60명 초과면 유료(월 $5)를 켜 두라고 경고 |
| 바로 공개(운영자) | 무료 요금제는 하루 10만 요청. 넘으면 **올라온 사이트가 모두** 그날 멈춤 | §3 |
| AI 무료 키 | 분당·하루 횟수 | 기다렸다 다시 → 같은 등급의 다른 모델 → 연결해 둔 다른 무료 AI 순으로 앱이 이어감. 유료 연결·가벼운 모델로 넘어가기 전에는 물어봄 |
| 참여 기능 서버가 끊김 | — | 사이트 본문·자료는 정적이라 그대로 열림. 참가자 글은 기기에 쌓아 두었다가 다시 이어지면 보냄(`live/core.js`) |

강사가 고르는 것: [설정]의 **무료 한도를 넘으면 → 멈추기 / 유료로 이어가기**. '멈추기'(기본)는 돈이 드는 연결로 넘어가지 않고 그때 묻습니다.

## 3. 바로 공개 서버: 요금제를 고릅니다

방문 한 번이 Worker 요청 하나라서, 무료 요금제에서는 하루 10만 요청을 모든 사이트가 나눠 씁니다. 40명 연수 한 번이 2천~1만 2천 요청이니 하루 8~40회가 한계이고, 넘으면 그날 모든 사이트가 멈춥니다. 강사에게 가장 나쁜 일이라 다음처럼 했습니다.

- `PLAN=free`(기본): 무료 안에서만 돕니다. 하루 예산의 60%를 쓰면 새 사이트·새 방을 받지 않아 남은 몫을 이미 올라온 사이트에 씁니다. 앱은 바로 공개를 첫째로 권하지 않고 "본 연수는 내 계정에"라고 알립니다.
- `PLAN=paid`: Workers Paid(월 $5 정액). 하루 한도가 없습니다. 월 1,000만 요청이 포함되고(40명 연수 1,000번쯤), 넘으면 100만 요청당 $0.30입니다. 저장은 5GB 뒤 GB당 월 $0.20. **여러 강사에게 열어 둘 거라면 이쪽을 권합니다.**
- 공통: 방문이 있는 사이트는 지우지 않습니다(30일 동안 방문이 없을 때만 정리, 처음 만든 날부터 1년까지). 쓰이지 않는 사이트가 저장 공간을 차지하지 않게 하는 것이 곧 비용 절감입니다.
- 자리가 찼거나 서버에 닿지 않으면 앱이 그 선택지를 접고 내 계정에 올리는 길로 안내합니다.

비용을 더 줄일 수 있는 방법(아직 만들지 않음, 실제 계정으로 확인이 필요해서 보류):

1. **공통 실행 파일을 정적 자산으로**: 모든 사이트가 같은 엔진 파일(CSS·JS)을 씁니다. Worker의 정적 자산(요청 수에 안 들어감)에서 내보내면 방문당 요청이 절반 아래로 줄어듭니다.
2. **파일 주소에 내용 해시를 붙여 오래 캐시**: 지금은 10분. 다시 여는 방문의 요청이 없어집니다.
3. **Cloudflare Pages 미리보기 배포나 R2 + 캐시에 사이트 파일을 둠**: 방문이 Worker를 거치지 않아 사실상 무제한이지만, 신고·가리기와 CSP를 다시 설계해야 하고 R2는 카드 등록이 필요합니다.

## 4. 서버 없는 실시간(P2P)은 넣지 않았습니다

WebRTC(Trystero 등)로 강사 브라우저가 방 역할을 하면 서버가 0이 됩니다. 하지만 공개 중계 서버(Nostr·WebTorrent·MQTT)가 이 작업 환경에서 닿지 않아 **확인하지 못했고**, 학교망은 P2P 연결을 자주 막으며(TURN 중계가 있어야 하고 그것은 유료), 강사 탭이 닫히면 방이 사라집니다. "멈추지 않기"에 맞지 않아 보류했습니다.

## 5. AI 모델 추천을 정하는 방법

모델 이름은 몇 달마다 바뀝니다(2026-11: OpenAI GPT-6.1 Sol·Terra, GPT-6 Astra·Luna / Gemini 4 Carbon·Argon, 3.8 Flash / Claude Opus 5.5·Sonnet 5.5·Haiku 5.5·Fable 5.2). 이름으로 고르는 규칙은 금방 틀리므로, 앱이 **OpenRouter 공개 목록의 가격과 출시일**을 읽어 등급을 매깁니다(키 없이 읽히고 운영자 서버를 거치지 않음. 못 읽으면 이름으로 어림).

- 등급(출력 100만 토큰 값): 최상위 $30~ · 고품질 $8~ · 표준 $3~ · 가벼움 그 아래
- 추천: 고품질 등급에서 가장 새 모델. 나온 지 2주가 안 된 모델은 뒤로. Claude는 Opus
- 지금 값으로는 OpenAI `gpt-6.1-sol`(약 220원), Claude `claude-opus-5-5`(약 450원), Gemini 유료 키 `gemini-4-argon`, Gemini 무료 키 `gemini-3.8-flash`
- 공식 문서의 말과 맞습니다.
  - OpenAI: "지능과 비용의 균형은 GPT-6.1 Sol, 가장 어려운 일은 GPT-6 Astra(값 5배), 대량·저비용은 GPT-6 Luna". GPT-6.1 Sol은 `v1/chat/completions`를 지원하고 무료 등급에서는 쓸 수 없습니다(크레딧 충전 필요).
  - Anthropic: "어느 모델을 쓸지 모르겠으면 Claude Opus 5.5".
  - Google: Gemini 4 Carbon·Argon은 **무료 등급에서 쓸 수 없고**, 3.8 Flash·3.6 Flash·3.5 Flash-Lite는 무료입니다. 그래서 무료 키는 처음 한 번 Gemini 4가 거절되면 3.8 Flash로 내려가 그 모델을 기억합니다. Gemini 4는 2026-12-01부터 $4 / $20으로 오릅니다(지금 $2 / $10). 값은 실시간으로 읽으므로 앱의 어림 값도 따라 바뀝니다.
  - Google 한도는 키가 아니라 프로젝트 단위이고, 하루 한도는 태평양 시간 자정(한국 시간 오후 5시쯤, 미국 서머타임 기간에는 오후 4시쯤)에 다시 채워집니다. 새 계정은 약관에 동의하면 프로젝트와 키가 자동으로 만들어집니다(앱의 키 안내에 반영).
- 가벼운 모델(Luna·Haiku·Flash-Lite)은 한 번에 10원쯤이지만 연수 흐름과 문구가 단순해져 추천하지 않습니다. 고를 수는 있습니다.

codeitso MCP(`codeitso_find_models`)는 이 규칙을 점검할 때 썼습니다. 앱이 실행 중에 부르게 하지는 않았습니다. 모든 사용자의 요청이 운영자 Worker를 거치면 위 §1의 원칙(운영자 몫 없음)에 어긋나기 때문입니다.

## 6. 확인한 것과 못 한 것

- 확인: 예산 60%에서 새 사이트만 멈추고 올라온 사이트는 열림, `PLAN=paid`에서는 막지 않음, 방문 시 기간 연장(로컬 workerd 통합 테스트). 앱에서 공개 → 참가자 질문 → 강사 화면 → 다시 올리기(무료·유료 설정 둘 다). AI 한도 넘김·유료 이어가기·모델 추천(가짜 응답, 실제 2026-11 모델 목록).
- 못 함: 실제 Cloudflare 계정 배포와 과금, 실제 AI 키 호출(Claude의 `fallbacks` 값은 안 받는 환경이면 기본 요청으로 다시 보내게 해 둠). 공식 문서는 읽기만 했고 실제 키로 부른 것은 아닙니다.

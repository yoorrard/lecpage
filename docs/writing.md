# lecpage 문구 기준

앱 화면(교재 넣기·고치기·공개하기)과 lecpage가 만드는 연수 사이트(참가자 화면·강사 화면·발표 화면)의 글에 같이 씁니다.
AI가 연수 사이트 문구를 쓸 때 보는 짧은 판은 [`skills/lecpage/references/copywriting.md`](../skills/lecpage/references/copywriting.md), 검사는 `engine/src/prompt/copy-rules.js` 한 곳에 있습니다.

```bash
node app/scripts/copy-lint.mjs            # 앱 화면 글 + 엔진 고정 문구(고침·살핌 목록)
node app/scripts/copy-lint.mjs --report   # 규칙별 건수·심한 것·용어 불일치·화면별 글 양(표)
node app/scripts/copy-lint.mjs --json     # [{ file, line, kind, text, rule, level, hit, fix, fixed }]
node skills/lecpage/scripts/copy-lint.mjs work/blueprint.json   # AI·초안이 쓴 설계도
```
**고침**은 고칩니다. **살핌**은 아래 예외에 들면 그대로 둡니다. 그대로 둘 줄은 그 줄이나 윗줄에 `// copy-ok: 까닭`을 적습니다.

읽는 사람은 연수 중인 교사입니다. 휴대폰을 들고 서서, 실습하다 곁눈으로 읽습니다. 강사는 연수 직전에 급하게 만듭니다.

## 1. 원칙

1. **해요체 하나로.** 모든 화면 글은 해요체("~해요", "~해 주세요"). 합니다체·하십시오체를 섞지 않는다.
2. **할 일과 결과를 먼저, 짧게.** 한 문장에 한 가지, 70자 안. 화면에 이미 있는 말, 안 읽어도 되는 말(잡초)은 뺀다. 빈자리를 채우려고 쓰지 않는다.
3. **능동으로.** 누가 했는지 분명하게: "저장되었습니다" → "저장했어요". 이중 피동("되어지다", "보여지다")은 쓰지 않는다.
4. **긍정 먼저, 다음 할 일까지.** 안 되는 것보다 되는 조건을 먼저: "암호가 없으면 볼 수 없어요" → "암호를 넣으면 볼 수 있어요". 오류는 *무슨 일인지 + 다음에 할 일*. 사과로 때우지 않는다.
5. **높임은 가볍게.** "~하시겠어요?" → "~할까요?", "계신가요" → "있나요", "여쭤봐요" → "물어봐요".
6. **정해진 말은 그대로, 나머지는 쉽게.** 교육 행정 용어(직무연수, 이수 기준, 출석 확인, 차시)와 흔한 외래어·약어(QR, URL, PDF, AI, 프롬프트)는 풀지 않는다. 풀어쓰기는 *문장 속 명사 덩어리*에만 한다("설정 변경 완료" → "설정을 바꿨어요").
7. **사람이 쓴 것처럼, 사실만.** 꾸밈말·감탄·홍보 문구·이모지로 분위기를 띄우지 않는다. 같은 것은 늘 같은 이름으로 부른다(4절).

### 예외: 이럴 때는 원칙을 거스른다

| 원칙 | 거슬러도 되는 때 | 예 |
|---|---|---|
| 해요체 | 개인정보 처리방침·이용약관(법적 문서), 내려받는 문서(운영 안내·디자인 규칙), 교재 인용, 강사 자기소개, 핵심 메시지·맺음말처럼 한 문장 명제, 참가자가 직접 하는 동의 문장 | "안녕하세요, 유영재입니다." · "숫자는 학생을 대신하지 않습니다." · "…지우는 데 동의합니다." |
| 능동 | 끝남·만료·연결 끊김처럼 **상태**를 알릴 때, 시스템이 늘 하는 일을 설명할 때, 결과가 사용자 행동에서 왔다고 알릴 때, 안심시킬 때 | "공개 기간이 끝났어요." · "이 브라우저에 자동으로 저장돼요." · "연결이 끊겼어요." |
| 긍정 먼저 | 정책상 아예 안 될 때(이유 함께), 일부 기능만 안 될 때, 개인정보 안심 문구, 되돌릴 수 없는 결과 | "만 14세 미만은 이름을 받지 않아요." · "교재는 운영자 서버로 보내지 않아요." · "지운 뒤에는 되돌릴 수 없어요." |
| 가벼운 높임 | 설문처럼 선의를 구할 때, 참가자 상황을 짐작해 물을 때 | "연수가 도움이 되셨나요?" · "처음 오셨나요?" |
| 명사 풀기 | 제목·메뉴·단추·이름표·상태 표시·범례, 그리고 **정해진 용어** | "만족도 조사" · "답변 완료" · "출석 확인" |

판단이 서지 않으면: 소리 내어 읽어 강사가 옆 사람에게 하는 말처럼 들리면 통과.

## 2. 화면 자리별 규칙

| 자리 | 규칙 | 좋은 예 |
|---|---|---|
| 단추 | 누르면 일어나는 일을 동사로, 2~8자(최대 14자). "확인·예·진행"처럼 뜻이 흐린 이름 금지. 창만 닫으면 "닫기", **하던 일을 멈출 때만** "취소"·"멈추기". 새 창·외부 사이트로 가면 이름에 곳을 쓴다 | 지우기 · 설문 열기 · 공개하기 · Vercel 열기 |
| 메뉴·탭 | 명사 2~4자(최대 5자) | 내용 · 디자인 · 실습 · 질문 |
| 제목 | 명사나 한 줄(34자 안). 부탁은 제목이 아니라 단추가 한다. 마침표 없음 | 만족도 조사 · 연수 정보 |
| 한 줄 설명 | 제목 밑 한 문장. 제목을 되풀이하지 않고 *왜·무엇이 생기는지* | "PPT·PDF·한글(HWPX)·워드 파일을 이 브라우저 안에서 읽어요." |
| 이름표·도움말 | 이름표는 명사(20자 안), 조건은 괄호: "연수명 (필수)". 도움말은 칸 아래 한 문장, 툴팁은 마지막 수단 | "구성·분위기·색·대상처럼 바라는 점을 적으면 AI가 반영해요." |
| 자리표시(placeholder) | "예:"로 시작하는 실제 값. 설명을 넣지 않는다(입력하면 사라짐) | "예: 3모둠, 창가 두 번째" |
| 빈 화면 | 지금 상태 + 첫 할 일 | "아직 만든 연수가 없어요. 위에 교재 파일을 놓아 시작해 보세요." |
| 오류 | **무슨 일인지 + 다음 할 일**. 원인을 알면 원인을, 고칠 곳이 있으면 그 칸 옆에. 사과·"알 수 없는 오류"·코드만 보여 주기 금지(원래 오류 문구는 접어서) | "저장하지 못했어요. 저장 공간을 확인해 주세요." |
| 확인 창 | 제목은 질문("○○를 지울까요?"), 본문은 *무엇이 바뀌고 무엇이 남는지*, 단추는 동작 이름 + "닫기". 되돌릴 수 있으면 확인 창 대신 되돌리기([interaction.md](interaction.md) 4절) | 지울까요? → [지우기] [닫기] |
| 알림(토스트) | 한두 문장, 50자 안, 한 일의 결과를 과거형으로. 느낌표 없음. 실패 알림은 다음 할 일까지 | "공개했어요." · "복사했어요. 챗봇에 붙여 넣으세요." |
| 진행 중 | "~하는 중…"(줄임표 한 글자) + 1초 넘으면 무엇을 하는지, 10초 넘으면 얼마나 남았는지 | "슬라이드 그림 만드는 중 12/40" |
| 동의 | 무엇을, 왜, 얼마나 보관하는지 한 문장씩. 동의 단추·칸에 동의한다는 사실을 쓴다. 동의하지 않아도 되는 것은 그렇게 말한다 | "동의하지 않아도 안내와 교재는 그대로 볼 수 있어요." |
| 개인정보 | 어디로 가는지 실제 이름으로(“AI 회사” 말고 "Google"). 보내기 직전 화면에 한 줄 | "만들 때 교재의 글이 Claude로 가요." |
| 비용 | 돈이 드는 단추·선택지는 이름에 **유료**·금액을 쓴다. 무료 한도·만료를 미리 알린다 | 유료로 이어서 하기 · 크레딧 충전하기 |

강의 페이지(참가자 화면)는 AI가 쓰는 문구가 더 많습니다. 칸별 길이와 금지 표현은 `copywriting.md`가 기준입니다.

## 3. 쓰지 않는 표현

| 쓰지 않는 말 | 대신 | 검사 |
|---|---|---|
| ~를 통해, ~로 인해, ~함에 있어, ~를 진행하다, 필요로 하다 | ~로, ~해서, ~할 때, ~해요 | trans |
| 금일·익일·필히·기재·송부·수령·요망, "입력 시" | 오늘·다음 날·꼭·적기·보내기·받기, "입력하면" | trans |
| ~할 수 있습니다, ~합니다, ~하십시오 | ~할 수 있어요, ~해요, ~하세요 | formal |
| ~하시겠어요?, ~하시기 바랍니다, 여쭤봐요, 고객님 | ~할까요?, ~해 주세요, 물어봐요 | honor |
| 저장되었습니다, 되어요, 보여지다 | 저장했어요, 돼요, 보여요 | passive |
| 설정 변경 완료, 업로드 실패(알림·오류에서) | 설정을 바꿨어요, 올리지 못했어요 | noun |
| 오류가 발생했습니다, 알 수 없는 오류, 잘못된 요청 | 무엇이 안 됐는지 + 할 일 | error |
| 죄송합니다, 불편을 드려 | (뺀다) 할 일을 쓴다 | error |
| 함께 ~해 보아요, 알아볼까요, ~하는 시간을 가져요 | ~해 보세요, ~해요 | ai |
| 여정·탐험·핵심 포인트·꿀팁·인사이트 | 과정·살펴보기·핵심·팁 | ai |
| 혁신적인·놀라운·완벽한·지금 바로·손쉽게·누구나 쉽게 | (뺀다) 무엇이 되는지 사실로 | ai |
| 다양한·효과적으로·여러분·활용하여 | 이름을 대거나 뺀다 | ai·trans |
| 느낌표, 이모지 장식, `...`, 영어 대문자 장식(DATE·SPEAKER) | 마침표, (뺀다), `…`, 우리말 | mark·deco |
| 을(를)·이(가) 같은 조사 병기 | 받침에 맞는 조사, 또는 "뺐어요: 파일.pdf" | mark |
| QR 코드(Quick Response Code), URL(인터넷 주소) | QR, URL | plain |

## 4. 용어집

### 그대로 쓰는 말(풀지 않음)
- **교육 행정**: 직무연수, 자율연수, 원격연수, 집합연수, 특수분야 직무연수, 교육청 승인, 이수, 이수 기준, 이수 시간, 이수증, 이수자 명단, 출석 확인, 출석부, 차시, 연수 시간·기간·장소·대상·목표, 만족도 조사, 사전 설문, 개인정보 처리방침, 수집·이용 동의, 보유 기간.
- **흔한 외래어·약어**: QR, URL, PDF, CSV, PPT, HWP, AI, API 키, 프롬프트, 로그인, 링크, 앱, Wi-Fi, Zoom, 크롬북.
- **lecpage 화면 이름**: 참가자 화면, 강사 화면, 발표 화면, 참여 기능, 도움 요청, 진행 현황, 나눔 보드, 접속 확인, 공개 범위, 관리자 키, 자동 저장, 바로 공개, 짧은 주소, 수정 요청.
- **다른 서비스 화면의 글자**: Apps Script의 "배포", Vercel의 "Deploy", Supabase의 "Project Settings"는 그 화면에 보이는 대로(번역하면 못 찾는다).

새 정해진 용어는 `copy-rules.js`의 `FIXED_TERMS`에 더한다(명사 나열·공문투 검사에서 한 낱말로 본다).

### 한 가지로 부르는 말
지금 코드에서 같은 것을 두 이름으로 부르는 곳(2026-11, `copy-lint --report`). 검사는 `TERM_RULES`.

| 쓰는 말 | 쓰지 않는 말 | 지금 섞인 곳 | 비고 |
|---|---|---:|---|
| 연수(만든 것) · 저장한 파일(.lecpage) | 프로젝트, 프로젝트 파일 | 앱 10 | 단추가 이미 "파일로 저장"·"저장한 파일 열기". 다른 서비스의 프로젝트는 그대로 |
| 참여 기능 | 실시간 기능, 실시간 연결 | 엔진 8 | 질문·도움 요청·진행 현황·투표·나눔 보드·출석을 묶은 이름(앱 30곳이 이미 이렇게 씀). 서버는 "실시간 서버", 상태는 "연결됨" |
| 단추 | 버튼 | 5 | 앱 21곳이 "단추" |
| 공개(하기) · 올리기 | 배포 | 앱 5 | 다른 서비스 화면의 "배포"는 그대로 |
| QR | QR 코드 | 4 | 화면 읽기 프로그램용 이름표(aria-label)는 "QR 코드"도 됨 |
| 만족도 조사(섹션) · 설문(문항·응답) | 만족도 설문 | 3 | |
| 참가자 | 참여자, 수강생, 연수생 | 강사 화면 3 | 참가자 63곳 |
| 그림 | 이미지 | 2 | 찍은 것은 "사진" |
| 추가(단추) · 넣기(교재·파일) | 더하기(단추) | 2 | 문장 속 "더하다"는 그대로 |
| 지우기 | 삭제 | 1 | 법률 문서의 "삭제·파기"는 그대로 |
| 미리보기 | 미리 보기 | 1 | |
| 누르기 | 클릭, 터치 | 0 | 휴대폰에서도 맞는 말 |
| 내려받기 · 받기 | 다운로드 | 0 | 단추는 "자료 받기", 문장은 "내려받아요" |
| 연수 코드 | 입장·참여·접속 코드 | 0 | |
| 휴대폰 · 오류 · 새로 고침 · 별명 | 스마트폰·핸드폰·모바일 · 에러 · 새로고침 · 닉네임 | 0 | 다시 생기지 않게 검사만 |

섞어 써도 되는 짝: **주소**(사이트 주소)와 **URL**(다른 서비스 화면이 URL이라 부를 때), **이메일**(이름표)과 **메일**("메일 인증" 같은 합성어), **연수 사이트**와 **사이트**(앞에서 한 번 말한 뒤).

### 화면 글 속 이름 표기
- 누를 단추·메뉴 이름은 대괄호: "[되돌리기]를 누르면 돌아가요."(지금 22곳). 탭·칸 이름도 같게.
- 다른 서비스 화면의 영어 글자는 그대로: "Project Settings → API Keys".

## 5. 길이·숫자·문장부호

| 항목 | 기준 |
|---|---|
| 길이(검사 한도) | 메뉴 5자 · 단추 14자(목표 2~8자) · 이름표 20자 · 제목 34자 · 알림 50자 · 문장 70자 |
| 숫자 | 아라비아 숫자, 단위는 붙여: 30명, 3시간, 5분, 100MB, 34쪽, 80% |
| 범위 | 물결표, 띄우지 않음: 1~2분, 15:10~16:40, 31~100명 |
| 날짜·시간 | 2026. 11. 4.(수) · 24시간제 15:10 · 상대 시간은 1분 전·어제 |
| 마침표 | 문장(알림·오류·도움말 포함)은 찍고, 단추·메뉴·제목·이름표는 안 찍는다 |
| 물음표 | 확인 창 제목과 설문 문항에만 |
| 느낌표 | 쓰지 않는다 |
| 줄임표 | `…` 한 글자. 진행 중("불러오는 중…")과 뒤에 입력이 더 있는 메뉴("이름 바꾸기…")에만 |

## 7. 다크 패턴 금지(비용·유료 전환·동의·삭제)

강사와 참가자가 lecpage를 믿고 쓰게 하는 최소 기준입니다. 어기면 고침 대상입니다.

1. **무료·유료를 숨기지 않는다.** 돈이 드는 선택지는 단추 이름에 "유료"·금액을 쓰고, 무료 한도·만료(예: 바로 공개 기간, Supabase 무료 프로젝트 7일 멈춤)를 고르기 전에 알린다. 무료로 할 수 있는 길이 있으면 함께 보인다.
2. **유료 전환은 사용자가 고른다.** 무료 한도에 걸렸을 때 저절로 유료 모델·유료 키로 넘기지 않는다. "유료로 이어서 하기"는 이번 한 번만.
3. **거절 단추를 죄책감으로 쓰지 않는다.** "아니요, 더 좋은 사이트는 필요 없어요" 같은 말 금지. 중립으로 "닫기"·"나중에"·"건너뛰기".
4. **나갈 길을 늘 둔다.** 닫기·뒤로 가기·건너뛰기를 숨기거나 흐리게(꺼진 것처럼) 만들지 않는다. 들어오자마자 화면을 가로막는 창, 뒤로 가기를 가로채는 창을 띄우지 않는다.
5. **동의는 기본 꺼짐, 고른 것만.** 미리 체크하지 않는다. 동의하지 않아도 쓸 수 있는 부분을 말한다. 동의 문장 하나에 다른 동의를 끼워 넣지 않는다.
6. **보내기 전에 어디로 가는지.** 교재·학생 정보가 바깥(AI 회사·호스팅·실시간 서버)으로 가는 순간 바로 앞에 실제 이름을 쓴다.
7. **지우기는 무엇이 지워지고 무엇이 남는지.** "이 브라우저의 교재·그림이 지워져요. 이미 올린 사이트는 그대로예요." 되돌릴 수 없으면 그렇게 쓴다.
8. **단추로 다음을 짐작할 수 있게.** 혜택만 되풀이하는 단추 금지. 결제 화면·외부 사이트·새 창으로 가면 이름에 그 곳을 쓴다("결제 페이지 열기").
9. **거짓 급함 금지.** "지금 바로", "오늘만", 남은 수량·시간 압박을 쓰지 않는다.

# lecpage 개인정보 처리방침

시행일: 2026-11-11

lecpage 운영자(이하 '운영자')가 lecpage 웹앱(https://yoorrard.github.io/lecpage/)에 적용하는 방침이에요. 웹앱은 회원가입이 없어요. 교재와 프로젝트는 쓰는 분의 브라우저 안에서만 처리되고 운영자 서버로 보내지 않아요. Agent Skill은 쓰는 분의 컴퓨터와 AI 도구 안에서 돌아가고 운영자에게 아무것도 보내지 않아요.

| | |
|---|---|
| 운영자가 받는 것 | 이메일로 문의하신 경우의 이메일 주소와 문의 내용 |
| 운영자가 받지 않는 것 | 교재, 프로젝트, AI 키, 배포 토큰, AI에 보낸 내용, 만든 사이트의 참가자 정보 |
| 예외 | '바로 공개'로 직접 올린 사이트 파일(9번, 기능이 켜져 있을 때만) |
| 쿠키·분석 도구·광고 | 쓰지 않음 |

웹앱에 'lecpage 주소로 바로 공개' 기능이 켜져 있으면 [9. 바로 공개 기능을 쓸 때](#9-바로-공개-기능을-쓸-때)가 함께 적용돼요. 그 기능이 없는 동안에는 9번과 '예외' 줄은 해당 없어요.

## 1. 운영자가 처리하는 개인정보

| 언제 | 항목 | 목적 | 보유 기간 |
|---|---|---|---|
| 이메일로 문의·요청할 때 | 이메일 주소, 문의 내용, 메일에 적은 이름 | 문의 답변, 권리 요청 처리 | 답변을 마친 날부터 1년(운영자가 정한 값), 그 뒤 삭제 |

- 문의하신 분의 요청을 처리하는 데 필요한 정보라 따로 동의를 받지 않아요(개인정보 보호법 제15조제1항제4호).
- 주민등록번호 같은 고유식별정보와 민감정보는 받지 않아요. 메일에 적지 말아 주세요.
- GitHub 이슈는 누구나 보는 공개 게시판이에요. 글과 GitHub 계정 이름이 공개되고, GitHub의 개인정보 처리방침이 적용돼요.

## 2. 이 브라우저 안에서만 처리되는 정보

아래 정보는 운영자에게 오지 않아요. 바로 공개로 직접 올린 사이트 파일만 예외예요(9번).

| 정보 | 저장 위치 |
|---|---|
| 교재, 프로젝트, 만든 사이트 파일 | 브라우저 저장소(IndexedDB) |
| AI 키, 배포 토큰 | '이 기기에서 기억하기'(처음에 켜져 있음)를 켠 것은 암호화해 IndexedDB에 저장. 끄면 열어 둔 탭에만 있음 |
| 화면 설정(밝게·어둡게 등) | localStorage |
| 오프라인용 앱 파일 | 서비스 워커 캐시 |

- 지우는 방법: 웹앱 **설정 > 이 브라우저의 데이터 모두 지우기**, 또는 브라우저의 사이트 데이터 삭제.
- 운영자는 이 정보를 가지고 있지 않아서 대신 보거나 지워 드릴 수 없어요.
- 함께 쓰는 컴퓨터에서는 '이 기기에서 기억하기'를 끄고, 끝나면 데이터를 지워 주세요.

## 3. 쓰는 분이 고른 곳으로 브라우저가 직접 보내는 정보

운영자를 거치지 않고 브라우저에서 그 회사로 바로 가요. 운영자가 가진 적이 없는 정보라 운영자의 제3자 제공·처리 위탁·국외 이전에 해당하지 않고, 각 회사의 약관과 개인정보 처리방침이 적용돼요.

| 언제 | 받는 곳 | 보내는 것 |
|---|---|---|
| AI를 쓸 때 | Google(Gemini), OpenRouter, OpenAI, Anthropic 중 고른 곳(국외) | 교재에서 뽑은 글과 그림, 연수 정보, 수정 요청 내용, 내 AI 키 |
| 사이트를 올릴 때 | Vercel, GitHub, Netlify 중 고른 곳(국외) | 만든 사이트 파일, 내 배포 토큰 |
| 참여 기능을 연결할 때 | 내가 만든 Google Apps Script, Supabase, Cloudflare, 자체 서버 | 연결 확인 요청, 연수 설정 |
| 디자인을 미리 볼 때 | jsDelivr, Google Fonts, 네이버 글꼴 서버 | 글꼴·효과 파일 요청(IP 주소 등 접속 정보) |

- **AI 학습에 쓰이는지**는 회사·요금제·계정 설정마다 달라요. 예를 들어 Gemini API 무료 등급은 입력 내용을 서비스 개선에 쓰고 사람이 검토할 수 있다고 약관에 적혀 있어요. 운영자는 입력 내용을 받지 않고 AI 학습에도 쓰지 않아요.
- 교재에 다른 사람의 개인정보(학생 이름·사진, 연락처 등)가 있으면 AI에 보내기 전에 지워 주세요.

## 4. 접속 기록

웹앱 파일은 GitHub Pages(GitHub, Inc., 미국)가 보내 줘요. GitHub은 보안을 위해 방문자의 IP 주소를 기록·보관한다고 [밝히고 있어요](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection). 운영자는 이 기록을 받지 않고 볼 수도 없어요. 호스팅 회사를 바꾸면 이 방침을 먼저 고쳐서 알려요.

## 5. 쿠키 등 자동 수집 장치

쿠키, 분석 도구, 광고 추적을 쓰지 않아요. 2번의 브라우저 저장소는 기능을 위한 것이고 운영자에게 전송되지 않아요.

- 제3자 제공: 없음
- 처리 위탁·국외 이전: 운영자의 문의 메일함이 Gmail이라 문의 메일은 Google 서버에 보관돼요.

| 항목 | 내용 |
|---|---|
| 이전받는 자 | Google LLC (문의: https://support.google.com/policies/contact/general_privacy_form) |
| 이전 국가 | 미국 |
| 이전 항목 | 이메일 주소, 문의 내용 |
| 이전 시기·방법 | 메일을 보낼 때 네트워크로 전송 |
| 이용 목적·보유 기간 | 메일 보관, 1번의 보유 기간까지 |
| 거부 방법과 효과 | 메일을 보내지 않으면 이전되지 않아요. 일반 문의는 GitHub 이슈로 할 수 있어요 |

## 7. 파기

보유 기간이 지난 문의 메일은 메일함과 휴지통에서 지워 복구할 수 없게 해요. 브라우저에 있는 정보는 2번의 방법으로 직접 지워요.

## 8. 권리와 행사 방법

- 운영자가 가진 내 개인정보(문의 메일)의 열람·정정·삭제·처리정지를 이메일로 요구할 수 있어요. 10일 안에 조치하고 알려 드려요. 대리인을 통해서도 할 수 있어요.
- 웹앱은 강사 등 성인을 대상으로 하고, 만 14세 미만 아동의 개인정보를 받지 않아요.
- **만든 연수 사이트의 참가자 정보**는 운영자가 처리하지 않아요. 개인정보처리자는 그 연수를 운영하는 강사나 기관이고, 기록은 강사가 연결한 계정(구글 시트, Supabase, Cloudflare, 자체 서버)에 저장돼요. 열람·삭제는 그 사이트의 '개인정보 처리 안내'에 적힌 문의처로 요청해 주세요. 강사용 안내: [participant-privacy-guide.md](participant-privacy-guide.md)

## 9. 바로 공개 기능을 쓸 때

**이 절은 웹앱에 'lecpage 주소로 바로 공개' 기능이 켜져 있고, 그 기능을 쓴 경우에만 적용돼요.** 이 기능은 만든 사이트를 운영자 서버에 저장해 lecpage 주소(`/s/<id>/`)로 공개해요. 쓰지 않으면 1~8번 그대로예요.

| 항목 | 목적 | 보유 기간 |
|---|---|---|
| 올린 사이트 파일(안에 담긴 강사 소개·사진 등 포함) | 사이트 저장과 공개 | 마지막 공개나 방문 뒤 30일 동안 아무도 열지 않으면 자동 삭제(운영자가 정한 값). 올린 분이 지우거나 삭제를 요청하면 바로 삭제 |
| 공개 시각, 사이트 ID | 만료 관리 | 사이트와 함께 삭제 |
| 참가자의 참여 기록(위 설명의 경우에만): 별명, 질문·응답·보드 글과 파일, 출석 정보 | 강사를 대신해 참여 기능 제공 | 사이트와 함께 삭제. 강사가 강사 화면에서 먼저 지울 수 있음 |
| 수정 키의 해시값 | 올린 사람만 고치고 지울 수 있게 확인 | 사이트와 함께 삭제. 수정 키 원문은 저장하지 않음 |
| 공개 요청을 보낸 기기의 IP 주소 | 과도한 요청·악용 차단 | 24시간 안에 삭제(운영자가 정한 값) |

- 사이트에 담긴 내용은 올린 분이 정한 것이고, 운영자는 저장과 전송만 해요. 다른 사람의 개인정보가 든 자료는 올리지 말아 주세요.
- 사이트를 보는 사람의 접속 기록(IP 주소 등)은 Cloudflare가 전송과 보안을 위해 처리해요. 운영자는 요청 수 같은 합계만 봐요.
- **참여 기능을 바로 공개 서버로 쓸 때**(강사가 따로 연결하지 않고 바로 공개로 올린 사이트): 참가자가 남긴 별명·질문·투표 응답·보드 글과 파일, 출석 정보(강사가 켰을 때 이름·소속)가 그 사이트의 공개 기간 동안 운영자 서버에 저장돼요. 이 정보의 개인정보처리자는 연수를 운영하는 강사·기관이고, 운영자는 저장과 전송을 맡는 수탁자예요. 운영자는 장애 대응과 신고 처리에 필요한 때가 아니면 내용을 열어 보지 않아요. 사이트가 지워지면 함께 지워져요.
- 강사가 구글 시트·Supabase 등 자기 계정에 참여 기능을 연결한 사이트의 참여 기록은 운영자 서버에 오지 않아요.
- 처리 위탁·국외 이전(개인정보 보호법 제28조의8제1항제3호에 따라 이 방침에 공개):

| 항목 | 내용 |
|---|---|
| 이전받는 자 | Cloudflare, Inc. (privacyquestions@cloudflare.com) |
| 이전 국가 | 미국 등 Cloudflare 데이터센터가 있는 국가 |
| 이전 항목 | 위 표의 항목 전부 |
| 이전 시기·방법 | '바로 공개'를 누를 때 네트워크로 전송 |
| 이용 목적·보유 기간 | 사이트 저장·전송, 위 표의 보유 기간까지 |
| 거부 방법과 효과 | 바로 공개를 쓰지 않으면 이전되지 않아요. ZIP 저장과 내 계정(Vercel·GitHub·Netlify)으로 올리기는 그대로 쓸 수 있어요 |

- 삭제: 올린 분은 수정 키로 직접 지울 수 있어요. 수정 키를 잃어버렸거나 내 정보가 남의 사이트에 실려 있으면 이메일로 요청해 주세요.

## 10. 안전성 확보 조치

- 바로 공개 기능을 빼면 웹앱에는 운영자 서버와 데이터베이스가 없어요.
- 웹앱은 HTTPS로만 제공하고, 콘텐츠 보안 정책(CSP)으로 허용한 곳에만 연결해요.
- 기억하게 한 AI 키·배포 토큰은 AES-GCM으로 암호화해 저장해요.
- 문의 메일함은 운영자만 접근하고 2단계 인증을 써요.
- 바로 공개 기능: 수정 키와 강사 화면 관리자 키는 해시값만 저장하고, 저장소에는 운영자만 접근해요. 참가자가 올린 파일은 그림·PDF·소리·영상만 받고 형식을 검사해요. (기능이 켜져 있을 때만)

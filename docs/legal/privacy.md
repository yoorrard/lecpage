# lecpage 개인정보 처리방침

시행일: 2026-11-21

lecpage 운영자 유영재(이하 '운영자')가 lecpage 웹앱(https://lecpage.com/, 예비 주소 https://yoorrard.github.io/lecpage/)에 적용하는 방침이에요. 웹앱은 회원가입이 없어요. 교재와 프로젝트는 쓰는 분의 브라우저에 저장되고 운영자 서버로 보내지 않아요. 사이트 만들기는 쓰는 분이 고른 AI가 해서, 교재 원본이 그 AI 회사로 브라우저에서 바로 가요(3번). Agent Skill은 쓰는 분의 컴퓨터와 AI 도구 안에서 돌아가고 운영자에게 아무것도 보내지 않아요.

| | |
|---|---|
| 운영자가 받는 것 | 이메일로 문의하신 경우의 이메일 주소와 문의 내용, 바로 배포 사이트를 신고하신 경우의 신고 내용과 연락처(적은 경우만) |
| 운영자가 받지 않는 것 | 교재, 프로젝트, AI 키, 배포 토큰, AI에 보낸 내용, 만든 사이트의 참가자 정보 |
| 예외 | '바로 배포'로 직접 배포한 사이트 파일과 그 사이트의 참여 기록(9번, 기능이 켜져 있을 때만) |
| 쿠키·광고·바깥 분석 도구 | 쓰지 않음. 바로 배포가 켜진 앱만 개인을 알아볼 수 없는 하루 합계를 셈(9-1, 설정에서 끔) |

웹앱에 'lecpage 주소로 바로 배포' 기능이 켜져 있으면 [9. 바로 배포 기능을 쓸 때](#9-바로-배포-기능을-쓸-때)가 함께 적용돼요. 그 기능이 없는 동안에는 9번과 '예외' 줄은 해당 없어요.

## 1. 운영자가 처리하는 개인정보

| 언제 | 항목 | 목적 | 보유 기간 |
|---|---|---|---|
| 이메일로 문의·요청할 때 | 이메일 주소, 문의 내용, 메일에 적은 이름 | 문의 답변, 권리 요청 처리 | 답변을 마친 날부터 1년(운영자가 정한 값), 그 뒤 삭제 |
| 바로 배포 사이트를 신고 화면(`…/report`)으로 신고할 때 | 신고한 사이트 주소, 신고 까닭, 연락처(선택, 적은 경우만), 받은 시각 | 신고 처리(사이트 가리기·지우기)와 결과 알림 | 받은 날부터 90일이 지나면 서버가 자동 삭제(운영자가 정한 값) |

- 문의·신고하신 분의 요청을 처리하는 데 필요한 정보라 따로 동의를 받지 않아요(개인정보 보호법 제15조제1항제4호).
- 신고는 운영자만 관리 화면(Cloudflare Access로 운영자 계정만 들어옴)에서 봐요. 운영자에게 가는 메신저 알림에는 신고 번호와 관리 화면 링크만 보내고, 신고 내용·연락처는 보내지 않아요.
- 같은 곳에서 신고가 몰리는 것을 막으려고 IP 주소를 날짜와 함께 해시해 횟수만 세요(9번의 IP 주소 줄과 같은 방식·기간).
- 주민등록번호 같은 고유식별정보와 민감정보는 받지 않아요. 메일에 적지 말아 주세요.
- GitHub 이슈는 누구나 보는 공개 게시판이에요. 글과 GitHub 계정 이름이 공개되고, GitHub의 개인정보 처리방침이 적용돼요.

## 2. 이 브라우저 안에서만 처리되는 정보

아래 정보는 운영자에게 오지 않아요. 바로 배포로 직접 배포한 사이트 파일만 예외예요(9번).

| 정보 | 저장 위치 |
|---|---|
| 교재, 프로젝트, 만든 사이트 파일 | 브라우저 저장소(IndexedDB) |
| AI 작업 기록(받는 중인 답 조각, 이어 받을 위치, 쓰던 AI 창에서 붙여 넣은 답)과 판 기록(최근 10판) | 이 기기의 IndexedDB(`lecpage-gen`). 연수를 지우면 그 연수의 기록도 함께 지움 |
| AI 키, 배포 토큰 | '이 기기에서 기억하기'(처음에 켜져 있음)를 켠 것은 암호화해 IndexedDB에 저장. 끄면 열어 둔 탭에만 있음 |
| 화면 설정(밝게·어둡게 등), 연결 동의(길마다 처음 한 번 확인한 기록) | localStorage |
| 오프라인용 앱 파일 | 서비스 워커 캐시 |

- 지우는 방법: 웹앱 **설정 > 모든 데이터 삭제**, 또는 브라우저의 사이트 데이터 삭제.
- 운영자는 이 정보를 가지고 있지 않아서 대신 보거나 지워 드릴 수 없어요.
- 함께 쓰는 컴퓨터에서는 '이 기기에서 기억하기'를 끄고, 끝나면 데이터를 지워 주세요.

## 3. 쓰는 분이 고른 곳으로 브라우저가 직접 보내는 정보

운영자 서버를 거치지 않고 브라우저에서 그 회사로 바로 가요. 운영자가 가진 적이 없는 정보라 운영자의 제3자 제공·처리 위탁·국외 이전에 해당하지 않고, 각 회사의 약관과 개인정보 처리방침이 적용돼요.

| 언제 | 받는 곳 | 보내는 것 |
|---|---|---|
| 구독으로 연결(lecpage 커넥트)을 쓸 때 | 내 PC의 `127.0.0.1`에서 도는 lecpage 커넥트, 그다음 ChatGPT 계정이면 OpenAI(이 PC에서 바로), Claude 계정이면 내 PC의 Claude Code(Anthropic), Codex면 OpenAI | 교재 원본과 아래 API 키 길과 같은 내용(AI 키는 빼고). Claude Code·Codex 길은 PC의 임시 폴더에 두었다가 끝나면 지워요. ChatGPT 계정의 로그인 정보(토큰)는 이 PC의 사용자 폴더 파일에만 두고, 브라우저·운영자에게 보내지 않아요. lecpage.com 화면은 이 브라우저에서 `127.0.0.1`의 lecpage 커넥트로만 요청해요. 앱 화면을 lecpage.com에서 받아 올 때는 접속 정보가 4번과 같이 처리돼요 |
| AI로 사이트를 만들거나 고칠 때(API 키 길) | Anthropic(Claude), OpenAI(GPT) 중 고른 곳(국외) | **교재 원본 파일**(PDF), 교재 쪽 그림과 보조 글자, 연수 정보, 수정 요청 내용, 고칠 때의 지금 사이트 HTML·CSS, 참고 디자인의 분위기 글, 내 AI 키 |
| 사이트를 올릴 때 | Vercel, GitHub, Netlify 중 고른 곳(국외) | 만든 사이트 파일, 내 배포 토큰 |
| 참여 기능을 연결할 때 | 내가 만든 Google Apps Script, Supabase, Cloudflare, 자체 서버 | 연결 확인 요청, 연수 설정 |
| 쓰던 AI(채팅 앱)를 쓸 때 | 내가 연 AI 앱(ChatGPT·Claude 등) | 앱이 만든 요청문을 내가 직접 붙여 넣고 파일을 직접 올려요. 앱이 보내지 않아요 |
| 디자인을 미리 볼 때 | jsDelivr, Google Fonts, 네이버 글꼴 서버 | 글꼴·효과 파일 요청(IP 주소 등 접속 정보) |

- **회사별 보관**: OpenAI는 답을 OpenAI에 잠시 저장했다가(긴 작업을 이어 받으려고) 다 받으면 앱이 지워요. 실패하거나 끊겨도 나중에 다시 지우려 하지만, 지우지 못하면 OpenAI의 보관 기간 동안 남을 수 있어요. Claude는 짧은 시간 캐시에 둘 수 있어요. 자세한 기간은 각 회사 문서를 따라요.
- **AI 학습에 쓰이는지**는 회사·요금제·계정 설정마다 달라요. 운영자는 입력 내용을 받지 않고 AI 학습에도 쓰지 않아요.
- OpenRouter는 사이트 만들기에 더는 쓰지 않아요.
- 교재에 다른 사람의 개인정보(학생 이름·사진, 연락처 등)가 있으면 AI에 보내기 전에 지워 주세요.

## 4. 접속 기록

웹앱 파일은 Cloudflare(Cloudflare, Inc., 미국)가 보내 주고, 예비 주소는 GitHub Pages(GitHub, Inc., 미국)가 보내 줘요. 두 회사는 전송과 보안을 위해 방문자의 IP 주소 등 접속 기록을 처리해요(GitHub은 [기록·보관한다고 밝힘](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)). 운영자는 요청 수 같은 합계만 보고, 개인을 알아볼 수 있는 접속 기록은 따로 모으지 않아요. 호스팅 회사를 바꾸면 이 방침을 먼저 고쳐서 알려요.

## 5. 쿠키 등 자동 수집 장치

쿠키, 바깥 분석 도구, 광고 추적을 쓰지 않아요. 2번의 브라우저 저장소는 기능을 위한 것이고 운영자에게 전송되지 않아요. 바로 배포가 켜진 앱은 9-1의 익명 하루 합계만 보내고, 설정에서 끌 수 있어요.

## 6. 제3자 제공, 처리 위탁, 국외 이전

- 제3자 제공: 없음
- 처리 위탁·국외 이전: 운영자의 문의 메일함이 Gmail이라 문의 메일은 Google 서버에 보관돼요(아래 표). 신고 화면으로 보낸 신고는 바로 배포 서버가 있는 Cloudflare에 보관돼요(9번의 Cloudflare 표와 같은 이전받는 자·국가, 이전 항목은 1번 표의 신고 줄, 보유 기간 90일). 신고 화면 대신 이메일로 신고하면 아래 표만 해당돼요.

| 항목 | 내용 |

| 이전 국가 | 미국 |

## 7. 파기

보유 기간이 지난 문의 메일은 메일함과 휴지통에서 지워 복구할 수 없게 해요. 신고는 받은 날부터 90일이 지나면 서버가 하루 한 번 자동으로 지워요. 브라우저에 있는 정보는 2번의 방법으로 직접 지워요.

## 8. 권리와 행사 방법

- 운영자가 가진 내 개인정보(문의 메일, 신고)의 열람·정정·삭제·처리정지를 이메일로 요구할 수 있어요. 10일 안에 조치하고 알려 드려요. 대리인을 통해서도 할 수 있어요.
- 웹앱은 강사 등 성인을 대상으로 하고, 운영자가 직접 받는 정보(문의·신고)는 만 14세 미만 아동에게서 받지 않아요. 바로 배포로 학생 대상 연수의 참여 기능을 쓰면 참가자 별명 등이 운영자 서버에 저장될 수 있는데, 이 정보의 개인정보처리자는 연수를 운영하는 강사·기관이고 법정대리인 동의 등 절차도 처리자가 맡아요(9번).
- **만든 연수 사이트의 참가자 정보**의 개인정보처리자는 그 연수를 운영하는 강사나 기관이에요. 기록은 강사가 연결한 계정(구글 시트, Supabase, Cloudflare, 자체 서버)에 저장되고 운영자는 받지 않아요. 바로 배포로 참여 기능을 함께 쓴 사이트만 운영자가 강사를 대신해 저장해요(9번). 열람·삭제는 그 사이트의 '개인정보 처리 안내'에 적힌 문의처로 요청해 주세요. 강사용 안내: [participant-privacy-guide.md](participant-privacy-guide.md)

## 9. 바로 배포 기능을 쓸 때

**이 절은 웹앱에 'lecpage 주소로 바로 배포' 기능이 켜져 있고, 그 기능을 쓴 경우에만 적용돼요.** 이 기능은 만든 사이트를 운영자 서버에 저장해 lecpage 주소(사이트마다 `s-<id>.….pages.dev`, 예전 방식은 `/s/<id>/`)로 공개해요. 쓰지 않으면 1~8번 그대로예요.

| 항목 | 목적 | 보유 기간 |
|---|---|---|
| 배포한 사이트 파일(안에 담긴 강사 소개·사진 등 포함) | 사이트 저장과 공개 | 마지막 배포 뒤 60일이 지나면 자동 삭제. 운영자가 한 주소 아래에 두는 방식을 쓰면 마지막 배포나 방문 뒤 30일 동안 아무도 열지 않을 때 삭제(모두 운영자가 정한 값). 올린 분이 지우거나 삭제를 요청하면 바로 삭제 |
| 배포 시각, 사이트 ID | 만료 관리 | 사이트와 함께 삭제 |
| 참가자의 참여 기록(위 설명의 경우에만): 별명, 질문·응답·보드 글과 파일, 출석 정보 | 강사를 대신해 참여 기능 제공 | 사이트와 함께 삭제. 강사가 강사 화면에서 먼저 지울 수 있음 |
| 수정 키의 해시값 | 배포한 사람만 고치고 지울 수 있게 확인 | 사이트와 함께 삭제. 수정 키 원문은 저장하지 않음 |
| 배포·신고 요청을 보낸 기기의 IP 주소 | 과도한 요청·악용 차단 | 원문은 저장하지 않고 날짜와 함께 해시해 횟수만 셈. 그날(한국 시간 오전 9시에 바뀜)이 끝나면 지움, 만든 때부터 길어야 약 25시간(운영자가 정한 값) |
| 기기 표(웹앱이 이 브라우저에 만들어 둔 무작위 값. 이름·계정·다른 정보와 묶지 않고 새 사이트를 만들 때만 보냄) | 한 기기가 하루에 만드는 새 사이트 수 세기(여럿이 같은 학교 인터넷을 써도 막히지 않게) | 원문은 저장하지 않고 날짜와 함께 해시해 셈. 그날이 끝나면 지움, 만든 때부터 길어야 약 25시간 |

- 사이트에 AI가 쓴 스크립트가 들어 있으면, 그 스크립트는 사이트를 여는 참가자의 브라우저에서 돌아요. 서버가 연결할 수 있는 곳을 좁히고 비밀번호 칸 같은 것은 올릴 때 거절하지만, 스크립트의 모든 동작을 막지는 못해요. 올리기 전에 미리보기로 확인해 주세요.
- 사이트에 담긴 내용은 배포한 분이 정한 것이고, 운영자는 저장과 전송만 해요. 다른 사람의 개인정보가 든 자료는 올리지 말아 주세요.
- 사이트를 보는 사람의 접속 기록(IP 주소 등)은 Cloudflare가 전송과 보안을 위해 처리해요. 운영자는 요청 수 같은 합계만 봐요.
- **참여 기능을 바로 배포 서버로 쓸 때**(강사가 따로 연결하지 않고 바로 배포한 사이트): 참가자가 남긴 별명·질문·투표 응답·보드 글과 파일, 출석 정보(강사가 켰을 때 이름·소속)가 그 사이트의 보관 기간 동안 운영자 서버에 저장돼요. 이 정보의 개인정보처리자는 연수를 운영하는 강사·기관이고, 운영자는 저장과 전송을 맡는 수탁자예요. 운영자는 장애 대응과 신고 처리에 필요한 때가 아니면 내용을 열어 보지 않아요. 사이트가 지워지면 함께 지워져요.
- 학생 대상 연수(강사가 '학생 워크숍'으로 설정)는 참여 기능이 별명만 받아요. 법정대리인 동의 등은 개인정보처리자인 강사·기관이 학교 절차에 따라 맡아요([강사용 안내](participant-privacy-guide.md) 5번).
- 강사가 구글 시트·Supabase 등 자기 계정에 참여 기능을 연결한 사이트의 참여 기록은 운영자 서버에 오지 않아요.
- 처리 위탁·국외 이전(개인정보 보호법 제28조의8제1항제3호에 따라 이 방침에 공개):

| 항목 | 내용 |
|---|---|
| 이전받는 자 | Cloudflare, Inc. (privacyquestions@cloudflare.com) |

## 9-1. 익명 이용 합계와 공지 (바로 배포가 켜진 앱만)

**바로 배포 기능이 켜진 웹앱에만 해당해요.** 운영자가 서버 비용(무료 한도 안에서 둘지, 월 정액으로 올릴지)과 고칠 곳을 정하려고, 개인을 알아볼 수 없는 하루 합계만 셉니다.

| 언제 | 보내는 것(이것뿐) | 서버가 하는 일 |
|---|---|---|
| 앱을 연 날(하루 한 번) | `open` | 그날의 '앱 열기' 숫자에 1을 더함 |
| AI로 사이트 만들기를 마쳤을 때 | `make`와 길(API 키·쓰던 AI 창) | 그날의 해당 숫자에 1을 더함 |
| 배포를 마쳤을 때 | `publish`와 배포한 곳 종류(바로 배포·Vercel·GitHub·Netlify) | 그날의 해당 숫자에 1을 더함 |

- 보내지 않는 것: 교재·프로젝트 내용, 사이트 주소, 연수 이름, AI 키·토큰, 기기·브라우저 식별자, 쿠키.
- 서버는 IP 주소와 보낸 시각을 저장하지 않고 숫자만 더해요(전송 중 Cloudflare가 처리하는 접속 정보는 9번과 같아요). 같은 곳에서 1분에 20번이 넘으면 세지 않고, 항목마다 하루 상한이 있어요(부풀리기 막기).
- 하루 숫자는 400일 뒤 지워요. 운영자 관리 화면에서 날짜별 합계로만 보여요.
- 끄기: 웹앱 **설정 > 이용 합계**. 브라우저의 '추적 안 함'(Do Not Track·Global Privacy Control)을 켜도 보내지 않아요. 끄면 숫자에서만 빠지고 다른 기능은 그대로예요.
- 공지: 앱이 켜진 뒤 운영자의 공지를 한 번 받아 와요(바로 배포 서버, 없으면 웹앱 배포 안의 `notice.json`). 요청만 보내고 쿠키·식별자는 보내지 않아요. 본 공지는 이 브라우저(localStorage)에만 적어 두어 다시 띄우지 않아요.

## 10. 안전성 확보 조치

- 바로 배포 기능을 빼면 웹앱에는 운영자 서버와 데이터베이스가 없어요.
- 웹앱은 HTTPS로만 제공하고, 콘텐츠 보안 정책(CSP)으로 허용한 곳에만 연결해요.
- lecpage 커넥트는 내 PC의 `127.0.0.1`에서만 받고, 이 PC에 저장한 짝 맞춤 토큰과 허용한 출처(lecpage.com)를 확인해요. ChatGPT 로그인 토큰은 이 PC 사용자 폴더의 파일(본인만 읽기)에만 두고, Claude Code·Codex의 로그인 파일은 읽지 않아요.
- 기억하게 한 AI 키·배포 토큰은 AES-GCM으로 암호화해 저장해요.
- 문의 메일함은 운영자만 접근하고 2단계 인증을 써요.
- 바로 배포 사이트: 사이트마다 주소(출처)를 나누고, 서버가 정한 보안 정책(CSP)으로 사이트가 연결할 수 있는 곳을 그 사이트와 그 사이트의 참여 기능 서버로 좁혀요. 비밀번호 입력 칸·로그인 화면 흉내·다른 사이트로 보내는 양식·서비스 워커가 있는 사이트는 받지 않아요. 다만 사이트가 입력값을 주소에 붙여 다른 사이트로 이동시키는 것은 이런 정책으로 막을 수 없어서, 모든 사이트 아래 '신고' 링크로 받아 확인하는 동안 가리고(사이트와 참여 기능이 함께 닫힘) 필요하면 지워요. (기능이 켜져 있을 때만)
- 바로 배포 기능: 수정 키와 강사 화면 관리자 키는 해시값만 저장하고, 저장소에는 운영자만 접근해요. 운영자 관리 화면은 Cloudflare Access(운영자 계정만, 2단계 인증)로 들어오고 서버가 그 토큰을 한 번 더 확인하며, 가리기·지우기·공지는 누가 언제 했는지 기록해요. 참가자가 올린 파일은 그림·PDF·소리·영상만 받고 형식을 검사해요. (기능이 켜져 있을 때만)

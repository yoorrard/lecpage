# lecpage 기획서 v1.1

> 초안(v0.1, 2026-11-09 대화)에서 이름을 **lecpage**로 정하고, 조사 결과를 반영해 고도화한 판입니다. 같은 날 v1.0 구현과 함께 확정했습니다.

## 0. 방향 (v1.1, 2026-11-11)

**목표**: 교재만 넣으면, 디자이너와 개발자가 붙어 만든 것 같은 연수 사이트가 공개 주소까지 한 번에 나온다. AI 에이전트에게 그냥 시켰을 때와 결과가 한눈에 달라야 하고, 처음 쓰는 사람도 헤매지 않아야 한다.

| 원칙 | 뜻 | 구현 |
|---|---|---|
| 교재가 원본 | 내용을 지어내지 않는다 | 섹션마다 근거 쪽(`source.pages`)을 두고 화면에 "교재 n쪽"으로 표시. 교재 속 지시문은 따르지 않음 |
| AI가 먼저, 사람은 고른다 | 빈 화면에서 시작하지 않는다 | [AI로 사이트 만들기] 한 번에 구성·문구·디자인. 기본 초안을 먼저 보여 주고 AI 결과로 바꿈(되돌리기 가능). AI 연결은 로그인 한 번 또는 키 붙여넣기. AI 없이도 기본 초안은 나옴 |
| 강사가 할 일은 최소로 | 연결·설정을 시키지 않는다 | 요청 사항 한두 줄이면 구성·분위기에 반영. 키·토큰은 [붙여넣기] 한 번. 운영자가 '바로 공개'를 켜 두면 가입 없이 공개하고 질문·보드·파일 올리기까지 함께 켜짐. 자료는 공개한 뒤에도 올리고, 연수 중에는 강사 화면에서 링크 추가 |
| 만들기부터 공개까지 한곳에서 | 파일을 받아 따로 올리게 하지 않는다 | 올릴 곳을 추천하고 단추 하나로 공개 → 주소·QR·안내 문구 → 실제로 열리는지 확인. 한 번 연결한 곳은 다음부터 단추 하나 |
| 사람 손이 닿은 디자인 | 틀에 색만 바꾸지 않는다 | 컨셉 먼저(참가자가 겪는 경험 한 줄 → 디자인). 디자인 27종마다 첫 화면 구성·글 배치·글꼴·섹션 문법이 다름(그림이 이끄는 첫 화면 8종, 가운데·세로쓰기·어긋난 격자·반반 화면 포함). 정적~스크롤 연출 가운데 고름. 효과 58가지, 프리셋마다 다른 페이지 연출 계획(첫 화면 밖 전 구간). 'AI 티' 규칙과 자동 점검(design-lint) |
| 가볍게, 안전하게 | 운영비와 개인정보 책임을 지지 않는다 | 서버 없는 앱, 강사 소유 계정, CSP·이스케이프·암호 보호, 개인정보 안내 자동 생성 |

AI에게 그냥 시킬 때와 다른 점

| | 그냥 시키면 | lecpage |
|---|---|---|
| 디자인 | 비슷한 틀이 반복, 검증 없음 | 주제·분위기·교재 글꼴로 디자인을 고르고 대비·줄바꿈·넘침·AI 티를 자동 점검 |
| 내용 | 그럴듯하게 지어낼 수 있음 | 교재 쪽을 근거로 구성, 스키마 검증·자동 보정 |
| 기능 | 정적 페이지 한 장 | 교재 보기·실습·질문·투표·나눔 보드·강사 화면·발표 화면·QR 안내문·접속 확인 |
| 비용 | HTML 전체를 쓰고 고칠 때마다 다시 씀 | 설계도(JSON)와 작은 패치만. 같은 일에 읽는 글 약 1/12, 쓰는 글 약 1/170 |
| 공개 | 받은 파일을 직접 올림 | 추천·한 번에 공개·열림 확인 |

## 1. 한 줄 정의
연수 교재(PPT·PDF·한글 HWPX·워드)와 연수 정보로, 그 연수만을 위한 사이트를 **내용 구성·디자인·모션·실시간 참여 기능·서버 운영 방식·배포**까지 맞춰 만들어 주는 Agent Skill과 웹앱.

## 3. 구성
1. **엔진**(`skills/lecpage/engine/src`): 설계도 검증·자동 보정 → 결정 규칙(유형·디자인·운영) → 렌더러(섹션 30종, 페이지 6종: 참가자·강사 화면·발표 화면·접속 확인·QR 안내문·개인정보 안내) → 빌드(파일 묶음) · 교재 해석(PPTX·PDF·HWPX·DOCX) · AI 프롬프트 팩.
2. **런타임**(`engine/runtime`): 참가자 화면(교재 보기·실습·프롬프트 복사·접속 확인·실시간 UI), 강사 화면, 발표 화면, 효과 레지스트리(fx), 실시간 어댑터(live).
3. **백엔드**(`skills/lecpage/backends`): Supabase SQL(RLS·RPC·속도 제한), Apps Script, Cloudflare Worker+Durable Objects, 의존성 없는 Node 서버(SQLite·SSE·WebSocket, Docker).
4. **skill**(`skills/lecpage/SKILL.md` + references 10여 개 + scripts): 11단계 흐름, 인터뷰 질문, 설계도 작성법, 디자인·운영·배포·개인정보·점검 기준.
5. **웹앱**(`app/`): 3단계(교재 넣기 → 살펴보고 고치기 → 공개하기)와 늘 보이는 미리보기(모니터·노트북·태블릿·휴대폰), 디자인 둘러보기(디자인·효과가 실제로 움직임), 도움말, 설정(연결).

## 5. 디자인 체계
무드 프리셋 → 디자인 토큰(shadcn 이름, 라이트·다크, 대비 자동 검사) → 부품 변형(첫 화면·카드·메뉴·버튼) → 모션 단계(0~3) → 슬롯별 효과 → 시그니처 하나. 생성 사이트마다 `DESIGN.md`를 함께 출력해 나중에 어떤 AI로 고쳐도 일관성 유지. 상세: `skills/lecpage/references/design.md`, 조사: `docs/research/motion-graphics.md`.

## 6. 운영 방식 결정
입력: 인원·필요 기능·기간·숙련도·가진 인프라·네트워크·유료 여부·미성년자.
- 기록이 필요 없음 → 정적(서버 없음)
- 모으기만, 40명 이하 → Google Sheets
- 클릭만 하는 강사, 50명 이하(질문·도움 요청·진행 현황 포함) → Google Sheets
- 실시간, 100명 이하 → Supabase 무료(강사 소유)
- 100명 초과 → Cloudflare Workers + Durable Objects(강사 계정, Deploy 버튼)
- 운영자 공용 중계는 두지 않음(모두 강사 소유)
- 가진 서버(AWS·학교·NAS) + 설정 가능 → 자체 Node 서버(Docker)
- 인터넷 없음 → 강사 노트북 서버(LAN)
올릴 곳(2026-11-11 재조사, `docs/research/hosting-2026-11.md`): 앱은 **Vercel**(토큰 하나로 앱에서 바로, 다시 올려도 같은 주소) → GitHub Pages → Cloudflare(ZIP 끌어 놓기) → Netlify, skill은 **Cloudflare Workers 정적 자산**(`wrangler`, 상업 이용 가능·요청 무제한) 먼저. 강사료를 받는 연수는 Vercel 무료를 빼고, 사이트 크기·파일 수·지난번에 올린 곳·연결해 둔 곳을 보고 순서를 바꿈(`decideHost`, `checkHost`). 운영자가 켜면 가입 없이 30일 동안 여는 '바로 공개'(`hosting/`)도 고를 수 있음. 그 밖: Firebase · AWS · 자체 서버 · ZIP/USB. 상세: `references/infra-decision.md`, `references/deploy/*.md`(15종).
생성 사이트 공개 범위: 링크(기본, 검색 제외) · 공개 · 암호(AES-GCM 암호화, QR `#k=`로 자동 열기). 강사용 파일(DESIGN.md·운영안내.md·설계도)은 올리는 사이트에 넣지 않음.

## 7. 개인정보·보안
별명 + 연수 코드가 기본, 이름·소속은 출석 기능에서만(동의 화면·처리 안내 자동), 보관 30일 후 일괄 삭제, 14세 미만은 별명만. 관리자 키는 해시만 서버에. AI·사용자 입력은 JSON 데이터로만 다루고 렌더러가 모두 이스케이프, 링크는 https만. 웹앱은 키를 탭에만 기억(선택 시 WebCrypto 암호화), 미리보기는 샌드박스.

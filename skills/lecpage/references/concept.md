# 컨셉 먼저

디자인을 고르기 전에 **컨셉**을 세운다. 컨셉은 이 연수가 참가자에게 주는 경험을 한 문장으로 적은 것이고, 디자인(프리셋·색·글꼴·움직임·첫 화면 그림)과 구성(섹션·참여 기능)이 모두 여기서 나온다. 컨셉이 없으면 프리셋을 "예뻐 보이는 것"으로 고르게 되고, 그런 사이트는 어느 연수에 붙여도 똑같아 보인다.

## 1. 설계도의 `concept`

설계도 최상위에 둔다(`design` 안이 아니다. 구성도 이 값을 읽는다).

| 필드 | 뜻 | 읽는 곳 |
|---|---|---|
| `idea` | 한 줄 컨셉. 참가자가 이 연수에서 겪는 경험. 색·글꼴 낱말을 쓰지 않는다 | DESIGN.md, 앱 디자인 칸 |
| `why` | 교재·주제의 어디에서 나왔는지(쪽 번호나 낱말) | DESIGN.md, 앱 |
| `motif` | 화면에 되풀이할 은유·그림 하나. 첫 화면 그림 → 본문 구분선 → 마무리로 이어진다 | 프리셋 고르기의 근거 |
| `keywords` | 핵심 낱말 3~5개 | DESIGN.md |
| `moods` | 분위기(`calm`·`warm`·`tech` …). `design.mood`가 비었을 때 쓴다 | `validate` |
| `preset` | 컨셉에 맞는 디자인 id. `design.preset`을 따로 적지 않았을 때 쓴다 | `validate`, 초안 만들기 |
| `motion` | 컨셉이 바라는 페이지 연출 단계 0~3. 환경 상한(공식 연수·크롬북)이 먼저다 | `validate` |
| `sections` · `features` | 컨셉 때문에 고른 섹션 타입·참여 기능 | 구성(디자인은 읽지 않음) |
| `source` | `ai` · `auto`(규칙으로 세움) · `teacher`(강사가 고침) | 다시 만들 때 `teacher`는 지킨다 |

`design.preset`을 직접 적으면 그것이 먼저다. `concept`가 없는 예전 설계도는 그대로 동작한다.

## 2. 세우는 순서

1. **읽기**: 교재 제목·차례·핵심 문장에서 "참가자가 무엇을 하게 되는가"를 찾는다. 듣는가, 따라 하는가, 나누는가, 돌아보는가.
2. **한 줄**: "…하는 시간"으로 끝나는 문장 하나. 예: "한 사람의 마음이 물결처럼 번져 교실 전체에 닿는 것을 함께 겪는 시간".
3. **모티프**: 그 경험을 눈에 보이게 하는 그림 하나. 교재에 이미 있는 것이면 더 좋다(마음 날씨 → 물결, 학습 기록 → 점, 그림책 → 책 표지).
4. **디자인**: 모티프와 가장 가까운 프리셋을 고른다. 글 배치도 본다 — 조용히 읽히는 연수는 가운데·세로쓰기, 정보가 많은 연수는 어긋난 격자·자료 그림, 교재가 얼굴인 연수는 그림 가득·펼친 교재. 목록은 `references/design.md`.
5. **구성**: 컨셉에 맞는 섹션과 참여 기능만 남긴다. 돌아보는 연수에 퀴즈를 넣지 않고, 따라 하는 연수에 긴 메시지 띠를 넣지 않는다.
6. **적기**: `patch <설계도> --set concept.idea='…' --set concept.motif='…' --set concept.why='…' --set concept.preset=<id> --set design.preset=<id>`.

`design <설계도>`는 지금 컨셉(없으면 주제에서 규칙으로 세운 것)과 디자인 순위를 보여 준다. 규칙으로 세운 컨셉은 출발점이다. 교재를 읽었다면 교재의 말로 다시 쓴다.

## 3. 좋은 컨셉 · 나쁜 컨셉

| 나쁨 | 까닭 | 좋음 |
|---|---|---|
| "따뜻하고 세련된 파스텔 톤 디자인" | 디자인 낱말뿐. 경험이 없다 | "초대받은 자리에서 아이의 하루를 함께 들여다보는 시간" |
| "AI 시대의 미래 교육" | 어느 연수에나 붙는 말 | "낯선 기술을 손으로 돌려 보며 내 수업의 도구로 바꾸는 시간" |
| "데이터 분석 역량 강화" | 연수 목표이지 경험이 아니다 | "흩어진 기록이 점 하나하나로 모여 무늬가 되는 것을 보는 시간" |

## 4. 컨셉이 화면에 나타나는 곳

- 첫 화면: 프리셋의 구성과 그림(물결·점 지도·도형 타일·세로 제목 …).
- 본문: 같은 모티프가 섹션 머리·구분선·마무리에 작게 되풀이된다(프리셋의 본문 장치).
- 움직임: 프리셋마다 '페이지 연출 계획'이 있어 섹션이 들어오는 방식과 스크롤·카드 효과가 컨셉에 맞게 다르다. 빌드하면 DESIGN.md의 '컨셉'·'페이지 연출 계획' 단락에 적힌다.

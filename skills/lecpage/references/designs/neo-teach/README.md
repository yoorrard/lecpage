# 질문이 먼저, AI는 그다음 — 레퍼런스

가상의 AI 시대 수업 설계 교원 직무연수(3시간). 교재 `material/교재.pdf`(16:9 17쪽)를 `prepare`로 준비하고 끝까지 읽은 뒤 `site/`를 직접 썼어요. 기관·강사·연락처는 지어낸 예시예요.

## 디자인 판단
- **정체성**: 교재는 어두운 회로판 위에 '다섯 노드(질문→목표→증거→경험→성찰)'를 그린 슬라이드예요. 교사가 정하는 노드는 불씨 주황, AI가 돕는 연결은 하늘색 점선이라는 교재의 색 규칙을 사이트 전체의 문법으로 썼어요(주 단추·지금·번호는 주황, 프롬프트의 바꿀 자리·AI 역할은 하늘색).
- **첫 화면**: 교재 표지의 신경망을 WebGL로 살렸어요. 다섯 층 노드와 베지어 연결선, 연결선을 타고 흐르는 신호(정점 셰이더가 곡선 위치를 계산), 마우스 둘레를 밝히는 탐침, 스크롤하면 카메라가 망 안으로 들어가요. 다섯 노드 이름표는 같은 투영식으로 HTML에 붙여 또렷해요. 제목은 글자가 접혀 올라오고 'AI' 두 글자만 신호처럼 흔들리다 자리 잡으며, 커서 가까운 글자는 가변 글꼴 굵기가 가늘어져요. 일시·장소·강사·이수는 유리 띠로 첫 화면 안에, 도크에 가리지 않게.
- **흐름**: 첫 화면 → 일정(180분 비율 막대·시간표·목표·준비물 체크) → 들어가며(출석·첫 투표) → 1부 다섯 노드 → 실습 셋 → 안전하게 쓰기 → 교재 넘기기 → 확인 문제 → 질문 → 마무리(맺음말·한 낱말 투표·과제·후속 모임·설문·자료실·모음).
- **1부 노드 그래프**: PC는 왼쪽에 붙어 있는 SVG 그래프(3D로 살짝 기울고 마우스로 기욺)가 스크롤 위치를 따라 신호를 내려보내며 노드를 켜요. 노드마다 교재 6쪽 표(교사가 정할 것·AI에게 부탁할 것·맡기지 않을 것)를 붙여 5·6쪽을 한 장면으로 합쳤어요. 휴대폰은 그래프 없이 점선 줄기와 켜지는 노드만.
- **실습**: 단계 머리에 다섯 점 사슬로 '이 실습이 다루는 노드'를 표시(실습 3은 연결선이 켜짐). 프롬프트는 줄 번호가 있는 콘솔 카드에 원문 그대로, [ ] 자리는 하늘색, 복사는 `data-copy-text`. 휴대폰에서는 앞 몇 줄만 보이고 [전체 보기](복사는 늘 전체)라 실습 중 곁눈질 거리가 짧아요.
- **움직임**: 첫 화면 장면, 섹션 제목 낱말이 흐림에서 또렷하게(한 번), 노드 신호, 교재 쪽 3D 고리(스크롤로 회전), 맺음말 낱말이 화면 안에서만 차례로 켜짐, 흐르는 노드 띠(스크롤 방향·속도를 따름), 자석 단추·빛 따라오는 상자·커서 고리(가는 포인터만). 실습·복사·키트 칸은 가만히. 움직임 줄이기면 신경망은 한 장면만 그리고 나머지는 처음부터 다 보여요.
- **가볍게**: 라이브러리 없이 WebGL 1 직접(정적 버퍼, 애니메이션은 셰이더), 화면 밖·탭 숨김이면 멈추고 느린 기기는 해상도를 낮춰요. 사이트 파일 0.9MB(교재 쪽 그림 17장 포함).
- **글꼴**: Pretendard Variable(가변 굵기 장면), 숫자·시간 Space Grotesk, 프롬프트의 영문·기호 JetBrains Mono(한글은 Pretendard로 떨어져 읽기 편함).
- **키트**: 출석, 투표 5(첫 투표 2쪽·확인 문제 3개 `data-answer`·한 낱말 `data-kind="word"`), 실습 단계 3(`data-minutes` 40·40·30), 보드 1(보드는 첫 것만 실시간이라 실습 1·3이 같이 씀), 교재 넘기기, 질문, 설문, 자료실(캔버스 PDF·프롬프트 모음), 모음. 실습 레일은 `data-st-link`·`data-st-count`·`data-st-progress`.

## 그대로 복제하지 마세요
어두운 회로판·신경망은 'AI 시대 수업 설계'라는 이 교재의 은유에서 나왔어요. 다른 연수에 WebGL 망·주황/하늘색 문법을 옮기지 말고, 그 교재의 은유에서 같은 깊이로 새로 정하세요. 가져갈 것은 방법(교재의 색 규칙을 사이트 문법으로, 대표 그림 하나를 첫 화면 장면으로, 움직임은 개념을 보여 줄 때만)이에요.

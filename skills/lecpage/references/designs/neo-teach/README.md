# 질문이 먼저, AI는 그다음 — 레퍼런스

가상의 AI 시대 수업 설계 교원 직무연수(3시간). 교재 `material/교재.pdf`(16:9 17쪽)를 `prepare`로 준비하고 끝까지 읽은 뒤 `site/`를 직접 썼어요. 기관·강사·연락처는 지어낸 예시예요.

## 디자인 판단
- **사이트는 당일 도구**: 교재 내용은 교재 넘기기(쪽 그림)와 강사에게 맡기고, 사이트는 참가자가 그날 하는 일로만 짰어요. 설명이 필요한 곳은 핵심 한 줄 + '교재 N쪽 보기' 링크.
- **두 쪽**: `index.html`은 허브(첫 화면 → 지금·오늘의 흐름 → 시작 전에(출석·첫 투표·준비물) → 교재 → 실습 들어가기 → 질문·투표 → 연수가 끝난 뒤(과제·후속 모임·설문·자료실·모음)), `lab.html`은 실습 쪽(할 일·복사할 프롬프트·보드·완료 체크). 실습 중에는 실습 쪽만 보면 되고, 질문·도움 요청은 도크가 어느 쪽에서나 받아요. 휴대폰 길이는 허브 약 5화면, 실습 쪽 약 4화면.
- **지금**: 오늘의 흐름 줄마다 그 순서의 할 일로 가는 짧은 단추(출석·교재 5쪽·실습 1…·확인 문제). 연수 중에는 지금 줄·실습 카드·섹션 점이 켜지고, 첫 화면 칩이 '지금 · 순서 이름 [지금 할 일]'로 바뀌어요(전에는 D-day와 달력, 뒤에는 과제 마감).
- **다시 찾기**: 교재 아래 '자주 찾는 쪽' 바로 가기, 자료실(캔버스 PDF·프롬프트 모음), 모음(복사한 프롬프트), 달력 넣기.
- **정체성**: 교재의 색 규칙(교사가 정하는 노드 = 불씨 주황, AI가 돕는 연결 = 하늘색 점선)을 사이트 문법으로: 주 단추·지금·번호는 주황, 프롬프트의 바꿀 자리·안전 안내는 하늘색. 실습 머리의 다섯 점 사슬이 그 실습이 다루는 노드를 표시(실습 3은 연결선이 켜짐).
- **첫 화면**: 교재 표지의 신경망을 라이브러리 없이 WebGL로. 다섯 층 노드·베지어 연결선·선 위 신호(정점 셰이더), 마우스 탐침, 스크롤 카메라. 제목은 글자가 접혀 오르고 'AI'만 기호로 흔들리다 자리 잡으며, 커서 둘레는 가변 굵기가 가늘어져요. 일시·장소·강사·이수는 유리 띠로 첫 화면 안에, 도크에 가리지 않게.
- **실습 쪽**: 프롬프트는 줄 번호가 있는 콘솔 카드에 원문 그대로([ ] 자리는 하늘색, 복사는 `data-copy-text`). 휴대폰에서는 앞 몇 줄만 보이고 [전체 보기](복사는 늘 전체). 거르는 기준·마지막 확인은 한 문단으로 줄였어요.
- **움직임**: 첫 화면 장면, 섹션 제목 낱말이 흐림에서 또렷하게(한 번), 유리 머리 막대와 진행선, 자석 단추·빛 따라오는 상자·커서 고리(가는 포인터만). 키트 칸·실습 원문은 가만히. 움직임 줄이기면 신경망은 한 장면만 그리고 나머지는 처음부터 보여요. 화면 밖·탭 숨김이면 멈추고, 느린 기기는 해상도를 낮춰요.
- **글꼴**: Pretendard Variable(가변 굵기 장면), 숫자·시간 Space Grotesk, 프롬프트의 영문·기호만 JetBrains Mono.
- **키트**: 출석, 투표 5(첫 투표 2쪽·확인 문제 3개 `data-answer`·한 낱말 `data-kind="word"`), 실습 단계 3(`data-minutes` 40·40·30, 실습 쪽 레일에 `data-st-link`·`data-st-count`·`data-st-progress`), 보드 1(보드는 첫 것만 실시간이라 실습 1·3이 같이 씀), 교재 넘기기, 질문, 설문, 자료실, 모음.

## 그대로 복제하지 마세요
어두운 회로판·신경망은 'AI 시대 수업 설계'라는 이 교재의 은유에서 나왔어요. 다른 연수에 WebGL 망·주황/하늘색 문법을 옮기지 말고, 그 교재에서 같은 깊이로 새로 정하세요. 가져갈 것은 방법(당일 할 일로 구성, 설명은 한 줄 + 교재 쪽, 교재의 색 규칙을 사이트 문법으로, 대표 그림 하나만 크게)이에요.

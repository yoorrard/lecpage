# 학교 데이터로 수업 바꾸기 — 레퍼런스

가상의 교사 데이터 리터러시 연수(3시간). 교재 `material/교재.pdf`(16:9, 16쪽)를 읽고 `site/`를 직접 썼어요. 학교·기관·인물·수치는 모두 연수용 가상 예시예요.

## 디자인 판단
- **결**: 스위스 격자 × 데이터 이야기. 교재의 잉크·종이 두 색과 신호색 하나(#f2441a, 밝은 바탕의 작은 글자는 #c2370f), 12칸 격자 선, 아주 큰 좁은 숫자(Archivo 62% 폭)를 그대로 웹으로.
- **첫 화면**: 교재 1·2쪽의 두 그림을 한 장면으로. 한 학기 기록 1,440칸(30명 × 12주 × 4종)이 주차 순서로 채워지며 숫자가 세어지고, 7주차 네 줄이 신호색으로 바뀐 뒤 3반의 12주 선이 그어져 41%에 멈춰요. 칸에 마우스를 올리면 '14번 학생 · 7주차 · 형성평가 기록'처럼 그 칸이 무엇인지 알려 줘요(값은 지어내지 않음).
- **스크롤 이야기**: 교재 6쪽 '평균 72점의 반'을 네 단계로. 번호순 점 → 점수순 벌떼 그림 → 평균·중앙값 선 → 60점 미만 9명. PC는 그림을 붙여 두고 글이 지나가며 바뀌고(sticky), 휴대폰은 옆으로 넘기는 칸이라 화면 길이를 아껴요.
- **직접 해 보는 그림 셋**: ① 12주의 맥박(교재 7쪽)을 7~12주차만 짐작해 그리고 정답 보기(마우스·손가락·화살표 키) ② 실습 1 안의 기준 점수 밀대와 평균·중앙값 전환 ③ 2부 '질문 → 차트'(교재 10쪽): 같은 48개 점이 꺾은선 ↔ 점 분포로 옮겨 가고 막대는 0에서 자라요.
- **움직임**: 첫 화면 제목 가려 올리기·숫자 세기·선 긋기, 읽기 진행 막대와 숫자 띠·부 번호는 CSS 스크롤 타임라인(지원 브라우저만), 마무리 문장 가려 올리기. 시간 재기는 웹 애니메이션 하나를 시계로 써서 끝으로 보내면 끝 모습이 그려져요(검수 그림·인쇄에서도 온전). `prefers-reduced-motion`이면 처음부터 다 그려진 모습.
- **키트**: 출석, 투표 5(첫 투표 2쪽, 퀴즈 4개는 정답 `data-answer`와 교재 쪽 `data-page`), 실습 단계 3(`data-minutes` 25·30·25), 자료실(가상 CSV 2개), 모음, 교재 넘기기, 질문, 과제 보드, 설문(교재 16쪽 문항 그대로).
- **휴대폰**: 키트 칸을 빼고 10화면 안. 띠 장식은 숨기고, 첫 화면은 일시·장소를 숫자 그림보다 앞에, 프롬프트와 이야기 단계는 옆으로 넘기는 칸.

## 그대로 복제하지 마세요
신호색·좁은 숫자·벌떼 그림은 숫자로 말하는 이 교재에 맞춘 거예요. 가져갈 것은 방법(교재 그림을 직접 만지는 그림으로, 움직임은 끝 모습이 늘 온전하게, 휴대폰은 길이를 따로 설계)이에요.

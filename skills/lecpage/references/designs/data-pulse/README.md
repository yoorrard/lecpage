# 학교 데이터로 수업 바꾸기 — 레퍼런스

가상의 교사 데이터 리터러시 연수(3시간). 교재 `material/교재.pdf`(16:9, 16쪽)를 읽고 `site/`를 직접 썼어요. 학교·기관·인물·수치는 모두 연수용 가상 예시예요.

## 디자인 판단
- **사이트는 당일 도구**: 교재 내용(평균·중앙값 설명, 차트 이야기)은 교재 넘기기와 강사에게 맡기고, 사이트에는 참가자가 그날 하는 일만 둬요. 부마다 한 줄 핵심 + '교재 N쪽' 링크(`#deck-pN`)뿐이에요.
- **두 쪽**: `index.html`(오늘) = 지금 칸 → 오늘의 흐름 → 입장(출석·예시 데이터 받기·첫 투표) → 교재 넘기기 → 실습 길 → 질문·퀴즈 → 과제(보드) → 만족도 조사·다시 찾기. `practice.html`(실습) = 실습 세 가지의 단계, 복사할 수식·프롬프트 원문, 확인 도구, 모음. 실습 중 곁눈질은 실습 쪽 하나로 끝나요.
- **지금 칸**: 첫 화면의 신호색 칸이 연수 전(D-n·입장하기), 중(지금 시각·지금 순서·그 순서로 가는 단추), 뒤(과제 마감·과제 보기)를 바꿔 보여 줘요. 같은 시각에 흐름 표에 빨간 세로선이 서요.
- **결**: 스위스 격자 × 데이터. 잉크·종이 두 색과 신호색 하나(#f2441a, 밝은 바탕 작은 글자 #c2370f), 12칸 격자 선, 아주 큰 좁은 숫자(Archivo 62% 폭). 첫 화면에 교재 1·2쪽의 기록 1,440칸(마우스를 올리면 '14번 학생 · 7주차 · 형성평가 기록')과 표지의 12주 선.
- **그림은 실습 도구로만**: 실습 1의 기준 점수 밀대(시트에서 센 수가 맞는지 확인), 실습 2의 차트 모양 고르기(같은 48개 점이 꺾은선·점 분포로 옮겨 가고 막대는 0에서 자람)와 점검표(이 기기에만 저장). 설명용 스크롤 이야기는 두지 않아요.
- **움직임**: 첫 화면 제목 가려 올리기·지금 칸 펼치기·숫자 세기·선 긋기, 읽기 진행 막대(CSS 스크롤 타임라인), 흐름 막대 자라기, 마무리 문장. 끝으로 보내면 끝 모습이 그려지는 시계를 써서 검수 그림·인쇄에서도 온전하고, `prefers-reduced-motion`이면 정지 모습이에요.
- **키트**: 출석, 자료실(가상 CSV 2개), 투표 5(첫 투표 2쪽, 퀴즈 4개는 `data-answer`·`data-page`), 교재 넘기기, 실습 단계 3(`data-minutes` 25·30·25, `data-st-link`·`data-st-count`·`data-st-progress`), 모음, 질문, 과제 보드, 설문(교재 16쪽 문항 그대로).
- **휴대폰**: 오늘 쪽 약 5화면, 실습 쪽 약 4화면(키트 칸 제외). 프롬프트는 옆으로 넘기는 칸.

## 그대로 복제하지 마세요
신호색·좁은 숫자·기록 칸은 숫자로 말하는 이 교재에 맞춘 거예요. 가져갈 것은 방법(교재 설명은 쪽 그림에 맡기고 한 줄 + 쪽 링크, 첫 화면에 '지금 할 일' 하나, 그림은 실습 도구일 때만)이에요.

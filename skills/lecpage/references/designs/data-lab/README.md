# 데이터로 읽는 우리 반 — 레퍼런스

가상의 교사 데이터 실습 연수(3시간). 교재 `material/교재.pdf`를 읽고 `site/`를 직접 썼어요.

## 디자인 판단
- **흐름**: 연수 당일에 쓰는 사이트. 첫 화면에 제목·날짜·시간·장소·강사·이수 조건과 '지금' 상태(180분 막대)를 모으고, 흐름 → 준비(출석·첫 투표) → 실습 다섯 단계 → 교재 넘기기 → 질문 → 마무리(설문·연수 후) 순서.
- **정체성**: 교재의 모눈·시트 열 글자·빨간 펜·형광펜을 웹 부품으로. 위 막대는 스프레드시트의 이름 상자와 수식 입력줄이라 지금 보는 곳을 알려 줘요(장식이 아니라 위치 표시).
- **글꼴**: 제목은 Noto Serif KR(데이터를 '읽는' 글), 본문 IBM Plex Sans KR, 시간·수식만 IBM Plex Mono. 한글 라벨에 고정폭을 쓰면 낱말 사이가 벌어져 피했어요.
- **색**: 종이 #f7f5ef, 잉크 #1a1d21, 빨간 펜 #b33a1f는 번호·지금·주 단추에만. 형광펜은 제목과 '지금' 줄에만. 어두운 모드 색은 따로.
- **움직임**: 첫 화면 형광펜·동그라미, 차트가 보일 때 선 긋기 한 번씩. 기본은 다 그려진 모습이라 캡처·인쇄에서도 온전해요.
- **키트**: 출석, 투표 2, 실습 단계 5, 보드, 교재 넘기기, 질문, 설문. 실습 레일은 `data-st-link`·`data-st-count`·`data-st-progress`로 진행 표시와 이어져요.
- **쪽 제목**: 교재 넘기기 캡션·강사 화면 쪽 목록에 '1부 · …'처럼 교재의 부·실습 이름을 붙이려고 `lecpage.json`의 `pages`로 고쳤어요. 제목 글꼴은 `theme.fontHeading`으로 강사·발표 화면·QR 안내문에도 이어져요.

## 그대로 복제하지 마세요
이 판단은 시트·차트를 다루는 이 교재에 맞춘 거예요. 다른 연수에 수식 입력줄·모눈·빨간 펜을 옮기지 말고, 그 교재의 성격에서 같은 깊이로 새로 정하세요. 가져갈 것은 방법(첫 화면 위계, 당일 쓰임, 교재 정체성을 웹 부품으로 바꾸기)이에요.

# 신입생 학부모 설명회 — 레퍼런스

가상의 누리봄중학교 2027학년도 신입생 학부모 설명회(90분, 발표 다섯 꼭지). 학교가 인쇄해 나눠 주는 A4 자료집 `material/안내자료.pdf`(15쪽)를 읽고 `site/`를 직접 썼어요. 대상은 학부모(`audience: "parents"`)예요.

## 디자인 판단
- **동반자 사이트**: 설명은 발표와 자료가 해요. 자료집 내용을 글로 옮기지 않고, 사이트에는 지금 어디인지·자료 따라 보기·이름 없이 질문·집에 가서 다시 찾을 것(입학 전 날짜·준비물·연락처)·회신서만 둬요.
- **순서가 곧 자료 지도**: 순서마다 그 꼭지의 자료 쪽(`#deck-p7`)으로 가요. 첫 화면 '지금' 줄도 시각으로 지금 꼭지와 그 쪽을 알려 줘요.
- **정체성**: 공문·가정통신문의 교표, 굵은 줄+가는 줄 장 제목, □ 표시, 줄만 있는 표, 회신서 절취선을 웹 부품으로. 제목은 학교안심 알림장, 본문은 Pretendard GOV.
- **학부모라서**: 본문 18px, [글자 크게]로 21px(이 기기에 기억), 전화번호는 누르면 걸림, 짧은 문장. 출석·실습 단계는 넣지 않았어요.
- **색**: 흰 바탕에 학교 초록 하나(7.8:1), 시험 날짜만 주황. 어두운 모드는 색을 따로 정했어요.
- **움직임**: 첫 화면 이중선 긋기 한 번, 바로 가기로 옮긴 장 제목 잠깐 표시. 움직임 줄이기면 없음.
- **A4 세로 쪽**: 키트 기본 16:9 틀에서는 휴대폰에서 쪽이 작아져 쪽 비율 그대로 보이게 덮어썼어요.

## 그대로 복제하지 마세요

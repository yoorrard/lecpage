# 그림책 한 장, 마음 한 뼘 — 레퍼런스

가상의 그림책 사회정서학습(SEL) 교사 실습 연수(3시간). 교재 `material/교재.pdf`(A4 가로 그림책 교재 16쪽)를 읽고 `site/`를 직접 썼어요. 기관·사람·그림책은 모두 지어낸 것이에요.

## 디자인 판단
- **흐름**: 첫 화면(제목·일시·장소·강사·이수, 시각에 따라 바뀌는 '지금' 줄과 주 단추) → 차례(시간표·목표·이수 기준) → 들어가며(출석·마음 색 투표) → 1부(다섯 역량·퀴즈) → 그림책 → 실습 세 가지 → 교재 넘기기 → 질문 → 과제·만족도 조사 → 뒤표지.
- **정체성**: 교재의 찢은 종이 콜라주, 크림 종이, 네 가지 마음 색(노랑·파랑·빨강·보라), 주인공 참새 '콩이'를 웹 부품으로 옮겼어요. 첫 화면은 펼친 그림책(왼쪽 쪽은 글, 오른쪽 쪽은 그림)이고, 섹션 경계는 찢긴 종이 가장자리, 끝은 붉은 천 뒤표지예요.
- **그림**: 사람이 그린 결의 인라인 SVG. 참새 몸은 몸통 타원과 머리 원을 합친 윤곽을 극좌표로 계산해 그려서, 같은 식으로 깃털이 '부푼' 모양까지 이어서 바꿀 수 있어요(교재 그림과 사이트 그림이 같은 식). 손그림 떨림(feTurbulence + feDisplacementMap)과 종이 그림자 필터는 정적인 층에만.
- **움직임**(움직임 줄이기면 모두 꺼지고, 기본은 다 그려진 모습):
  - 처음 열 때 한 번 표지가 넘어가고, 콜라주 조각이 차례로 놓이며 콩이 윤곽이 선으로 그려져요.
  - 첫 화면 층마다 깊이가 달라 마우스·스크롤에 시차로 움직여요(화면 밖이면 멈춤, 휴대폰은 반복 움직임 없음).
  - 콩이를 누르면 마음이 바뀌고(설레요 → 깜짝이야 → 속상해 …) 깃털이 부풀어요.
  - 머리 막대의 콩이는 빠르게 스크롤하면 깃털이 부풀고, 멈추면 그 섹션의 표정으로 돌아와요. 막대 아래 연필 선이 스크롤 진행을 그려요.
  - 그림책은 [다음 장]·화살표 키·밀기로 쪽이 넘어가요(PC는 오른쪽 쪽이 접혀 넘어가고 휴대폰은 한 쪽씩). 2장에서는 본문대로 깃털이 세 번에 나눠 부풀고, 3장에서는 '하나 둘 셋 넷'에 맞춰 가라앉아요.
  - 마음 이름 카드: 낱말 24개를 누르면 카드가 펼쳐지고, 뒤집으면 교재의 짝 활동 문장("나도 ○○할 때 ○○했어.")과 마음 온도(1~5)가 나와요. [한 장 뽑기]는 카드 부채가 펼쳐졌다 한 장을 내놓아요.
- **휴대폰**: 곁눈질용으로 줄였어요. 실습은 진행 표시가 탭이 되어 한 번에 하나만 보이고(시간·주소 `#st-s2`에 맞춰 열림), 다섯 역량은 옆으로 넘기고, 목표·놀이 설명은 교재 쪽 링크로. 강의 기능 칸을 빼고 10화면 안.
- **글꼴**: 제목 송명(Song Myung, 그림책 표제 같은 옛 명조), 손글씨 메모 감자꽃(Gamja Flower), 본문 Pretendard, 숫자 몇 곳만 Fraunces 기울임. 송명은 굵기가 하나라 가짜 굵게를 끔(`font-synthesis:none`).
- **색**: 종이 #f4ecdc, 잉크 #2a2320, 강조 #a93b24(번호·지금·주 단추). 마음 색은 글이 올라가는 곳에서 옅은 색(#f5d78f·#bcd2e8·#f3b4a0·#cfbde0)으로 써서 잉크 글이 4.5:1 넘게. 그림책 섹션은 밤 책상(#212943)과 스탠드 불빛. 어두운 모드 색은 따로.
- **키트**: 출석, 투표 3(마음 색은 교재 2쪽, 역량 퀴즈 `data-answer`는 5쪽, 마음 낱말 `word`는 11쪽에 묶음), 실습 단계 3(`data-minutes` 35·30·40), 보드(분류 '실습 1 질문'·'과제', 사진 2장), 모음, 교재 넘기기(A4 가로), 질문, 설문(교재 16쪽 다섯 문항).

## 그대로 복제하지 마세요
이 판단은 그림책 한 권으로 하는 마음 수업 연수에 맞춘 거예요. 다른 연수에 참새·찢은 종이·네 마음 색·밤 책상을 옮기지 말고, 그 교재의 성격에서 같은 깊이로 새로 정하세요. 가져갈 것은 방법(교재의 주인공을 계산된 그림으로 만들어 교재와 사이트에서 같이 쓰기, 장식이 아니라 뜻이 있는 움직임, 휴대폰에서는 실습을 탭으로)이에요.

# 마음이 먼저 도착하는 교실 — 레퍼런스

가상의 사회정서학습(SEL) 교사 나눔 연수(90분, 현장과 Zoom). 교재 `material/교재.pdf`(A4 세로 자료집 16쪽)를 읽고 `site/`를 직접 썼어요.

## 디자인 판단
- **쓰임**: 이야기·성찰·짝 활동 연수라 참가자는 강사의 이야기를 듣고 자료집을 봐요. 그래서 사이트는 이야기를 다시 옮겨 적지 않고 곁에 두는 동반자로 짰어요: 지금 몇 시·무엇을 하는지, 그때 할 일, 자료집 쪽, 참여(마음 날씨 투표·나눔 보드·익명 질문·성찰 설문). 이야기 세 편은 흐름의 한 줄과 자료집 쪽 그림(교재 넘기기, `#deck-p4` 링크)으로만.
- **첫 화면**: 제목·일시·장소·강사 아래 '지금' 한 줄과 주 단추. 주 단추는 시각에 따라 바뀌어요(시작 전 마음 날씨 고르기 → 이야기 동안 자료집 따라 보기 → 짝 활동 → 보드 → 설문).
- **정체성**: 자료집의 해가 뜨는 지평선과 번지는 물결, 마음 날씨 선 그림, 이야기마다 바뀌는 날씨 색(흐림 회청 → 아침 살구 → 비 갠 세이지)을 흐름의 줄 색과 자료집 바로 가기에 그대로 썼어요. 끝은 밤 남색 띠에 맺음 한 문장.
- **글꼴**: 제목·인용은 고운바탕(손으로 쓴 듯한 이야기 결), 본문·단추는 Pretendard. 둘 다 나눠 받는 웹 글꼴.
- **색**: 종이 #f8f3ec, 잉크·강조 남색 하나(#222a45·#2e3a74), 살구 해는 장식·지금 표시에만. 어두운 모드에서는 강조가 살구 해로 바뀌어요.
- **키트**: 투표 셋(마음 날씨·한 낱말·내일 해 볼 것), 보드(사진 받지 않음: 아이 사진이 올라오지 않게), 질문, 교재 넘기기(A4 세로 비율), 설문. 실습 단계는 쓰지 않았어요(나눔 중심).
- **움직임**: 첫 화면 해가 한 번 떠오르는 것뿐, 기본은 다 그려진 모습.

## 그대로 복제하지 마세요
이 판단은 이야기 자료집으로 하는 성찰 연수에 맞춘 거예요. 다른 연수에 해·물결·마음 날씨·남색과 살구색을 옮기지 말고, 그 교재의 성격에서 같은 깊이로 새로 정하세요. 가져갈 것은 방법(강의 내용은 교재 쪽 그림에 맡기고 사이트는 지금·할 일·참여만, 시각에 따라 바뀌는 첫 화면 단추, 교재 모티프를 길잡이 부품으로 바꾸기)이에요.

# 레퍼런스 사이트

AI가 교재 원본을 읽고 Skill 흐름 그대로 만든 강의 운영 사이트 사례예요. 셋 다 연수 당일에 참가자가 휴대폰에 열어 두고 쓰는 사이트이고, 결·글꼴·움직임이 서로 달라요. 구성·배치를 베끼지 말고 판단하는 방식(당일 쓰임 순서, 교재 내용은 교재 넘기기에, 교재의 디자인을 사이트 문법으로)을 이어받아요. 결·글꼴 짝·움직임 기법은 `../design-library.md`에 있어요.

## 쓰는 법
- 폴더마다 `site/`(사이트 파일), `material/교재.pdf`(그 사이트를 만든 교재), `lecpage.json`(연수 정보), `notes.json`(분위기 한 줄·키트·글꼴·색), `README.md`(디자인 판단)가 있어요. 먼저 `README.md`만 읽고, 필요할 때만 `site/`의 CSS·HTML을 봐요.
- 강사가 "이런 느낌으로"라며 사례를 고르면 그 `notes.json`의 `mood`(분위기 설명)를 지금 교재에 맞게 옮겨요.
- 웹앱은 이 폴더를 빌드 때 조립해 참고 디자인 화면과 첫 화면에 보여 주고(`app/scripts/prepare.mjs`), 먼저 해보기는 `neo-teach`의 교재와 사이트 파일을 한 번의 AI 답 꼴로 씀(`app/src/data/demo-run.js`). 조립·검수는 `npm run examples`.

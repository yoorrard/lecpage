# 레퍼런스 사이트

AI가 교재를 읽고 자유롭게 만든 완성도 높은 강의 사이트 사례예요. **참고만 하고 따르지 않아요.** 구성·배치를 베끼지 말고, 위계·여백·교재 디자인을 이어받는 방식만 봐요. 디자인은 늘 지금 교재에서 출발해요(`../design-principles.md`).

## 쓰는 법
- 폴더마다 `site/`(사이트 파일), `material/교재.pdf`(그 사이트를 만든 교재), `lecpage.json`(연수 정보), `notes.json`(분위기 한 줄·키트·글꼴·색), `README.md`(디자인 판단)가 있어요. 먼저 `README.md`만 읽고, 필요할 때만 `site/`의 CSS·HTML을 봐요.
- 강사가 "이런 느낌으로"라며 사례를 고르면 그 `notes.json`의 `mood`(분위기 설명)만 가져와 지금 교재에 맞게 옮겨요.

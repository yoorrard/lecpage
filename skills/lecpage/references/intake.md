# 물어볼 것

교재를 읽은 뒤, **확실하지 않은 것만** 고르기형(선택지 + "직접 입력")으로 **한 번에** 물어요. 보통 2~4문항, 많아야 6개. 교재와 대화에서 알아낸 것은 묻지 않고 한 줄로 알려요. 예: "교재 30쪽을 읽었어요. 12월 3일 오후, 본관 컴퓨터실에서 하는 생성형 AI 실습 연수로 잡았어요. 세 가지만 확인할게요."

디자인(색·분위기·움직임)은 묻지 않아요. 교재에서 정하고, 만든 뒤 화면 그림을 보여 주며 고쳐요.
"알아서 해 주세요"거나 답을 기다릴 수 없으면 아래 기본값으로 만들고, 무엇을 가정했는지 한 줄로 알려요.

## 1. 자주 묻는 것 (교재로 알 수 없을 때만)
| 질문 | 선택지 | 적는 곳 |
|---|---|---|
| 어떤 연수인가요? | 교내 자율연수 / 교육청 승인 직무연수(이수 처리) / 설명회·컨퍼런스 / 학생 대상 | `lecpage.json` `admin.kind`: school·official·conference·student(학생이면 `audience: "students"`도) |
| 연수 중에 쓸 참여 기능(여러 개) | 질문 받기 / 도움 요청·진행 현황 / 투표·워드클라우드 / 나눔 보드 / 출석·이수 확인 / 만족도 설문 / 필요 없음 | `features` + 그 자리 표시(`references/kit.md`) |
| 참가자 기기·인터넷은?(여러 개) | 노트북·크롬북 / 휴대폰 위주 / 학교망이라 막히는 사이트가 있음 / 인터넷이 없거나 아주 느림 | 디자인 판단(휴대폰 위주면 더 단순하게), 배포 판단(없으면 `pack`), 접속 확인 쪽 안내 |
| 몇 명쯤인가요? | 30명 이하 / 31~100명 / 101~300명 / 300명 넘음 | 참여 기능 서버 고르기(`decide-infra --size`) |

## 2. 상황별 (해당할 때만)
| 언제 | 질문 | 적는 곳 |
|---|---|---|
| 날짜·시간·장소가 교재에 없거나 여러 개일 때 | 이 날짜·장소가 맞나요?(찾은 것 보여 주기 / 직접 입력) | `sessions`·`venue` |
| 온라인·혼합 낌새가 있을 때 | 오프라인 / 온라인 / 둘 다 → 온라인이면 회의 주소(Zoom·Meet) | `mode`, 회의 주소는 `lecpage.teacher.json` `joinUrl` |
| 직무연수인데 이수 기준을 모를 때 | 출석 기준은? 90% / 80% / 직접 입력 | `admin.completionRate`·`admin.hours` |
| 문의처가 없을 때 | 참가자가 연락할 곳은? 강사 이메일 / 담당자 연락처 / 없음 | `contact` |
| 기관 설문을 따로 쓸 때 | 설문 주소(구글 설문 등)가 있나요? | `lecpage.teacher.json` `surveyUrl` |
| 교재 파일을 나눠 줄 때 | 교재 PDF 내려받기를 허용할까요? | 허용하면 `site/files/`에 넣고 자료실 자리 표시 |
| 배포할 때 | 누가 볼 수 있게 할까요? 주소를 받은 사람만(기본) / 누구나 검색으로 | `lecpage.teacher.json` `access`: link·public |

연수 목표·강의 흐름은 묻지 않아요. 교재에서 읽어 설계하고, 건넬 때 "이렇게 구성했어요"로 확인받아요.

## 3. 기본값 ("알아서"일 때)
| 항목 | 기본값 |
|---|---|
| 연수 종류 | 교재에서 찾은 것, 없으면 교내 자율연수(`school`) |
| 참여 기능 | 실습이 있으면 `qa`·`help`·`progress`(실습 단계 자리 표시와 함께), 강의 중심이면 `qa`·`poll`. 직무연수면 `attendance`도(입실·퇴실 기록이 있어야 이수자 명단이 나옴) |
| 기기·인터넷 | 노트북, 인터넷 잘 됨 |
| 공개 범위 | `link`(주소를 받은 사람만, 검색 제외) |
| 참여 기능 서버 | 없음(연습 모드). 배포할 때 앱의 바로 배포나 `publish --live`로 연결 |

## 4. 강사에게 받은 값은 어디에
- 연수 내용(제목·일정·장소·강사·기능·색): `work/lecpage.json`
- 강사만 정하는 값(`access`·`siteUrl`·`joinUrl`·`shortUrl`·`surveyUrl`·`live`·`privacy`·`keepUntil`): `work/lecpage.teacher.json`(꼴: `references/cli.md` 3절)
- 강사가 따로 부탁한 말(강조할 내용·분위기·대상): 설계에 그대로 반영하고, 반영한 곳을 건넬 때 한 줄로 알려요.

# 문구 규칙

연수 사이트의 글은 길 안내다. 참가자는 휴대폰을 들고 서서, 실습 중에 곁눈으로 읽는다. 짧고, 바로 알아듣고, 사람이 쓴 것처럼 읽혀야 한다.
금지 목록과 점검은 `engine/src/prompt/copy-rules.js` 한 곳에서 관리한다(AI 프롬프트에도 같은 목록이 들어감).

## 1. 원칙
1. **해요체로 짧게.** 한 문장에 한 가지, 70자 안. 길면 둘로 나눈다. 강사 콘솔은 더 짧게("공지 보내기", "결과 공개"). 개인정보 안내만 합니다체.
2. **버튼은 동작, 제목은 명사.** 버튼 "실습 시작하기", "설문 열기", "제출하기". 제목 "만족도 조사", "연수 목표". 부탁은 제목이 아니라 버튼이 한다.
3. **흔한 용어는 그대로.** QR, URL, CSV, PDF, Wi-Fi, 로그인, 프롬프트, AI, 링크, 앱. 괄호로 풀어 쓰지 않는다. 낯선 약어만 처음 한 번 우리말을 앞에 둔다: "사회정서학습(SEL)".
4. **사실만.** 꾸밈말·감탄·권유로 분위기를 띄우지 않는다. 무엇을 하는지, 무엇이 생기는지를 쓴다.
5. **같은 것은 같은 이름.** 버튼이 "올리기"면 알림도 "올렸어요". 참여 코드(입장 코드 아님), 막혔어요(버튼)·도움 요청(콘솔 목록).
6. **알림·빈 화면은 다음 할 일까지.** "아직 질문이 없어요. 첫 질문을 올려 주세요." 오류는 무엇이 안 됐고 어떻게 하면 되는지. 사과하지 않는다.
7. **제작 과정을 드러내지 않는다.** "원고의 두 번째 미션", "교재를 재구성했습니다" 같은 만든 사람 쪽 이야기는 빼고 참가자가 할 일만.
8. **장식 금지.** 제목 위 영어 대문자 라벨(DATE, SPEAKER, TODAY'S WORKSHOP), 이모지, 느낌표 여러 개. 번호(01·02)는 실제 순서가 있을 때만.

## 2. 칸별 길이
| 칸 | 길이 | 예 |
|---|---|---|
| 메뉴(nav) | 2~4자 | 실습, 교재, 질문, 연수 후 |
| 버튼(ctas, links) | 12자 안 | 실습 시작하기, Zoom 입장 |
| 섹션 제목 | 한 줄(30자 안) | 다섯 정거장을 차례로 |
| 리드(lead) | 1~2문장 | 세 가지만 해 두면 바로 시작할 수 있어요. |
| 연수 목표 | 2~4개, "~할 수 있어요" | 흩어진 학습 기록을 한 표로 모을 수 있어요 |
| 실습 확인(outcome) | 결과물 이름이나 질문 하나 | 필터가 걸린 깔끔한 표 한 장 |
| 실습 메모(note) | 막히는 곳과 해결법 한두 줄 | AI에는 이름·연락처를 넣지 마세요. |

## 3. 고치기 전 → 후
| 전 | 후 | 까닭 |
|---|---|---|
| TODAY'S WORKSHOP · HANDS-ON | (빼거나) 한빛교육연수원 | 영어 장식 |
| DATE 2026년 11월 4일 / SPEAKER 유영재 | 일시 2026. 11. 4.(수) / 강사 유영재 | 우리말 라벨 |
| 설명은 짧게, 실습은 바로. (연수명 대신 제목) | 제목은 연수명, 구호는 부제로 | 무슨 연수인지 먼저 |
| 원고의 두 번째 미션: 사이트 음소거, 분할 보기 | 사이트 음소거와 분할 보기를 해 봐요. | 제작 과정 노출 |
| 이 연수를 통해 AI 활용 역량을 함께 키워 보아요! | 수업 자료 세 가지를 AI로 만들어 봐요. | 번역투·빈 권유 |
| 다양한 에듀테크 도구를 효과적으로 활용하는 방법을 알아보겠습니다. | 패들렛과 띵커벨로 모둠 활동을 열어요. | 흐린 꾸밈말·예고 |
| QR 코드(Quick Response Code)를 스캔하여 접속하실 수 있습니다. | QR을 찍어 들어오세요. | 풀어쓰기·공문투 |
| 완료! 다음 실습으로 넘어가 볼까요? | 완료했어요. | 감탄·권유 |
| 실시간 질문은(는) 실시간 연결이 켜진 사이트에서 쓸 수 있어요. 지금은 연결이 꺼져 있어요. | 실시간 연결을 켜면 여기서 쓸 수 있어요. | 군더더기 |
| 만족도 조사에 참여해 주세요 (제목) | 만족도 조사 (제목) + 설문 열기 (버튼) | 제목은 명사 |
| 결과를 확인하고, 내 수업에 맞게 한 가지를 수정해 보세요. (실습 다섯 개에 똑같이) | 필터가 걸린 표 한 장이 보이나요? | 실습마다 다른 확인 |
| 공감 많은 순 · 최신 순 | 공감순 · 최신순 | 굳은 말 |
| 핵심 포인트 · 꿀팁 | 핵심 · 팁 | 상투어 |
| 함께 생각을 나누는 시간을 가져요 | 생각을 나눠요 | 군더더기 |
| 도움을 요청했어요. 곧 갈게요! | 도움을 요청했어요. 곧 갈게요. | 느낌표 |

## 4. 쓰지 않는 말
| 표현 | 대신 |
|---|---|
| ~를 통해(서) | ~로, ~에서, ~하며 |
| ~할 수 있습니다 (참가자 화면) | ~할 수 있어요, ~해요 |
| 함께 ~해 보아요, 함께해요! | ~해 보세요, ~해요 (무엇을 하는지 동사로) |
| 알아보겠습니다, 알아볼까요 | 알려 줄 내용을 바로 |
| ~하는 시간을 가져요 | ~해요 |
| 여정, 탐험, 핵심 포인트, 꿀팁, 인사이트를 얻다 | 과정, 살펴보기, 핵심, 팁 |
| 혁신적인, 획기적인, 놀라운, 완벽한, 마법 같은 | (뺀다) |
| 느낌표 여러 개, 이모지 장식 | (뺀다. 반응 버튼처럼 기능인 것은 예외) |
| QR 코드(Quick Response Code), URL(인터넷 주소) | QR, URL |

줄이는 말(경고): 다양한, 효과적으로·효율적으로·체계적으로, 여러분, 활용하여, ~하기 위해서는, ~것입니다·진행됩니다·제공됩니다.

## 5. 표기
- 날짜 "2026. 11. 4.(수)", 시간 "15:10~16:40", 쪽 "34쪽", 인원 "30명".
- 메뉴·버튼에 마침표를 찍지 않는다. 문장에는 찍는다.
- 줄바꿈(`\n`)은 첫 화면 제목처럼 리듬이 필요한 곳에만.

## 6. 점검
```bash
node $SKILL/scripts/copy-lint.mjs work/blueprint.json   # 설계도
node $SKILL/scripts/copy-lint.mjs dist                  # 만든 사이트(index·console·screen·check·poster)
```
"고침"은 고친 뒤 다시 빌드한다. "살핌"은 맥락을 보고 정한다(교재 원문 인용이면 그대로 둬도 된다). 프롬프트·교재 쪽 글·강사 약력은 교재 원문이라 점검하지 않는다.

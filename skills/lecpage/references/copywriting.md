# 문구 규칙

연수 사이트의 글은 길 안내다. 참가자는 휴대폰을 들고 서서, 실습 중에 곁눈으로 읽는다. 짧고, 바로 알아듣고, 사람이 쓴 것처럼 읽혀야 한다.
금지 목록과 점검은 `engine/src/prompt/copy-rules.js` 한 곳(AI 프롬프트도 같은 목록). 앱까지 아우른 기준은 저장소의 `docs/writing.md`.

## 1. 원칙
1. **해요체로 짧게.** 한 문장에 한 가지, 70자 안. 강사 화면은 더 짧게("공지 보내기"). 합니다체는 개인정보 안내·인용·강사 자기소개만.
2. **능동, 가벼운 높임.** "저장되었습니다" → "저장했어요", "~하시겠어요?" → "~할까요?". 끝남·만료 같은 상태는 수동도 된다.
3. **단추는 동작, 제목은 명사.** 단추 "실습 시작하기", "설문 열기". 제목 "만족도 조사". 부탁은 단추가 한다. 창만 닫는 단추는 "닫기".
4. **정해진 말은 그대로.** QR, URL, PDF, AI, 프롬프트, 링크와 교육 행정 용어(직무연수, 이수 기준, 출석 확인, 차시)는 풀지 않는다. 낯선 약어만 처음 한 번: "사회정서학습(SEL)".
5. **사실만.** 꾸밈말·감탄·권유로 띄우지 않는다. 무엇을 하는지, 무엇이 생기는지.
6. **같은 것은 같은 이름.** 단추가 "올리기"면 알림도 "올렸어요". 참가자, 연수 코드, 참여 기능, 막혔어요(단추)·도움 요청(강사 화면).
7. **안내·빈 화면·오류는 다음 할 일까지.** "아직 질문이 없어요. 첫 질문을 올려 주세요." 사과하지 않는다.
8. **제작 과정을 드러내지 않는다.** "원고의 두 번째 미션", "교재를 재구성했습니다"는 빼고 참가자가 할 일만.
9. **장식 금지.** 제목 위 영어 대문자 라벨(DATE, SPEAKER), 이모지, 느낌표. 번호(01·02)는 실제 순서가 있을 때만.

## 2. 칸별 길이
| 칸 | 길이 | 예 |
|---|---|---|
| 메뉴(nav) | 2~4자 | 실습, 교재, 연수 후 |
| 단추(ctas, links) | 12자 안 | 실습 시작하기, Zoom 입장 |
| 섹션 제목 | 한 줄(30자 안) | 실습 다섯 가지를 차례로 |
| 리드(lead) | 1~2문장 | 세 가지만 해 두면 바로 시작할 수 있어요. |
| 연수 목표 | 2~4개, "~할 수 있어요" | 흩어진 학습 기록을 한 표로 모을 수 있어요 |
| 실습 확인(outcome) | 결과물 이름이나 질문 하나 | 필터가 걸린 깔끔한 표 한 장 |
| 실습 메모(note) | 막히는 곳과 해결법 한두 줄 | AI에는 이름·연락처를 넣지 마세요. |

## 3. 고치기 전 → 후
| 전 | 후 | 까닭 |
|---|---|---|
| TODAY'S WORKSHOP / DATE 2026년 11월 4일 | (빼거나) 일시 2026. 11. 4.(수) | 영어 장식 |
| 설명은 짧게, 실습은 바로. (연수명 대신 제목) | 제목은 연수명, 구호는 부제 | 무슨 연수인지 먼저 |
| 원고의 두 번째 미션: 사이트 음소거 | 사이트 음소거를 해 봐요. | 제작 과정 노출 |
| 이 연수를 통해 AI 활용 역량을 함께 키워 보아요! | 수업 자료 세 가지를 AI로 만들어 봐요. | 번역투·빈 권유 |
| 다양한 에듀테크 도구를 효과적으로 활용하는 방법을 알아보겠습니다. | 패들렛과 띵커벨로 모둠 활동을 열어요. | 흐린 꾸밈말·예고 |
| QR 코드(Quick Response Code)를 스캔하여 접속하실 수 있습니다. | QR을 찍어 들어오세요. | 풀어쓰기·공문투 |
| 완료! 다음 실습으로 넘어가 볼까요? | 완료했어요. | 감탄·권유 |
| 설문이 제출되었습니다. | 설문을 보냈어요. | 수동·합니다체 |
| 질문하시겠어요? | 질문할까요? | 과한 높임 |
| 실시간 기능이 꺼져 있습니다. | 참여 기능이 꺼져 있어요. 강사에게 알려 주세요. | 용어·다음 할 일 |
| 만족도 조사에 참여해 주세요 (제목) | 만족도 조사 (제목) + 설문 열기 (단추) | 제목은 명사 |
| 결과를 확인하고 한 가지를 수정해 보세요. (실습마다 똑같이) | 필터가 걸린 표 한 장이 보이나요? | 실습마다 다른 확인 |
| 함께 생각을 나누는 시간을 가져요 | 생각을 나눠요 | 군더더기 |
| 이수 기준 → 다 들었다고 인정받는 조건 | 이수 기준 (그대로) | 정해진 용어 |

## 4. 쓰지 않는 말
"~를 통해", "~할 수 있습니다", "함께 ~해 보아요", "알아볼까요", "~하는 시간을 가져요", 여정·탐험·핵심 포인트·꿀팁, 혁신적인·놀라운·완벽한, "되어지다", 느낌표, 이모지. 줄일 말: 다양한, 효과적으로, 여러분, 활용하여, ~하기 위해서는, ~것입니다. 전체 목록은 `copy-rules.js`.

## 5. 표기
- 날짜 "2026. 11. 4.(수)", 시간 "15:10~16:40", 쪽 "34쪽", 인원 "30명".
- 메뉴·단추·제목에 마침표를 찍지 않는다. 문장에는 찍는다. 줄임표는 "…".
- 줄바꿈(`\n`)은 첫 화면 제목처럼 리듬이 필요한 곳에만.

## 6. 점검
```bash
node $SKILL/scripts/copy-lint.mjs work/blueprint.json   # 설계도
node $SKILL/scripts/copy-lint.mjs dist                  # 만든 사이트
```
"고침"은 고친 뒤 다시 빌드한다. "살핌"은 맥락을 보고 정한다(교재 인용·명제형 맺음말이면 둬도 된다). 프롬프트·교재 쪽 글·강사 약력은 점검하지 않는다.

# 한국어 문구 규칙

연수 사이트의 글은 장식이 아니라 길 안내다. 짧고 평이하게, 사용자 쪽에서 쓴다.

- **버튼은 동작 그대로**: "실습 시작하기", "프롬프트 복사", "완료 체크", "교재 내려받기". "Submit", "확인하기" 같은 모호한 말을 피한다.
- **같은 동작은 같은 이름**: 버튼이 "올리기"면 알림도 "올렸어요".
- **존댓말 해요체**: "~해 보세요", "~할 수 있어요". 공문체(~바랍니다), 반말을 섞지 않는다.
- **한 문장 한 가지**: 40자 안팎. 길면 둘로 나눈다.
- **과장 금지**: "혁신적인", "놀라운", "완벽한" 같은 말, 느낌표 남발, 이모지 장식을 쓰지 않는다.
- **오류 문구**: 무엇이 안 됐고 어떻게 하면 되는지. 사과하지 않는다. 예: "질문을 올리지 못했어요. 잠시 뒤 다시 해 주세요."
- **빈 화면은 안내**: "아직 올라온 글이 없어요. 첫 글을 올려 주세요."
- **외래어·약어**: 처음 나올 때 풀어 쓴다(예: "SEL(사회정서학습)").
- **숫자**: 날짜 "2026. 11. 4.(수)", 시간 "15:10~16:40", 쪽 "34쪽".
- **제목 장식 금지**: 모든 제목 위에 영어 대문자 라벨(EYEBROW)을 붙이지 않는다. 번호(01·02)는 실제 순서가 있을 때만.
- **메뉴 이름(nav)**: 2~4자. 교재·도구·실습·질문·보드·자료·강사·설문.

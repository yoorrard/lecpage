# ZIP·USB로 나눠 주기 (인터넷 없이 열기)

> 사이트 폴더를 ZIP으로 묶어 메일·메신저·USB로 줍니다. 받은 사람은 압축을 풀고 `index.html`을 두 번 누르면 됩니다.

## 언제 고르나요
- 인터넷이 전혀 없음, 연수 뒤 **자료 보관용**, 기관 보고용 첨부.
- 고르지 말 것: 질문·투표 같은 실시간 기능이 필요할 때(→ `local-lan-classroom.md`), 참가자가 아이패드·휴대폰만 쓸 때(로컬 HTML 열기가 불편함).

## 비용
- 0원.

## 동작하는 것과 안 되는 것
| 기능 | file://로 열 때 |
|---|---|
| 본문·일정·슬라이드·프롬프트 복사 | ✓ (엔진 원칙: JS 없이도 내용이 보임) |
| 효과·테마 | ✓ (CDN 라이브러리는 인터넷 있을 때만) |
| 글꼴 | 인터넷 없으면 시스템 글꼴(맑은 고딕·Apple SD 고딕) |
| 진행 체크·기록(local) | ✓ 그 기기 안에만 저장 |
| 질문·투표·도움 요청(실시간) | ✗ |
| 영상(YouTube) | 인터넷 있을 때만 |

## 만드는 법
- 엔진 CLI: `node skills/lecpage/scripts/lecpage.mjs build <설계도.json> --target zip` ⚠️ 옵션 이름은 CLI 도움말 기준.
- 직접: 사이트 폴더 이름을 `연수명_날짜`로 바꾸고 압축.
  - Windows: 폴더 우클릭 → **압축(ZIP) 폴더로 보내기**(Windows 11은 **ZIP 파일로 압축**).
  - macOS: 폴더 우클릭 → **압축**.
- `live.provider`는 `none` 또는 `local`로 빌드합니다. CSP `<meta>`는 넣지 않습니다(file://에서 막힐 수 있음).
- `운영안내.md`, `DESIGN.md`는 참가자용 ZIP에서는 빼도 됩니다.
- 파일 이름은 영문·숫자 권장(한글 파일 이름은 일부 압축 프로그램에서 깨짐 ⚠️).

## 받은 사람 안내문(그대로 붙여 쓰기)
> 1. ZIP 파일을 내려받아 **압축을 풉니다**(ZIP 안에서 바로 열면 그림이 안 보일 수 있어요).
> 2. 풀린 폴더에서 `index.html`을 두 번 누릅니다.
> 3. 크롬·엣지·웨일에서 가장 잘 보입니다.

## 확인하기
- 다른 PC에서 압축을 풀고 인터넷을 끈 상태로 `index.html` 열기 → 슬라이드·메뉴·복사 버튼 확인.
- 크롬북: **파일** 앱에서 HTML 열기 ⚠️ 정책으로 막힌 학교 기기 있음.

## 되돌리기·고치기
- 고친 사이트로 ZIP을 다시 만들고 파일 이름에 버전을 붙여(`_v2`) 다시 나눕니다. 이전 ZIP은 "지워 주세요"라고 안내합니다.

## 연수가 끝난 뒤
- ZIP은 회수할 수 없으니 **개인정보(참가자 명단 등)가 들어 있지 않은지** 배포 전에 확인합니다.
- 기관 보관용이면 ZIP 이름에 날짜·버전을 붙여 보관합니다.

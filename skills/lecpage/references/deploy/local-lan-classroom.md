# 교실 LAN 수업 (강사 노트북이 서버)

> 인터넷이 없거나 학교망이 심하게 막혀도, **강사 노트북 + 작은 공유기**만 있으면 질문·투표·진행 체크가 됩니다. 참가자는 같은 와이파이에 붙고 QR만 찍으면 됩니다.

## 언제 고르나요
- 연수 장소 인터넷이 없음, 너무 느림, 외부 사이트·WebSocket이 막힘.
- 학생 대상이라 기록을 교실 밖으로 내보내고 싶지 않을 때.
- 고르지 말 것: 참가자가 각자 집·다른 장소에서 접속하는 온라인 연수.

## 비용
- 0원. 휴대용(여행용) 공유기가 있으면 가장 안정적(대략 2~4만 원대 ⚠️ 가격은 참고).

## 준비물
- 강사 노트북(Windows 10/11 또는 macOS), 충전기.
- **Node.js 22.5 이상**(https://nodejs.org 에서 LTS 설치, 2026-11 기준 24 LTS) 또는 Docker Desktop.
- lecpage 사이트 폴더 + `skills/lecpage/backends/node-server/`.
- 와이파이: 아래 표에서 하나.

| 와이파이 방법 | 동시 접속 | 장점 | 주의 |
|---|---|---|---|
| **휴대용 공유기**(권장) | 보통 20~50대 ⚠️ 제품별 | 안정적, 인터넷 없어도 됨 | 미리 이름·비밀번호 정해 두기 |
| 노트북 핫스폿(Windows "모바일 핫스폿") | 8대 안팎 ⚠️ | 장비 없음 | 노트북이 다른 와이파이에 붙어 있어야 켜지는 경우 있음 |
| 휴대폰 핫스폿 | 10대 안팎 ⚠️ | 장비 없음 | 데이터 소모, 배터리 |
| 학교 와이파이 | 많음 | 장비 없음 | **기기끼리 통신 차단(AP 격리)** 이 흔함 → 사전 확인 필수 |

## 따라 하기 — Node로 바로 실행(가장 간단)
node-server 하나가 **사이트와 실시간을 함께** 제공합니다(`--static`). 폴더 구성: `lecpage/site/`, `lecpage/node-server/`.

**Windows (PowerShell)**
```powershell
cd C:\lecpage
node .\node-server\server.mjs --static .\site --data .\data --port 8787 --admin-key "연수관리자키"
```
**macOS (터미널)**
```bash
cd ~/lecpage
node ./node-server/server.mjs --static ./site --data ./data --port 8787 --admin-key "연수관리자키"
```
- `--admin-key`를 빼면 서버가 키를 만들어 **처음 한 번** 화면에 보여 줍니다. 적어 두세요.
- `site/` 안의 `운영안내.md`·`DESIGN.md`는 그대로 열람될 수 있으니 실행 전에 다른 폴더로 옮겨 두세요.
- 옵션 전체는 `node-server/server.mjs` 머리말에 있습니다(업로드 한도 `--max-upload-mb`, 보관 기간 `--retention-days` 등).
- 처음 실행 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 누릅니다. 와이파이 네트워크 프로필이 "공용"이면 "개인"으로 바꿉니다(설정 → 네트워크 → 와이파이 → 속성).
- macOS: "들어오는 연결 허용"을 누릅니다.

## 따라 하기 — Docker Desktop(사이트·서버 한 번에)
`templates/deploy/server/`의 `docker-compose.yml`, `Caddyfile`, `.env`(LEC_SITE_ADDRESS=`:80`) → `docker compose up -d`. 참가자 주소는 `http://<노트북 IP>/`.

## 참가자 주소 만들기
1. 노트북 IP 확인
   - Windows: `ipconfig` → 무선 LAN의 **IPv4 주소**(예: 192.168.0.10)
   - macOS: `ipconfig getifaddr en0`
2. 주소: `http://192.168.0.10:8787/` (Docker면 `http://192.168.0.10/`).
3. `screen.html`을 프로젝터에 띄우면 큰 QR이 나옵니다. QR이 이 주소를 가리키는지 확인(엔진의 `meta.joinUrl`).
4. 칠판에도 주소를 적어 둡니다(QR 못 찍는 기기 대비).

## 확인하기 (연수 전날, 같은 장비로)
1. 휴대폰을 같은 와이파이에 붙이고 `http://<IP>:8787/check.html` → 사이트·실시간 초록(외부 글꼴·CDN은 빨강이어도 괜찮음: 시스템 글꼴로 보임).
2. `console.html`에서 관리자 키 → 휴대폰에서 질문 하나 보내 보기.
3. 노트북 **절전·화면 꺼짐·자동 업데이트**를 끄고 전원 연결.

## 알아 둘 점
- http(자물쇠 없음)라서 일부 브라우저 기능(클립보드 자동 복사 등)이 제한될 수 있습니다 ⚠️. 런타임은 대체 방법을 씁니다.
- 인터넷이 없으면 외부 링크(도구 사이트, 영상)는 열리지 않습니다. 필요한 자료는 사이트 `assets/media/`에 넣어 두세요.
- IP는 공유기가 바꿀 수 있습니다. 연수 직전에 다시 확인하거나 공유기에서 노트북 IP를 고정(DHCP 예약)하세요.
- 라즈베리 파이를 노트북 대신 써도 됩니다(64비트 OS + Node 22.5 이상, 또는 Docker). 전원만 꽂으면 켜지게 systemd로 등록.

## 되돌리기
- 사이트를 고치면 `site/` 폴더만 바꾸고 참가자에게 새로고침을 부탁합니다(서버 재시작 불필요).
- 서버가 이상하면 끄고(Ctrl+C) 다시 실행. 데이터는 `data/`에 남아 있습니다.

## 그날 문제가 생기면
- 아무도 접속 못 함: AP 격리 의심 → 휴대용 공유기/핫스폿으로 바꾸기, 방화벽 허용 확인.
- 일부만 접속: 공유기 동시 접속 한도 → 2~3명이 한 화면을 같이 보도록 안내.
- 노트북이 꺼짐: 다시 켜면 데이터 폴더(`data/`)에서 이어집니다.

## 연수가 끝난 뒤
1. 콘솔 CSV 내보내기 → 2. **전부 삭제** → 3. 서버 끄기(Ctrl+C 또는 `docker compose down`) → 4. `data/` 폴더 삭제.
5. 사이트를 계속 공유하려면 같은 폴더를 Cloudflare·GitHub Pages에 `live.provider: none`으로 다시 빌드해 올립니다.

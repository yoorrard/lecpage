# 디자인 품질 규칙 — 'AI 티' 없이, 디자이너가 만든 것처럼

lecpage가 그냥 "페이지 만들어 줘"와 다른 점은 이 규칙이 엔진(`runtime/lecpage.css`, `render/sections.js`)에 이미 들어 있고,
`scripts/design-lint.mjs`가 만든 쪽을 브라우저로 열어 기계적으로 확인한다는 점입니다. 사이트를 고치는 사람(AI 포함)은 이 문서를 지킵니다.

## 1. 원칙 다섯

1. **상자는 마지막 수단.** 묶음은 여백과 가는 선(hairline)으로, 위계는 글자 크기·굵기로 만든다. 상자는 대화상자·강사 콘솔 패널·보드 글처럼 '떼어 낼 수 있는 물건'에만.
2. **내용이 모양을 정한다.** 순서가 있으면 번호 목록, 시간이 있으면 시간표, 이름·설명 쌍이면 색인 목록. 똑같은 카드 세 장을 깔지 않는다.
3. **대담함은 한 곳에.** 첫 화면 제목·큰 숫자·마무리 문장 정도만 크게. 나머지는 조용하고 단정하게.
4. **강조색은 하나.** 번호·링크·지금 표시·초점에만. 색 띠·그라데이션 글자·장식 빛 번짐으로 꾸미지 않는다.
5. **한국어로 읽기 좋게.** 낱말 단위 줄바꿈, 한 줄 30~40자, 짧은 해요체 문구.

## 2. 하지 말 것 → 할 것 (이유)

| 하지 말 것 | 할 것 | 이유 |
|---|---|---|
| 알약 모양 꼬리표(둥근 배경 칩)로 분류·태그·상태 표시 | 작은 글자(13px, 600) + 가운뎃점(`생태·학교 숲·그림책`) | 칩이 줄마다 생기면 시선이 흩어지고 생성형 화면의 대표 버릇 |
| 상자 한쪽에 굵은 색 띠(`border-left: 4px`) | 띠 없이 여백·작은 제목, 필요하면 위쪽 가는 선 | 가장 잘 알려진 'AI 티'(impeccable `side-tab`) |
| 상자 안에 상자(카드 속 단계 상자 속 입력칸) | 상자는 한 겹. 입력칸만 테두리 | 깊이가 의미 없이 늘어 무겁다 |
| 모든 목록을 같은 크기 카드 격자로 | 번호 목록·시간표·색인·한 줄 목록 | 내용의 차이가 보이지 않는다 |
| 그라데이션 글자, 글자에 빛 번짐 | 한 가지 색, 크기·굵기로 강조 | 장식일 뿐 정보가 없다 |
| 섹션마다 아래에서 떠오르는 등장 효과, 카드 기울기, 흐르는 글자 띠 | 첫 화면 한 번, 숫자 세기처럼 의미 있는 움직임만 | 여기저기 움직이면 산만하고 흔한 기본값으로 읽힌다 |
| 이모지·✦ 같은 글리프를 아이콘으로 | 같은 굵기(1.8) 선 SVG 한 벌, 필요할 때만 | 크기·색이 기기마다 달라진다. 이모지는 반응 버튼 '내용'에만 |
| 제목 위 작은 영문 대문자 꼬리말(eyebrow) | 제목이 스스로 말하게. 주최 기관명은 보통 크기 글자 | 의미 없는 장식 라벨 |
| 이름 첫 글자를 담은 색 네모(도구 아이콘 흉내) | 이름 자체를 링크로, 주소는 고정폭 작은 글자 | 가짜 로고는 정보가 없다 |
| 장황한 안내문("~하시기 바랍니다", "~을(를) 클릭하세요") | 동사 + 목적어 짧게("자료 받기", "질문 올리기") | 읽는 시간을 줄인다 |

## 3. 글자

- **크기 단계(토큰)**: `--fs-xs 13` · `--fs-sm 15` · `--fs-base 17`(본문, 휴대폰 16) · `--fs-md 19` · `--fs-lg 20~24`(작은 제목) ·
  `--fs-h2s 28~40`(두 단 섹션 제목·큰 번호) · `--fs-xl 30~52`(섹션 제목) · `--fs-num 36~56`(큰 숫자) · `--fs-2xl 40~88`(첫 화면 제목).
  이 밖의 크기를 새로 만들지 않는다. 한 화면에 12가지가 넘으면 lint가 경고한다.
- **비율**: 섹션 제목 ÷ 본문 ≥ 1.6배(지금 넓은 화면 3배, 휴대폰 1.9배). 비슷한 크기 두 개로 위계를 나누지 않는다 — 크기를 못 키우면 굵기·색을 바꾼다.
- **굵기 대비**: 제목 700~800(글꼴이 한 굵기뿐이면 그 굵기), 작은 제목 700, 본문 400, 라벨 600. 본문에 600 이상을 길게 쓰지 않는다.
- **글꼴 역할**: 제목용 글꼴(`--font-display`)은 h1·h2·큰 숫자·인용·마무리 문장에만. h3 이하와 본문은 본문 글꼴. 장식 글꼴(검은고딕·주아·도현 등)을 작은 글자에 쓰지 않는다.
- **줄바꿈**: `word-break: keep-all`(낱말 단위) + `overflow-wrap: break-word`. 제목은 `text-wrap: balance`, 본문은 `pretty`.
- **한 줄 길이**: 한국어 본문 30~40자(`--measure: 38em`), 영어 45~75자. 넓은 화면이라고 글을 끝까지 늘이지 않는다.
- **자간**: 한국어 본문 0. 큰 제목만 -0.01em(명조) ~ -0.03em(굵은 고딕). -0.04em보다 좁히지 않는다. 대문자 넓은 자간 라벨을 쓰지 않는다.
- **행간**: 본문 1.75, 목록 설명 1.6, 섹션 제목 1.22, 첫 화면 제목 1.1 안팎(한국어는 영어보다 조금 넉넉히).
- **숫자**: 시간·쪽·점수는 `font-variant-numeric: tabular-nums`, 시간표 시간은 고정폭 글꼴.

## 4. 여백과 배치

- 여백 단계 `4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96`. 관련된 것은 좁게(8~16), 덩어리 사이는 넓게(32~64), 섹션 사이는 64~128.
- 제목 위 여백 > 제목 아래 여백. 섹션 사이에 굵은 구분선을 겹겹이 두지 않는다(여백이 구분선).
- **섹션별 모양**(같은 모양이 반복되지 않게):
  - 목록형(차례·일정·자료·준비·FAQ·용어·차시·목표·연수 후): 넓은 화면에서 제목 왼쪽(5/12, 붙박이) · 내용 오른쪽(7/12), 줄 사이 가는 선.
  - 차례: 큰 번호 + 제목 + 한 줄 설명. 일정: 시간 | 내용 | 부. '지금'은 옅은 강조색 바탕 + "지금" 글자.
  - 도구: 이름(링크) · 주소(고정폭) · 설명 · 교재 쪽의 2~3단 색인. 자료: 형식 · 제목 · 크기 · 받기 단추 한 줄.
  - 핵심 단계·요약 숫자: 위쪽 선만 있는 가로 열. 실습: 왼쪽 목차 + 오른쪽 한 단계, 상자 없이 번호와 선.
  - 첫 화면·마무리: 프리셋 변형(가운데·좌우·잡지형)을 따르고, 나머지 섹션은 왼쪽 정렬.
- 휴대폰(390px): 한 단, 좌우 20px, 누르는 곳 44px 이상, 가로 스크롤 없음, 입력 글자 16px 이상(iOS 확대 방지).

## 5. 색·상자·움직임

- 색은 `theme.css` 변수만. 강조색(`--primary`)은 번호·링크·현재 위치·지금 표시·주 단추에만. 글자 대비 4.5:1(큰 글자 3:1) 이상 — 엔진 테스트가 12프리셋 × 밝게/어둡게, 34색 조합을 확인한다.
- 선 색은 `--rule-c`(글자색 14%). 프리셋 변형으로 선만 바뀐다: 놀이터·잉크 에디토리얼은 진한 선, 종이·윤곽형은 조금 진한 선.
- 그림자는 떠 있는 것(대화상자·도크·메뉴)에만. 하드 오프셋 그림자는 네오브루털 프리셋(놀이터)의 단추에만.
- 움직임은 프리셋당 한 '순간'(첫 화면 제목·마무리)과 의미 있는 것(숫자 세기·일정 선 그리기·완료 축하)만.
  '섹션 등장(reveal-up)'·'카드 기울기(tilt)'·'흐르는 띠(marquee)'·'그라데이션 글자'는 프리셋 기본에서 뺐다. 동작 줄이기 설정과 멈춤 단추를 늘 따른다.

## 6. 말

- 단추는 동사형 2~8자: "자료 받기", "질문 올리기", "설문 열기". 메뉴는 명사 2~4자.
- 안내는 해요체 한 문장. 같은 말을 제목·설명·단추에 되풀이하지 않는다. 빈 화면은 할 일을 알려 준다("아직 질문이 없어요. 첫 질문을 올려 주세요.").
- 틀 말투 금지: `(을)를`, `(이)가`, "~하시기 바랍니다", "클릭하세요", 영어 대문자 라벨(PART 01, STEP 1)을 장식으로.

## 7. 교재 글꼴 → 사이트 글꼴

교재와 사이트의 인상이 같도록, 교재에 쓴 글꼴을 읽어 같은 글꼴(무료 웹 버전) 또는 결이 비슷한 무료 글꼴로 씁니다.

- **읽는 곳**: PPTX 테마 제목/본문 글꼴(`majorFont`/`minorFont`의 latin·ea·Hang)과 글자 조각의 `a:latin`/`a:ea`(글자 수로 가중) ·
  DOCX 테마·스타일·`w:rFonts`(eastAsia) · HWPX `header.xml` 글꼴과 글자 모양 · PDF 글꼴 이름(pdf.js 또는 파이썬 대체 경로, `ABCDEF+` 떼기).
  제목 자리표시자·제목 스타일·크고 짧은 글 = 제목(display), 나머지 = 본문(body).
- **결과**: `material.detected.fonts = { display:{name, share}, body:{name, share}, all:[{name, share, role}] }`
  → 초안의 `design.sourceFonts = { display:{name, share}, body:{name, share} }`
  → `resolveDesign`이 `design.fonts = {display, body}`(글꼴 키)와 `design.fontMatch`(설명: `from`·`label`·`exact`·`system`)를 채움.
- **고르는 순서**: ① 같은 글꼴의 무료 웹 버전(Pretendard·본고딕/Noto Sans KR·본명조/Noto Serif KR·나눔 글꼴들·G마켓 산스·스포카 한 산스 네오·SUIT·Wanted Sans·IBM Plex Sans KR·고운·주아·도현·검은고딕·마루 부리·함렛…)
  ② 없으면 결이 비슷한 무료 글꼴: 맑은 고딕·굴림·돋움·Calibri → Pretendard / 바탕·함초롬바탕·HY신명조 → Noto Serif KR / 함초롬돋움 → Noto Sans KR /
  HY헤드라인 → 검은고딕 / HY견고딕 → G마켓 산스 / 에스코어 드림 → SUIT / 손글씨 → 개구 / 둥근 글꼴 → 나눔스퀘어라운드.
  ③ 본문에는 제목 전용 글꼴을 쓰지 않는다(본문은 같은 결의 읽기 좋은 글꼴).
- **프로그램 기본 글꼴은 '고른 글꼴'이 아니다**: 맑은 고딕·굴림·바탕·함초롬바탕·Calibri 등은 그 자리에서 프리셋 글꼴을 그대로 둔다.
- 선생님이 글꼴 짝(`fontPair`)이나 글꼴(`fonts`)을 고르거나 `design.fontFrom = 'preset'`이면 교재 글꼴을 쓰지 않는다.
- 유료·독점 글꼴 파일은 절대 싣지 않는다. 주소는 버전 고정 jsDelivr·Google Fonts·네이버 한글(hangeul.pstatic.net)만. 굵기마다 이름이 다른 네이버 글꼴은 굵기별 `@font-face`를 엔진이 직접 만든다(가짜 굵게 방지).

## 8. 검사: `node scripts/design-lint.mjs <사이트 폴더>`

넓은 화면(1280)·휴대폰(390)으로 열어 셉니다. 오류(✗)는 0이어야 하고 경고(!)는 이유를 적을 수 있어야 합니다.

| 규칙 | 수준 | 기준 |
|---|---|---|
| side-stripe | 오류 | 한 변만 2px 넘는 색 테두리·inset 띠(색이 있거나 상자에 붙은 것) |
| pill-chip | 오류 | 높이 14~40px, 반지름 ≥ 높이/2, 배경·테두리가 있는 누르지 않는 글자 |
| nested-cards | 오류 | 상자(테두리·배경·그림자 + 안쪽 여백) 속 상자 |
| gradient-text | 오류 | `background-clip: text` + 그라데이션 |
| emoji-icon | 오류 | 이모지·✦ 등을 아이콘 자리에(반응 버튼·사용자 글 제외) |
| uniform-card-grid | 경고 | 같은 폭 상자 3개 이상 격자 |
| line-length | 경고 | 여러 줄 본문이 한 줄에 한국어 45자·영어 85자 넘음 |
| heading-ratio | 경고 | 섹션 제목 < 본문 × 1.6, 첫 화면 제목 < 본문 × 2.2 |
| font-sizes | 경고 | 한 화면 글자 크기 12가지 초과 |
| long-label | 경고 | 단추·탭 16자, 라벨 40자 초과, `(을)를`·"하시기 바랍니다" 같은 틀 말투 |

모듈로도 씁니다: `import { lintPage } from './design-lint.mjs'` → `await lintPage(page)` → `{ findings, metrics }`.

# 점검 목록

## 자동(`check work`)
결과는 요약 몇 줄, 자세히는 `work/check/issues.md`(고칠 곳마다 위치·까닭·고치는 법)와 `report.json`. **고칠 곳**은 모두 고치고, **살펴볼 곳**은 맥락을 보고 정해요(교재 인용이면 둬도 됨).
- 조립: `index.html` 있음, 받지 않는 파일(SVG·엔진 파일 이름·숨김 파일)·바깥 그림·인라인 스크립트 옮김 알림
- 정적: `<!doctype>`·`lang`·`<title>`·viewport·`<h1>` 하나·섹션 제목·빈 섹션·잘린 글, 깨진 그림·링크·CSS·스크립트·앵커, 그림 대체 글, 틀(`iframe`) 주소·제목, 금지 패턴(`<form action>`·비밀번호 칸·`javascript:`·`<object>`·바깥 스크립트·바깥 CSS·importmap), 스크립트 문법, 키트 표시(모르는 종류·투표 보기·설문 문항·JSON 속성·실습 단계 아이디·교재 쪽 범위·자리 표시 안의 글·기능과 자리 표시 짝), `--lp-*` 색 꼴과 글자·바탕 대비, 파일·사이트 크기
- 화면(390·1280px, Playwright가 있을 때): 가로 넘침, 글끼리 겹침, 안 보이는 글·낮은 대비, 잘린 글, 깨진 그림, 빈 섹션, 12px 밑 글자, 작은 단추, 스크립트 오류, CSP가 막은 것
- 문구: 번역투·빈 구호·긴 단추 이름(교재에서 그대로 옮긴 글은 빼고 셈)
- 화면 그림 `work/check/<쪽>-390.png`·`-1280.png`

**화면 그림은 직접 열어요.** 숫자가 통과여도 위계가 흐린 첫 화면, 너무 긴 문구, 어색한 여백, 교재와 동떨어진 색은 눈으로만 보여요.

## 사람 점검(건네기 전)
- [ ] 첫 화면의 연수명·일시·장소·강사가 교재·강사 답과 같은가(`lecpage.json` `facts`의 쪽을 열어 맞춰 봄)
- [ ] 사이트에 교재에 없는 날짜·수치·이름·도구·인용을 지어 쓰지 않았는가
- [ ] 실습 프롬프트·단계·주소가 교재 원문과 같은가(복사 단추로 붙여 넣어 확인)
- [ ] 교재 쪽 그림의 쪽 번호와 본문의 "○쪽"이 맞는가
- [ ] 키트 기능이 필요한 순간에 있는가(실습 단계 안의 [완료 체크]·[도움 요청], 강의 뒤 질문, 끝의 설문)
- [ ] 휴대폰 그림에서 첫 화면만 보고 무슨 연수·지금 할 일이 보이는가, 너무 긴 카드·단추가 없는가
- [ ] 교재의 색·글꼴 느낌이 이어졌는가, AI 티(`design-principles.md` 8번)가 없는가
- [ ] 동작 줄이기(`prefers-reduced-motion`)에서도 내용이 다 보이는가
- [ ] 강사 값(`lecpage.teacher.json`)이 강사가 알려 준 값뿐인가
- [ ] 관리자 키·토큰이 `site/`·`lecpage*.json`·대화 어디에도 없는가
- [ ] 올릴 폴더는 `work/dist/`뿐이고 `work/dist-강사용/`은 올리지 않는가

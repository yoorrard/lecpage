## 사람 점검(빌드할 때마다)
- [ ] 첫 화면에 연수명·일시·장소·강사가 정확한가(교재와 대조)
- [ ] 실습 프롬프트가 교재 원문과 같은가(복사 버튼으로 붙여 넣어 확인)
- [ ] 도구 링크가 모두 열리는가(`check.html` 접속 진단)
- [ ] 교재 뷰어 쪽 번호와 도구 카드의 쪽 번호가 맞는가
- [ ] 글이 너무 긴 카드·버튼이 없는가(휴대폰 화면)
- [ ] 대비가 낮은 글씨가 없는가(특히 그라데이션 위 글씨)
- [ ] '움직임 멈춤' 버튼과 동작 줄이기 설정에서 화면이 멀쩡한가
- [ ] 실시간: 두 기기로 질문·막혔어요·완료 체크를 보내 콘솔에 보이는가, 공지·타이머가 참가자 화면에 뜨는가
- [ ] 개인정보: 수집 항목과 동의 문구가 맞는가, `privacy.html` 내용 확인
- [ ] 관리자 키가 설계도·저장소·사이트 파일 어디에도 없는가

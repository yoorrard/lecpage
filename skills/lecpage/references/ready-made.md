# 이미 있는 것 (새로 짜기 전에)

강사의 요청 대부분은 키트와 조립이 **이미 합니다**. 스크립트·쪽·서버를 새로 만들기 전에 이 표를 봐요. 표에 없을 때만 `site/`에 직접 만들고, 만든 것은 강사에게 알려요.

| 강사가 원하는 것 | 이미 있는 것 | 할 일 |
|---|---|---|
| 질문·투표·나눔 보드·출석·설문 | 키트 자리 표시 | `<div data-lp="qa">` 등(`kit.md`). 연습은 `preview`, 실제로는 배포할 때 참여 기능 서버 연결 |
| 투표를 그 자리에서 띄우기 | 강사 화면 투표 칸의 **즉석 투표** | 질문 한 줄 + 보기 → [바로 띄우기]. 참가자 화면에는 첫 투표 자리에 떠요(그래서 투표를 쓸 연수면 자리 표시를 하나 둬요) |
| 실습 진행 현황·도움 요청 | 실습 단계 자리 표시 | `<section data-lp-step="s1" data-title="…">`에 [완료 체크]·[도움 요청]이 붙고 강사 화면이 셈 |
| 교재 슬라이드(강사 따라) | 교재 슬라이드 자리 표시 | `<div data-lp="deck" data-pages="1-12">`. 쪽 그림은 `prepare`가 만든 것 |
| 자료 나눠 주기 | 자료실 자리 표시 | 파일은 `site/files/`, `<div data-lp="materials" data-items='[…]'>` |
| 프롬프트 복사 단추 | 키트 런타임 | `<button type="button" data-copy-text="프롬프트 원문">복사</button>`(복사하고 알림을 띄움) |
| QR 안내문(인쇄)·발표 화면 접속 안내 | `poster.html`·`screen.html` | 배포 뒤 `handouts <주소>` → `QR-안내문.pdf`·`발표화면.png`(`publish`가 자동으로 함) |
| 사이트 안 QR·공유 | 접속 QR·공유 단추 자리 표시 | `data-lp="join"`·`data-lp="share"` |
| 강사만 보는 화면 | `console.html`(관리자 키) | 참가자·도움 요청·진행·투표·질문·공지·타이머·자료 링크·[CSV 다운로드]·[모든 데이터 삭제], [발표 화면 띄우기] |
| 강사용 연수 전·중·후 안내 | 강사 화면 도움말 + `work/dist-강사용/운영안내.md` | 따로 잠근 쪽을 만들지 않음 |
| 명단·설문·투표 CSV | 강사 화면 [CSV 다운로드] | 직무연수 이수자 명단은 `attendance` 기능 |
| 달력에 넣기 | `assets/event.ics` | 사이트에서 링크만(`lecpage.json` `sessions`로 만듦) |
| 접속 확인(학교·회사 망) | `check.html` | 연수 전날 참가자 망에서 열기 |
| 개인정보 안내 | `privacy.html` | 켠 기능에 맞춰 조립이 씀 |
| 앱에서 이어 하기 | `app work` | `.lecpage` 파일 하나 |

## 만들지 않는 것
- 강사 화면·발표 화면·안내문을 HTML로 새로 쓰기, 참여 기능 서버를 따로 짜기, 관리자 키로 잠근 안내 쪽, 안내물 PDF 스크립트, 참가자 정보 입력 양식.
- `work/dist/`(조립 결과)를 손으로 고치기: 다음 조립 때 사라져요. 늘 `work/site/`를 고쳐요.

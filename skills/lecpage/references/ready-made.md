# 이미 있는 것 (새로 짜기 전에)

강사의 요청 대부분은 엔진이 만든 사이트에 **이미 들어 있습니다**. 스크립트·쪽·안내 파일을 새로 만들기 전에 이 표와 `brief`를 봅니다. 없는 것만 만들고, 만들면 엔진에 넣을 일로 보고합니다.

| 강사가 원하는 것 | 이미 있는 것 | 하는 일 |
|---|---|---|
| 디자인 여러 안 보고 고르기 | `options` | `options work/blueprint.json [--mood calm,bold]` 한 번 → `work/options/contact-sheet.png`. 고르면 `patch --set design.preset=<id>`, 색은 `--set design.accent=#15803D` |
| 교재가 다 들어갔는지 확인 | `make`·`patch` 요약의 `교재 반영` 줄 | 프롬프트·실습 단계·링크·질문답·교재 줄을 엔진이 셈. 빠진 것만 고침. 손으로 대조하지 않음 |
| 무료로 올리기(준비만) | `publish work --dry-run` | 순서와 **강사가 할 일**을 그대로 보여 줌. 실제로는 `--dry-run`을 빼고 한 번 |
| 질문·투표(참여 기능) | 질문 칸·투표 칸, 강사 화면, Cloudflare 중계 | `publish work --live --features qa,poll` 한 번(중계·관리자 키·다시 빌드·올리기·허용 주소·확인). 올리기 전 시험은 `serve dist` → 강사 화면(같은 브라우저 탭은 `local`로 이어짐) |
| 투표를 그 자리에서 띄우기 | 강사 화면 투표 칸의 **즉석 투표** | 질문 한 줄 + 보기 2~5개 → [바로 띄우기]. 참가자 화면·발표 화면에 막대, [결과 공개] |
| QR 안내문(인쇄) | `poster.html`(A4 한 장 + 강사 카드) | 올린 뒤 `handouts <주소>` → 강사용 폴더에 `QR-안내문.pdf`·`강사-카드.pdf` (`publish`가 자동으로 함) |
| 발표 화면 접속 안내 | `screen.html`(QR·주소·연수 코드, QR 크게 보기) | `handouts`가 `발표화면.png`·`발표화면-QR-크게.png`도 만듦 |
| 강사만 보는 화면 | `console.html`(관리자 키) | 참가자·도움 요청·진행·투표·질문·공지·타이머·자료 링크·CSV·데이터 지우기 |
| 강사만 보는 안내(연수 전·중·후) | 강사 화면의 **도움말** 칸 + `<out>-강사용/운영안내.md` | 같은 글. 강사 메모(발표자 노트)는 운영안내.md에만. 따로 잠근 쪽을 만들지 않음 |
| 참가자 명단(별명) CSV | 강사 화면 [기록 내려받기 (CSV)] → [참가자] | 참가자 화면의 [출석] 한 번(도크)으로 질문·투표를 안 한 사람도 명단에 남음 |
| 설문 결과 CSV | 사이트 안 설문이면 [설문 응답] CSV. 바깥 설문(구글 설문지)이면 그 설문의 응답 탭 | 도움말 칸에 받는 법이 적힘 |
| 출석·이수자 명단 | 출석 칸(입실·퇴실, 이름·소속은 동의 뒤) | `info.json` `features`에 `attendance` → [이수자 명단] CSV |
| 접속 확인(학교망) | `check.html` | 연수 전날 참가자 망에서 열기 |
| 개인정보 안내 | `privacy.html` | 켠 기능에 맞춰 엔진이 씀 |
| 암호로 잠그기 | `--password` | AES-GCM. QR에 `#k=` |
| 강사가 화면에서 고칠 곳 표시 | `review dist` | `work/feedback/`을 읽고 `patch` |
| 앱에서 이어 하기 | `app work` | `.lecpage` 파일 하나 |

## 만들지 않는 것
- 강사 화면·발표 화면·안내문을 HTML로 새로 쓰기, 중계 서버를 따로 짜기, 관리자 키로 잠근 안내 쪽, 안내물 PDF 스크립트: 모두 위에 있습니다.
- 교재와 사이트를 한 줄씩 대조하는 일: `교재 반영` 줄과 `qa`가 합니다. 빠졌다고 나온 것만 `patch`로.

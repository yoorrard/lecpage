# 개인정보·연수 행정 기본값

## 개인정보(개인정보 보호법 기준 최소 수집)
| 항목 | 기본값 |
|---|---|
| 참여 신원 | 별명 + 연수 코드만. 가입·로그인 없음 |
| 이름·소속 | 출석·이수 확인을 켤 때만(`privacy.collect: ["name","school"]`). 동의 화면 필수 |
| 전화번호·생년월일 | 받지 않는다. 나이스 등재가 필요하면 기관 절차(별도 명단)를 쓴다 |
| 동의 화면 | 목적·항목·보유 기간·거부권(거부 시 불이익) 네 가지를 자동으로 보여 줌 |
| 처리 안내 | `privacy.html` 자동 생성: 수탁 업체와 국외 이전(Supabase·Google·Cloudflare 등은 미국 기업). 자체 서버(http, workers.dev·바로 배포 주소가 아님)는 맡기는 곳·국외 이전 없음, 'HTTPS로 암호화'는 https 주소일 때만 |
| 보유 기간 | 마지막 기록 뒤 30일(`privacy.retentionDays`), 바로 배포는 늦어도 사이트가 지워질 때 함께. 개인정보 안내·참여 동의·운영 안내가 같은 문장(`keepRule`)을 씀. 콘솔의 "데이터 모두 지우기"로 파기. **올린 파일도 함께** 지운다(아래 '실시간 백엔드') |
| 만 14세 미만 | `audience.minor: true` → 별명만, 보드 파일 올리기 끔(`allowFiles:false`: 콘솔이 서버에 `ui.uploads=false`를 적어 서버도 업로드를 거부). 학생 개인정보를 다루면 '학습지원 소프트웨어' 필수기준과 학교운영위원회 심의 대상이 될 수 있음을 안내 |
| 로그 | 서버에 이름·질문 내용을 로그로 남기지 않음 |

## 실시간 백엔드가 지키는 것(서버에서 강제)
- 관리자 키: 12자 이상, 예시 값(`change-me…`) 거부. 틀린 키는 (코드, IP)·IP마다 10분에 10·20번까지, 넘으면 맞는 키도 잠시 막음(Apps Script는 시트 단위 20번).
- 파일: 글에는 그 서버에 본인이 올린 파일만 붙일 수 있다. 보이는 글의 파일만 열리고, 숨기면 즉시 막히며, 글 삭제·모두 지우기·보유 기간 만료 때 파일도 지운다 — node·Cloudflare는 바로 삭제, Supabase는 비공개 버킷+휴지통(콘솔이 열릴 때 Storage에서 삭제), Apps Script는 드라이브 휴지통.
- 공개 범위: 답·진행·도움 요청의 작성자 ID는 강사와 본인에게만. 별명 '강사·운영자·admin·lecpage'는 참가자가 쓸 수 없음.
- 참가자 글: 보이지 않는 글자·방향 바꿈·한글 채움 문자·쌓인 결합 부호는 서버가 빼고(화면도 받을 때 한 번 더), 화면에는 글자로만. 발표 화면은 글 속 주소를 '(링크)'로 가림.
- 도배: 한 기기 보내기 속도(질문 분당 6개·3초 간격 등)와 서버 한도. 강사는 [질문 받기]·[새 글 받기]를 꺼서 잠그면 서버가 새 글을 거절(409 locked).
- 관리자 키: 강사 화면에서만 쓰고 이 탭에만 둠([이 기기에서 기억하기]는 고를 때만, 공용 PC 경고, [나가기]로 지움). 주소·화면·로그에 남기지 않음.
- 보드 '먼저 확인'(moderation)과 파일 끄기(uploads)는 서버가 지킨다. 연수를 `/init`으로 등록하는 앱은 `settings.uploads:false`·`settings.moderation:true`를 함께 보내면 콘솔을 열기 전부터 적용된다.

공립학교 교사가 업무로 운영하면 개인정보처리자는 학교·교육청이다. 기관 지침이 있으면 그것을 따르라고 강사에게 알린다.

## 저작권
- 업로드할 때 이용 조건(내가 만든 자료·CC·공공누리·이용 허락)을 고르게 한다.
- 교재 속 학생 사진·작품, 그림책 표지 등은 자료실 `notice`에 "연수 목적으로만, 촬영·재배포 금지"를 넣는다.
- 글꼴은 엔진 목록(OFL 등 상업 이용 가능)만 쓴다.

## 연수 행정 모드(`meta.admin.kind`)
| 모드 | 달라지는 것 |
|---|---|
| school 교내 자율연수 | 출석 선택, 설문 기본, 이수 처리 없음 |
| official 교육청 승인 직무연수 | 차시별 입·퇴실 기록(attendance), 이수 기준(`completionRate`, 보통 90%), 출석부 CSV, 15시간 = 1학점 합계(`hours`). 자체 발급 문서는 '참가 확인서'로 표기. 모션 1단계 상한 |
| conference 컨퍼런스·설명회 | 이수 처리 없음, 질문·투표 중심, 업로드 기본 끔 |
| student 학생 워크숍 | 개인정보 입력 차단, 별명만, 보드 사전 승인(moderation) |

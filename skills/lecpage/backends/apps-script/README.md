# 구글 시트로 실시간 기능 쓰기 (Apps Script)

서버도, 카드 등록도 없이 **구글 계정 하나**로 연수 사이트의 질문·막혔어요·진행 체크·출석·투표·보드를 받는 방법입니다. 결과가 구글 시트에 그대로 쌓이므로 연수 뒤 정리도 쉽습니다.

- 잘 맞는 경우: 참가자 **50명 안팎**, 학교·교육청 구글 계정을 쓰는 연수
- 실시간이 아니라 **7초마다 새로 읽기** 방식입니다(질문이 몇 초 늦게 보일 수 있어요).
- 시트 하나 = 연수 하나. 연수마다 시트를 복사해 쓰세요.

## 1. 시트 만들기 (3분)

1. [sheets.new](https://sheets.new) 로 새 구글 시트를 만들고 이름을 "○○ 연수 실시간"처럼 바꿉니다.
   (운영자가 준비한 견본 시트가 있다면 **파일 → 사본 만들기** 를 눌러 내 드라이브에 복사해도 됩니다. 그러면 2번을 건너뛸 수 있습니다.)
2. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 열린 편집기의 `Code.gs` 내용을 모두 지우고, 이 폴더의 **`Code.gs` 전체**를 복사해 붙여 넣은 뒤 **저장(💾)** 합니다.

## 2. 처음 한 번 준비하기

1. 편집기 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 **실행** 을 누릅니다. (시트의 **lecpage → 1. 시트 준비하기** 로 실행하면 연수 코드도 물어봅니다.)
2. "승인 필요" 창이 뜨면 **권한 검토 → 내 계정 선택 → (경고가 나오면) 고급 → 안전하지 않은 페이지로 이동 → 허용** 을 누릅니다. 내가 붙여 넣은 내 스크립트라서 나오는 안내입니다.
3. 시트로 돌아가 새로고침하면 메뉴에 **lecpage** 가 생깁니다. **lecpage → 2. 관리자 키 정하기** 를 눌러 강사 콘솔 비밀번호를 정합니다(**12자 이상**, 예시 값·같은 글자 반복은 거부, 다른 사람이 모르게). 키는 시트에 저장되지 않고 해시만 남습니다.
4. **연수 코드**: 시트 하나는 연수 코드 하나만 받습니다. 준비할 때 적지 않았다면 첫 참가자(또는 강사 콘솔)의 코드로 자동 고정되고, 다른 코드의 요청은 거절합니다. 바꾸려면 **lecpage → 연수 코드 고정하기**.

## 3. 웹 앱으로 배포하기

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 설명: `lecpage`, **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자** 로 고르고 **배포**.
   - "모든 사용자"여야 참가자가 로그인 없이 쓸 수 있습니다. 학교 Workspace 계정은 관리자가 막아 두어 "도메인 내 모든 사용자"만 보일 수 있습니다. 그때는 개인 구글 계정으로 만들거나 정보 담당 선생님께 문의하세요.
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. lecpage 앱(또는 blueprint)의 실시간 설정에 붙여 넣습니다: `live.provider = "sheets"`, `live.url = <웹 앱 URL>`, `live.code = <참여 코드>`.
6. 확인: 웹 앱 URL 뒤에 `?a=ping` 을 붙여 브라우저로 열면 `{"ok":true,…}` 가 보여야 합니다.

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다(주소는 그대로).

## 4. 연수 중에

- 시트 탭마다(질문 `questions`, 막혔어요 `help`, 진행 `progress`, 출석 `attendance` …) 기록이 한 줄씩 쌓입니다. **시트를 직접 고치거나 줄을 지우지 마세요**(강사 콘솔에서 처리하세요).
- 강사 콘솔(`console.html`)에 관리자 키를 넣으면 진행 현황·도움 요청·CSV 내려받기를 쓸 수 있습니다.
- 수식처럼 보이는 글(`=`, `+`, `-`, `@`로 시작)은 글자로 저장되어 시트에서 실행되지 않습니다.

## 5. 파일 올리기 (선택)

기본은 꺼져 있습니다. **lecpage → 파일 올리기 켜기/끄기** 로 켜면 참가자가 올린 파일이 내 드라이브의 `lecpage 업로드` 폴더에 저장됩니다(이미지·PDF·MP3·MP4, 기본 10MB). 처음 켤 때 드라이브 권한을 한 번 더 승인해야 할 수 있습니다. 학교 계정은 외부 공유가 막혀 있을 수 있습니다.

- 파일은 **보드에 보이는 글에 붙어 있는 동안만** "링크가 있는 모든 사용자 보기"로 공유됩니다. 강사가 글을 숨기면 바로 비공개, 글을 지우거나 "모두 지우기"·보관 기간 자동 삭제를 하면 **드라이브 휴지통**으로 옮깁니다(휴지통은 30일 뒤 자동으로 비워짐). 글에 붙지 않은 업로드는 `cleanup` 트리거가 하루 뒤 휴지통으로 옮깁니다.
- 글에는 **이 스크립트가 그 참가자에게 받은 파일만** 붙일 수 있습니다(바깥 주소·남의 파일은 거부). 만든 파일 목록은 `files` 탭에 남습니다.
- 강사 콘솔은 보드가 파일을 받지 않는 사이트(만 14세 미만 연수 등)에서 상태에 `ui.uploads=false`를 적어 두어 서버도 업로드·첨부를 거부합니다. 보드 '먼저 확인'(콘솔의 `ui.moderation`, 또는 스크립트 속성 `MODERATION=on`)이면 새 글은 숨긴 채로 들어옵니다.

## 6. 연수가 끝나면

- 콘솔에서 CSV를 내려받은 뒤 **lecpage → 실시간 데이터 모두 지우기**(또는 콘솔의 "모두 지우기").
- 보관 기간 자동 삭제를 원하면 Apps Script 편집기 왼쪽 **트리거(⏰) → 트리거 추가 → 함수 `cleanup`, 시간 기반, 일 단위** 를 만듭니다. 마지막 사용 뒤 `RETENTION_DAYS`(기본 30일)가 지나면 지웁니다(프로젝트 설정 → 스크립트 속성에서 바꿀 수 있음).
- 다음 연수는 시트를 새로 복사해서 쓰는 것이 가장 깔끔합니다.

## 알아 둘 점(한계)

- 구글 할당량: 한 계정의 Apps Script 동시 실행은 약 30개입니다. 참가자 50명이 7초마다 읽으면 초당 7번 정도라 괜찮지만, 100명이 넘으면 느려지거나 "요청이 몰렸어요" 오류가 날 수 있습니다. 큰 연수는 Supabase나 Cloudflare 방식을 쓰세요.
- 읽기는 4초 동안 캐시되고, 쓰기는 한 번에 하나씩(LockService) 처리합니다.
- 속도 제한(분당, 참가자 기준): 쓰기 90, 질문 8, 도움 6, 보드 12, 채팅 30, 공감 120, 반응 90. 참가자는 500명까지.
- **틀린 관리자 키**는 시트 전체에서 10분에 20번까지만 받고, 넘으면 맞는 키도 그 10분이 끝날 때까지 막습니다(Apps Script는 접속한 사람의 IP를 알 수 없어 시트 단위로 셉니다). 콘솔이 "여러 번 틀려 잠시 막았어요"라고 하면 몇 분 기다리세요.
- 별명 `강사`·`운영자`·`admin`·`lecpage`는 참가자가 쓸 수 없습니다. 답·진행·도움 요청의 `by`는 강사와 본인에게만 보냅니다. 닫힌 투표의 답은 고칠 수 없습니다.
- 응답 상태 코드를 바꿀 수 없어 오류는 `{ok:false, status, error, message}` JSON으로 옵니다(`sheets.js`가 처리).
- 시험: 저장소 루트에서 `node --test skills/lecpage/engine/test/live-sheets.test.mjs` (Apps Script를 흉내 낸 환경에서 `Code.gs`와 `sheets.js`를 함께 검사합니다. 실제 구글 배포 동작은 위 3번의 `?a=ping`으로 확인하세요.)
